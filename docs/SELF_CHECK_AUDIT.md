## 逐章试做的最低标准

| 维度 | 核对方法 | 不合格信号 |
| --- | --- | --- |
| 小节覆盖 | 为每题登记所考的小节或概念标签；至少覆盖本章核心流程、一个限制条件及后续用途 | 多题聚集于同一例子的最后一步，整章其他能力没被考 |
| 任务类型 | 同章结合预测、手算、找错、比较、权衡、场景中的至少三类 | 只把三个“是否／能否”问句换了标签 |
| 真实迁移 | 至少一题更换数据、角色、输入条件或系统约束 | 所谓迁移只是在上一题结果上再除以总和 |
| 可复算性 | 数字题先用未舍入数算，再注明近似误差；明确分母、形状、Mask 和初始条件 | 同题多种解释得到矛盾结果，答案不写中间值 |
| 反馈与泄题控制 | 读者完成自测后，可点击直达 D.2 对应题组，先看提示、再看解答；题目下不出现正确判断 | 答案紧贴题目、链接错位、提示直接泄露数字 |
| 可访问与打印 | 检查题目不跨页拆坏、列表编号连续、链接与标签可读 | 题目孤页、答案重复编号、公式越界或书签失联 |

## 下一阶段：整书教学试做与真实使用审校

43 组均已完成源码层的整组改写；尚需按“章节覆盖、认知梯度、歧义、数字可复算性”逐题人工验收。优先请独立读者试做先修链（函数、梯度、矩阵、Softmax）、Transformer 的前向／训练／生成，以及记忆与 Agent 的跨章应用。需要记录首次作答错误率、查看答案后能否自行订正、是否必须回看一节和争议题目，再决定是否删题／换题，不以机器验收代替教学有效性。

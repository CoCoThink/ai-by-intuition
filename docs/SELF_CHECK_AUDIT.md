# 章末自测试做与题型审计

> 这是下一轮教学验收的工作表，不是“已经通过读者测试”的声明。对应教材源代码以 `book/main.tex` 与 `book/chapters/` 为准。

## 已完成的代码改造

- 共 **43** 个章末自测入口，每个入口保留 `check:<slug>` 锚点和章末核心判断；附录 D.2 保留 `answer:<slug>`。
- 其中 **16** 组已独立设计 **4–5 题**，覆盖不同的计算、错误诊断和使用情境，并在 D.2 按题号给出解答。
- 另外 **27** 组仍是旧三题加一题的过渡结构；其中 **10** 道重复度明显的附加题已换成不同考点，**不因此视为整组重构完成**。
- 静态 QA 要求 16 组的题型不重复、题数与答案编号一一对应。PDF 检查仍包含书签、交叉引用、分页、灰度、公式关联和 PDF/UA-2。

## 逐章试做的最低标准

| 维度 | 核对方法 | 不合格信号 |
| --- | --- | --- |
| 小节覆盖 | 为每题登记所考的小节或概念标签；至少覆盖本章核心流程、一个限制条件及后续用途 | 多题聚集于同一例子的最后一步，整章其他能力没被考 |
| 任务类型 | 同章结合预测、手算、找错、比较、权衡、场景中的至少三类 | 只把三个“是否／能否”问句换了标签 |
| 真实迁移 | 至少一题更换数据、角色、输入条件或系统约束 | 所谓迁移只是在上一题结果上再除以总和 |
| 可复算性 | 数字题先用未舍入数算，再注明近似误差；明确分母、形状、Mask 和初始条件 | 同题多种解释得到矛盾结果，答案不写中间值 |
| 即时反馈 | 章末给读者一个可以快速核对的核心判断，完整推导保留于 D.2 | 只能翻数十页才能判断最基本概念是否答对 |
| 可访问与打印 | 检查题目不跨页拆坏、列表编号连续、链接与标签可读 | 题目孤页、答案重复编号、公式越界或书签失联 |

## 优先完成的 27 组

剩余旧式自测应按学习依赖重做：先处理简单函数与向量链上仍重复的问法，再处理记忆专题的串扰／Delta 规则、模型部署、视觉选读和模型技术判断。重设计时更新 **正文自测 + 章末速答 + 附录 D.2 答案 + QA** 四处，不仅添加“第五题”。

> **状态：尚未开始人工签核。** 本流程提供可重复的任务和证据模板。

## 先冻结验收对象

在 [V3 发布验收](V3_RELEASE_READINESS.md)记录：完整源码 SHA、成功构建 ID、
实际下载的 PDF SHA-256、PDF 物理页数、工具/阅读器及版本、核对日期和审阅人。
必须使用**同一 SHA 的 PDF 和无障碍审计工件**，
不能沿用更早的页码或通过状态。

或 macOS VoiceOver 与兼容的 PDF 阅读器）。
不要因系统只报告“有标签”就勾选已通过。

## 人工逐页高清视觉审校

根据 [灰度校样操作说明](PRINT_PROOF.md)下载绑定 SHA 的 PDF，
执行 `scripts/print_proof.py --all --scale 1100`。
对每一物理页逐项检查：完整文本、上下标与公式矩阵、表格单位、图例
不只依赖颜色、跨页阅读顺序、Unicode 字形、长链接边界和字体大小。
用生成的 `CHECKLIST.md` 逐页记审阅人/日期/问题/处理 SHA。
仅自动生成缩略总览或接近空白页报告不得替代人工签字。

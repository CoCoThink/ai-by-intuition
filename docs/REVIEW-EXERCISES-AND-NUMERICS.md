## 数值验收

- 99 参数模型平均损失：`1.798430 -> 1.611377`。
- `probs[0,3]` 是位置 1 预测 ID 4“花”：`0.261653 -> 0.326865`。
- `probs[1,4]` 是位置 2 预测 ID 5“开了”：`0.050747 -> 0.068548`。
- 附录 B 的全部 20 张参数／中间值／梯度矩阵，共 213 个元素，与参考实现按四位小数精度逐项一致。
- 轨迹第 9 步首次三个贪心标签均为 `[4,5,3]`；第 20 步损失 `0.483173`。
- 独立采样、单次正确率 1/4、完美核验下，N=1/2/4/8/16 的成功率为 0.2500/0.4375/0.6836/0.8999/0.9900；严格达到 90% 需要 N=9。
- `test_time_compute_demo.py` 枚举四候选的小样本空间，另核对完全相关候选保持 25%、错误核验器把最终交付成功率压低的反例。

### 1＋2：合成第一次完整的模型评价

建议内容顺序：

1. 从语言预测的问题转入独立数值例，说明函数、样本与参数。
2. 使用三个样本 `(-1,-1),(0,2),(1,2)` 和直线模型，展示调一个参数会同时影响多个预测。
3. 保留三条候选直线图；初始预测在正文中算一次。
4. 用候选 B 的残差 `(1,-1,0)` 说明直接相加会抵消，再定义均方误差。
5. 用一张候选总表比较 A、B、C，避免在两章分别排出内容相近的预测表。
6. 以“B 只胜过当前三个候选，怎样继续寻找参数？”转入梯度下降。

模型、参数、训练、推理四个定义在需要处集中交代。保留一处章首导入、一组章末自测和一次收尾。正文自测覆盖参数变化、残差与损失、候选最优判断；其余题目移入练习体系并保留解答。

当前第 3 章已重排为“试探—梯度—直接求解—迭代验证—训练循环—学习率—SGD”，合并后成为新第 2 章，继续沿用这一顺序和同一组数据。

### 15＋16：把限制与解决办法放在一起

建议内容顺序为：直接读取的路径图 → 平均与加权读取 → 同一输入兼任三种职责 → 固定点积的对称性及长度偏好 → 拆出 Q/K/V → 同一组输入的投影对照 → 改变 Value 的对照。

保留零参数读出的 `(0.788,0.788)` 与改变 Key 投影后的 `(0.755,0.910)`，让新增能力由计算体现。Q/K/V 在读者遇到职责冲突时定义。训练选择性的实验入口仍保留，并明确它与本章手设二维投影的关系。

本次合并只去掉两章之间的完整收尾和再次开场；不把零参数版本压缩成一句话，也不把 RNN 章一起并入。RNN 的状态传递仍是一个有独立机制和数值过程的比较对象。

### 26＋27：同一个验证器，两种使用方式

先讲 SFT、偏好反馈、可验证奖励，再顺势冻结权重，用同一个 `17+25` 算例尝试多份候选。把“奖励用来更新参数”和“验证用来选本次答案”相邻对照。

保留 Best-of-n 的成功率计算、八次尚未达到严格 90% 门槛的辨析，以及相关候选、错误验证器的反例。方法分工表只保留一次，放在读者已经见过各条路径之后。

偏好与奖励的基础数字仍在正文；DPO 推导、GRPO 实现口径等较深内容继续清楚标为选读。合并后以教学过程组织节次，避免为每个缩写再套一轮小导学和小结。

### 36＋37：先写出问题，再连续比较两种修正办法

从第一条记忆起统一使用后续串扰与 Delta 例子的 Key/Value：`k_A=(1,0),v_A=(1,0)`，`k_B=(0.6,0.8),v_B=(0,1)`。单条外积、加入 B、读取 A、联立求解和逐条 Delta 更新连成同一个实验。

保留 A 在直接累加后读成 `(1,0.6)`、全局精确解，以及 Delta 修正 B 后 A 的误差约为 `0.700` 的反例。用它明确局部修正可能扰动旧关联。原两章中反复出现的“行向量从左边读入”“修改的是状态”在首次公式旁解释，后续靠一致记号承接。

现第 36 章已包含外积与串扰两个源文件，合并应在此基础上接入修正方法；不能按文件个数误判现有章数。

### 38＋39：先算选择性，再选读容量

保留“线性读出 → ReLU 筛选 → 幂次压低弱匹配 → MLP/Attention 统一视角”的主体。末尾设置一个 ★ 容量专题，解释随机 Key 的交叉点积尺度、随机 Value 的抵消，以及容量随维度变化的估计。

容量专题保留推导与假设，允许首读跳过。正文基础自测对应具体读出与选择性；容量题单独标 ★，共用一处练习和答案入口。全部分收束集中在统一比较之后，减少章末总结、下一章导入、部分小结连续重复。

## 三、固定栏目改成按教学需要使用

现有章首将问题、结论、输入输出和参数说明集中在一个框中；自测后已有一行练习/答案链接。直觉框并非每章都有。精简要减少重复信息和视觉分隔，优先保留帮助读者完成计算的内容。

| 位置 | 建议形式 | 保留完整形式的情形 |
| --- | --- | --- |
| 章首 | 一个问题接一小段导入，直接进入案例 | 跨多阶段的贯通实验、较长的现代架构章可保留路线提示 |
| 输入/输出/参数 | 首次计算旁标维度、训练对象；沿用时用一句话承接 | 切换二维/三维例子，改变 ID、形状、Mask 或训练对象时必须明确 |
| 直觉框 | 只承载新的机制解释或必要对照 | 删除与章首结论、紧邻正文、小结同义的重复内容 |
| 自测 | 按本章独立学习目标选题，允许有的章较少、有的有 ★ 挑战 | 保留关键手算、概念判断和会改变结论的反例，不为凑固定题型增加问题 |
| 题号与答案 | 共用一行导航，接在自测后 | 保持公开题号和可点击答案；合并章只出现一处入口 |
| 小结 | 简短收束核心结果和下一个缺口 | 若自测前已完成同样收束，可直接接下一节；部分末章与部分小结协调为一次收尾 |

全书统一的是符号、数值、图文对应和导航习惯。栏目数量随内容变化。不要给“短章版”再造一套同样固定且重复的栏目。

九个部分继续作为阅读路线，地图集中在部分开篇。部分累积复习保留独立题号与整合目标；它与末章自测的分工保持清楚，重复的总结文字统一收束。

## 五、实施顺序与验收

1. 先合并函数/损失，验证一组样本从模型到评分再到训练的阅读节奏；沿用本轮已完成的优化、ReLU 与 RoPE 修订。
2. 合并 Attention、后训练、记忆四组内容；每组合并时重新写中间过渡，清理原章尾和下一章导入的重复。
3. 按新教学目标调整章首和章末，检查保留短章；不把删除栏目等同于删除维度、训练对象或适用条件。
4. 同步 `book/main.tex`、阅读路径、部分开篇/收尾、术语锚点、题库归属和附录答案。公开 C/R 题号保持稳定，旧标签保留兼容入口；自测题与答案逐一对应。
5. 更新与实际目录相关的章数预期，重新运行生成器及源码、数值、引用、排版、灰度、色觉模拟、MathML 和 PDF/UA-2 检查。人工复核合并处的段落、图题、章首与章末，确认减少的是重复框架而非关键解释。

不预报节省页数；完成排版后再比较。同一套内容的可手算性、反例和来源覆盖作为验收重点。已有[下一版计划](NEXT_EDITION.md)中的评测、幻觉与校准案例补齐另行评估，形成完整案例后再决定放入现有章节还是独立专题，不计入本次 34 章映射。

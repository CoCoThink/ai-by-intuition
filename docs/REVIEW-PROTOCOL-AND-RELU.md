## 之前 CI 为什么漏检

旧门禁核对 URL 是否可访问、来源清单与附录 F 日期是否一致，但不比较正文宣称的协议版本与官方当前版本。旧版本规范仍可访问，因此检查通过；当前入口的访问记录甚至已经跳转到新版，也没有触发语义比较。

本轮增加 [check_dated_claims.py](../scripts/check_dated_claims.py)，并接入源码门禁与构建工作流：

- 离线检查断言来源、内容核验日期、目标锚点及附录 G 生成内容；仅有“链接可访问”的记录不能充当内容核验。
- 解析正文 JSON，核对 `params._meta` 内的版本与能力，拒绝缺字段、旧版字段和错误嵌套；正文版本与清单也必须一致。
- CI 在线读取 MCP 官方当前入口，比较最终跳转的修订号。入口指向新版本时要求重新审阅；不会自动修改日期或声称已核验新规范。本地历史版本仍能离线构建。
- 负例覆盖旧版本、缺失能力、元数据层级错误、无内容审阅记录和官方入口变化。

排版检查还明确要求封面署名、仓库地址与许可证同在第一页，版权页紧随其后；避免封面溢出时只报“目录过长”。第 35 章合并重复的工具链说明，使小结与两道部分复习接回同页，既有章末密度门禁保持不变。

[beginner_training_demo.py](../scripts/beginner_training_demo.py) 从样本误差独立复算直线下界、两单元拟合及五行输出权重训练表；[claude_function_call_demo.py](../scripts/claude_function_call_demo.py) 对照正文完整工具定义，检查多轮及并行调用、全部内容保留、结果 ID、越权拒绝、截断及预算终止。这两项均纳入既有数值 CI。Claude 检查采用离线合成响应，本轮没有调用付费 API。

## 验收

本地稳定编译为 **220 页、41 章、57 图、71 表**。源码与数值、八条日期断言、官方当前版本核对均通过；成品没有孤立的小结／自测尾页，全部章首位于页面上方三分之二，57 图均与图题同页。60 个目录页码和 1,087 个内部链接通过目的地检查。

最终 PDF/UA-2、全部公式的 MathML、灰度及色觉模拟验收以同一源码提交对应的 CI 工件为准；结果见本次提交的 GitHub Actions 记录。人工抽查覆盖封面、ReLU 拟合与迭代表、18.1 桥接图、第 35 章收尾和附录 G 清单，未将机器格式检查写成完整人工终审。

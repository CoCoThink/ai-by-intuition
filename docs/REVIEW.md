主要问题有三类：缺少文字稿里那种“为什么需要它”的叙事动力；“大模型”那一半偏薄；还有一批整理和版面上的疏漏。

## 一、内容

**1. 补回“动机层”（文字稿最强、本书最弱的部分）**
- 第 1 章只用一句“不能靠人手写尽所有规则”就切入 y=wx+b。文字稿先讲“精确函数写不出来（认猫、翻译）→ 改为猜一个带参数的函数再逼近”。建议在 1.1 前补一页，并把“猜→调→逼近”作为全书第一条主线。
- 第 9 章没有解释为什么要梯度下降，而不是令导数为零。9.1 的 L(w)=5/2(w−1)² 一步就能解出 w=1。应先让读者这样解，再说“网络的损失解不出来，只能一点点试”（文字稿 1.3 的顺序）。现在读者很可能反问“既然能解，为什么要迭代”。
- 第 5 章缺三样东西：向量为什么是“一组数”而不是一个数（文字稿的二维可直线划分小游戏）；嵌入为什么交给训练而不是人工定义；训练后相近词会靠近（Word2Vec 的 king−queen 类比）。书里的 Embedding 表全是人工给定的数，读者看不到训练的收获。至少补一幅二维散点图和一个“训练前/后”对比。
- 文字稿反复强调的三条心法，很适合做每章固定栏目：先问输入和输出是什么；不知道的就交给神经网络；抓住每个组件最初的“根”。书里类似的想法只在附录 E 以“任务契约”出现，而且正文里没有这个词。

**2. “大模型”一半偏薄**
- 全文检索不到 GPT、涌现、少样本/上下文学习、Scaling Law，也没有“预训练通才→后训练专才”的对比叙事（文字稿 5.1–5.3）。第 24 章是方法清单（SFT/RLHF/RLVR/CoT），但“预训练的模型为什么还不够用”只用一句话带过。
- 缺真实尺度的锚点。文字稿用 GPT-2（768 / 3072 / 50257）告诉读者玩具里的 2×2 对应什么。建议在第 19 或 20 章后加一张“玩具 vs 真实”对照表（d_model、d_ff、词表、层数、头数、参数量），并点明 GPT 只用解码器那一半（18.4 讲了结构，没提 GPT）。
- Tokenizer 只说“规定怎样切”，没有子词/BPE，也没有中文切分的例子。

**3. “贯通算例”不够贯通**
- 第 15 章的 Query=(1,1) 恰好是“开了”自己的向量，且 K=V=E、W=I，所以“自己得分最高”是构造出来的，看不出注意力对预测有什么帮助。另外 x_开了 = x_春天 + x_花，d=2 时三个向量线性相关，容易被误读成“语义相加”。建议改成 d=3，并让注意力读取的结果真正改变 logits。
- 第 20 章（p.45）明说位置编码、归一化、偏置、多头、多层都不参与，而这正是 17–18 章刚教的内容。读者仍没走过完整的 Block。至少把 Norm 和位置编码加进来。
- 17.2（p.39）的位置实验用 P=I，交换后两行都变成 (1,1)，Token 的区别被抹平，是个不幸的巧合。换一个不对称的 P。
- 21.4 只训练输出头、只拟合一个位置。建议再补一步：三个位置同时训练，让读者看到修一道题可能影响另一道，这才体现“一段文本产生多个训练目标”和泛化。
- 第 10 章（10.2）与第 11 章用的是同一组数字（x=2, y=5, w1=1, w2=2, η=0.05），结果也一样。读者会觉得重复，要么合并，要么 11 章换数。

**4. 第 25 章缺“这些词为什么会冒出来”的因果线**
文字稿用“老板和只会一问一答的员工”，把 prompt → context/memory → 联网/RAG → agent → function calling → MCP → workflow/skill → sub-agent 串成“每个概念解决上一步的什么痛点”。本书第 25 章更严谨（工具调用泳道图、提示注入防护、验收清单都超过文字稿），但读起来是并列定义。建议保留严谨性，在 25.1 前加一张演进图。另外 function calling 和 A2A 没有出现。

**5. 缺收尾的大图景**
文字稿第七、八部分讲哪些部件已经收敛、Scaling Law/Bitter Lesson，以及遇到新技术怎么判断它的分量。23.6 的表是个好开头，可以扩成一页。借用文字稿的具体数字（GLM-5.3、DeepSeek V4、67 个模型、能力差距百分比）前要自行核实，文字稿的整理者自己也说未核实。

**6. 篇幅与结构**
- 第七部分联想记忆有 7 章、约 10 页，是选读，还改用列向量约定，与主线的行向量约定冲突。第 13 章却把 mini-batch、优化器、Adam、裁剪、梯度消失/爆炸压在 1 页里，Adam 只有名字，没有手算。建议给 Adam/动量一个两步小算例，并把联想记忆整体移到“扩展篇”。
- 第 4–7 页是阅读指南、数学速查和张量形状速览，其中 d_ff、|V|、W_vocab、τ、β 读者都还没学到。p.7 的表适合挪到书末做速查卡。
- 封面写“Volume 01（后续卷册暂无确定计划）”，读者会困惑。要么去掉 Volume，要么承诺后续。

**7. 文风**
- 对冲太密。例如 17.3“这不是保证所有 Attention 都不会饱和的定理”，18.2“它不保证总梯度在所有情况下都不消失”，23.1“不能从这个恒等式直接保证无限外推”。每句都对，但连续出现会让新手不知道该记哪句。可以收进固定的“边界”侧栏，正文只留主结论。
- 文字稿的类比这里几乎没有。链式法则可以用齿轮传动比，Dropout 可以用“军队里混入高手”，现在 Dropout 只是一段定义。

**8. 自测与习题**
37 道自测多为单步回忆（如 2×3+1=?）。建议分成回忆、手算、迁移三层，例如“把第 20 章的 W_vocab 换一个，预测会怎样”。另外建议附一个约 20 行的 NumPy 脚本复现第 20–21 章的全部数字。手算是本书最大的特色，应让读者能自己验证。

## 二、设计与版式

**1. 封面与辨识度**
封面只有文字和一条很小的流程带，几乎看不清。可以把“春天→花→开了→。”做成主视觉。正文里已有 Q/K/V 的蓝/青/橙配色，可以升级为全书品牌色。

**2. 提示框**
- 同时有十多种盒子：直觉、动手算、易错、小结、读完自测、图解、数学随手查、从这里出发、本部分你会学会、关键观察、读图等。最该醒目的“易错”却是低饱和灰蓝，与“直觉”的蓝色很接近（p.5、p.7）。建议“易错”改用琥珀或红色并加图标，同时合并几种次要盒子。
- “小结”常把回顾和下章预告混在一起，有的很长（如 p.35 的 3 段）。可以拆成“一句话结论”和“下一步”。
- 16.2 的图解盒从 p.36 跨到 p.37，p.37 顶部还留着一段游离的尺寸说明。

**3. 图示**
- 现有图都是同风格的方框加箭头，缺少展示数据样貌的图：注意力权重热力图（含因果掩码灰格）、Embedding 空间散点、训练前后的概率条形图（0.059→0.427，现在只有表）、温度对比条形图（22.3 现在是表）、KV Cache 随步数增长的示意。
- 全书唯一的“从文字到应用”全景图在附录 F（p.87），又小又挤。应前移到封面内页或第 1 章后，并在每个 Part 开篇做“你在这里”高亮。
- 图注位置不统一：图 8（p.32）和图 11（p.36）的图注在图上方，其余在下方。图 13（图在 p.42，注在 p.43）和图 16（图在 p.87，注在 p.88）的图注被甩到下一页。图内的“图解：…”标题与图注内容也重复。
- 图 4（p.23）的反向梯度框字号接近脚注。

**4. 排版与导航**
- 单栏、衬线正文加无衬线标题，整体可读性好，PDF 元数据和字体嵌入也规范。但 p.36 这类页面公式和盒子叠得太满。
- 附录 G（pp.88–90）是三页单列列表，许多条目中英文相同（Adam、Epoch、Key、Query、Value、Dropout、Logits）。建议改两栏，并与附录 D 合并成一张表（中文/英文/一句话/章节）。p.90 的附录 H 标题孤悬在页底。
- 术语回链只到章首页。LoRA 链到第 26 章 p.61，实际内容在 p.63，建议精确到小节。
- 核心公式的加框不统一：9.3、16.2、21.2 加框，18.1–18.2 的残差公式没加。建议统一成“核心公式”样式，并在书末汇总成一页。

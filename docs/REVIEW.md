# 评审意见

讲稿指的是 docs/从函数到Transformer再到大模型_文字稿.md

总体判断：这本书在严谨性、可复算和边界意识上明显强于讲稿，弱点在叙事驱动力、记忆点和"从模型到真实世界"的桥梁。讲稿的优势恰好是这些。下面的建议是借它的叙事手法，同时避开它的松散表述。

## 一、内容：最值得补的 8 件事

1. **补一个"第一页"。** 讲稿开头有一句话主线（大模型就是把前面若干词映射成下一个词的超大函数）、路线表，结尾有"三个小诀窍"：先问输入输出、不知道就上神经网络、抓住组件的根。书里的阅读指南很长，却没有这种可带走的句子。另外，前 28 页（第一、二部分）都是标量和矩阵，语言要到第 29 页才出现。建议在阅读指南里放一张"整机预览图"，第一次看到 Token → Embedding → Attention → FFN → 概率的全貌，后面章节负责填空。

2. **把第九部分和第 31 章接上。** 这是书里错过的最大一处统一：
   - 线性注意力的状态 S = Σ vₖkₖᵀ，就是第 35 章的外积记忆。
   - Gated DeltaNet 的更新是 delta 规则，对应第 36 章"减少干扰"的最小二乘思路。
   - 如果把第九部分改成与主线一致的行向量约定，读取写成 σ(xKᵀ)V，就和第 19 章的 softmax(qKᵀ)V 同形。这样第 36.1.5 节那一长段转置解释基本可以删掉。
   - 第九部分也不必标"选读"，它承载的是核心洞见。

3. **补 Attention 的动机台阶。** 讲稿的推导是：先用词向量点积，发现不灵活，于是拆出 Q 和 K，再单独拆出 V。书里第 18 章直接宣布三种角色。可以先做一个零参数版本（x·x 点积），再点出两个问题：分数矩阵对称，每个词对自己得分最高。第 18.4 节的例子取 W_Q = W_K = I，正好能当反例，只是没点破。

4. **第 29 章（Agent）改成"累积式"讲法。**
   - 讲稿的老板与员工小 L 叙事，每补一层能力，架构图就多长一块。书里把它压成表格，缺了这张逐步长大的图。
   - 补一段 15 行左右的 agent loop 伪代码，再手工走一遍 Q1–Q3 任务的消息列表。
   - RAG 现在没有任何数值例子。用第 9、14 章的点积加 3 个二维文档块，手算一次 top-k 检索，再演示检索错了如何诱发幻觉。
   - 明确一点："API 是无状态的，历史每次整段重发"，再接到 KV Cache 和成本增长。
   - MCP 可放一个 tools/list、tools/call 的最小 JSON 片段。
   - 这章的叙事框架与视频高度重合，建议在章首明确致谢或确认授权。

5. **补一座"玩具到真实模型"的桥。**
   - 在附录 B.4 增加一个真实 GPT-2 small 的实验：真实分词、注意力热图、next-token 概率、温度对分布的影响。
   - 加上 sanity check：随机初始化时损失应约等于 ln|V|（本书 ln5 ≈ 1.609，GPT-2 约 10.8）。顺带可以解释本书主例初始损失 1.798 为何高于均匀猜测。
   - 第 24 章的"同一批数据训练 20 步"其实就是标准调试技巧"先过拟合一个 batch"，值得点名。
   - 第 22 章补参数分布：每个 Block 约 12d²，其中 FFN 8d²、Attention 4d²。这能呼应讲稿"FFN 才是占地面积最大的核心"，也为第 37 章的记忆视角铺垫。

6. **解释 CoT 为什么有效。** 讲稿的说法是模型没有"心算"，话必须说出来。更准确的版本：每个 Token 的前向计算深度固定，写出中间步骤等于买到更多串行计算。这能直接接上第 25 章的自回归，书里 28.5 只讲了"不保证真实"，没讲"为什么可能有用"。

7. **第 31 章加钩子和对照表。**
   - 用讲稿的"忒修斯之船"开篇。
   - 做一张"组件 × 模型"对照表，最好用脚本从公开的 config 读取，这符合本书可复算的风格。
   - 补两个与 GQA 例子平行的小算例：MLA 缓存元素数对比，以及把第 21 章的因果掩码图扩展成滑窗掩码图。

8. **补若干小缺口。**
   - 矩阵运算与 GPU 并行的关系（讲稿 2.1 讲了，第 10 章没讲）。
   - "产品／模型／公司"三分，以及闭源／开放权重／完全开源的分类表。
   - BPE 的 5 行手算。
   - 学习率 warmup 和 AdamW。
   - 位置向量 P 的来源（可训练表还是正余弦）。
   - 把 RLVR 的"相对优势"例子点名为 GRPO，并和 DeepSeek-R1 的引用连起来。
   - 第 34 章末尾补一页"ViT 输出 → 投影 → 并入 LLM 的 Token 序列"，兑现多模态。
   - 书名副标题目前只写到 Transformer，但内容已覆盖助手、Agent 和部署，建议改。

## 二、需要修正或统一的细节

- **第 20.4 节：** 头 1 的权重 (0.330, 0.670) 实际来自 √2 缩放。读者按第 18 章的未缩放算法会得到 (0.269, 0.731)，文中应写出分数和缩放步骤。
- **缩放不统一：** 第 18、19.1 节未缩放，19.4 节起缩放。建议每个算例开头用统一的小标签注明"缩放／未缩放"。
- **位置向量的称呼：** 第 20.2 节叫"固定位置向量"，第 24.5 节却对 P 求梯度并更新，术语冲突。建议改称"与位置绑定的向量"，并说明 P 是可训练表。
- **第 38.3 节：** √M/d 这个量级依赖 Value 的随机符号才能抵消。ReLU² 本身非负，不会抵消，这个条件应明写。
- **PDF 里上标要检查：** 提取文本中第 30.2 节和 D.2 第 33 题的"10⁹"变成了"109"，请确认 PDF 里显示正常。
- **全角括号前的空格：** 提取文本中粗体术语和全角括号之间常有多余空格（"损失 （MSE）"），可能是术语宏的问题。

# 《AI by Intuition》修订版全书设计

> 本稿是对现版《从函数到 Transformer 的直觉之旅》的整体重设计。保留原书的可复算、边界意识和"先问题、再算例、后公式"的风格，吸收讲稿的叙事驱动力、记忆点和"从模型到真实世界"的桥梁。
> 标记说明：【保留】基本不动；【改写】结构或讲法大改；【新增】全新内容；【移动】位置变化；【合并】由多处合并。

## 0. 设计原则

1. **先给全貌，再填空。** 读者第一页就看到一句话主线和整机图，之后每章都是在图上"填一个方框"。
2. **每章先问：输入是什么，输出是什么，形状多大，哪些参数可训练。** 用统一的章首卡固化这一习惯。
3. **每个新部件必须先暴露上一个方案哪里不够用。** 缺口 → 最朴素方案 → 反例 → 改进，不直接宣布结论。
4. **同一个数字例子贯穿到底，且全部可由脚本复算。** 新增内容（RAG、BPE、Agent、GPT-2 实验）同样遵守。
5. **模型能力与系统能力分开讲，证据与边界贴着结论写。** 这是原书的长处，修订时不能被讲稿的松散表述冲淡。
6. **一个洞见只讲一次，其余用回指。** 删除重复的章间桥接，把记忆视角并入主线。

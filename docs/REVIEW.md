## 一、内容结构上的缺口（优先级高）

**1. 分类损失出现太晚，且被"提前使用"。**
- 第 13.4 节已经在报"平均交叉熵 1.7984 → 0.4832"。
- 第 14 章写"损失函数已经学过"，但此前只学过 MSE。
- 交叉熵到 23.3 才定义，logits 到 20.5 才解释，"梯度 = p − onehot"没有推导。
- 建议在第 14 章前插一节"分类损失"，用 3 类小例子走完 logits → Softmax → −log p → 梯度 p − y。
- 同节可以放进文字稿的关键洞见：所有问题都能转成分类问题，输出维度等于类别数（情感二分类只需 2 个输出，预测下一词则等于词表大小）。

**2. "输入是什么、输出是什么"和"Attention 是给输入注入上下文的外挂"应前置。**
- 文字稿反复强调两点：大模型内部本质是一个大神经网络；注意力只是让输入带上上下文。
- 书里这个认识要到第 20–21 章才完整出现。
- 建议在第 15 或 17 章开头放一张"总览图 + 一句话"：Token → Embedding → [给输入加上下文] → 逐位置神经网络 → 词表分数。

**3. 向量与 Embedding 的动机缺失。**
- 第 8 章直接定义向量。文字稿用"每人一个数字 vs 两个数字 → 一维分不开、二维一条直线就分开"来解释为什么要升维。
- 第 13 章建议加一张四方案对比表：人工定义每一维 / ID 单数字 / One-hot / 可训练 Embedding。
- 第 13、22 章全是手设数值，但没说真实模型的 Embedding 和各矩阵是**随机初始化后联合训练**的。建议补一小节"初始化"，讲清为什么不能全 0、尺度怎么选。
- Word2Vec 的"男人−女人≈国王−王后"这种直觉演示，也比现在一句话带过更有效。

**4. 神经网络基础词汇缺失。**
- 书里没有"神经元 / 输入层–隐藏层–输出层"，也没有 L 层通式 `A[l] = g(W[l]A[l−1] + b[l])`。
- "涌现""鲁棒性""升维/降维/潜空间"这些词也没出现。
- 建议在第 11 章补一张经典圈线图，并给出通式。

**5. 第 2–4 章的数据不连贯，第 4.3 节"承诺未兑现"。**
- 第 2 章用三点 (−1,−1),(0,1),(1,3)，第 3 章换成 (1,1),(2,2)，第 4.3 节说要同时调 (w,b) 却没有算例。
- 建议沿用三点数据。我验算过：从 (w,b)=(1,0) 出发，MSE = 5/3，梯度 = (−4/3, −2)；取 η=0.3 更新到 (1.4, 0.6)，MSE 降到 0.4，目标是 (2, 1)。
- 再配一张等高线图或"碗形"图，对应文字稿里"w、b 各调一点点"的直觉。

**6. 第 28 章可以改写成"缺口链"。**
- 文字稿的"你是老板、员工小 L 只会一问一答"的角色扮演，正好契合本书"先提问题再给答案"的风格。
- 建议把 Prompt/Context/Memory、联网/RAG、Function Calling、MCP、Workflow、Skill、Subagent 排成一条链，每个概念写成"上一步缺什么 → 发明了什么 → 一句话本质"：
  - Memory = 把历史塞回输入。
  - Function Calling = 模型与程序之间的 JSON 格式约定。
  - MCP = 工具接入的接口协议。
  - Skill = 把说明和脚本固定存放。
  - Subagent = 上下文隔离。
- 这样更贴合第 31 章"拆解新技术"的目标，也能避免读者把应用层名词当成模型突破。

**7. 第 30 章加一张"从 GPT-2 到今天的组件替换表"，并落回第 22 章的数字。**
- 现有内容覆盖 RoPE、RMSNorm、SwiGLU、MoE、GQA/MLA 和稀疏注意力。
- 缺 YaRN/NoPE、QK-Norm、残差连接的改造（HC/mHC）、混合注意力、线性注意力（Mamba、Gated DeltaNet 等），以及 dense / sparse 的命名。
- "改一行"的做法：第 22 章第一行 X = (1.30, 0.05, −0.30)，RMSNorm 后约 (1.687, 0.065, −0.389)，对比 LayerNorm 的 (1.383, −0.437, −0.946)。这样读者能看到替换的是哪一步、数值怎么变。

**8. 缺"动手层"。**
- 整本 PDF 没有代码，尽量不要依赖仓库 "scripts/teaching_reference.py"代码路径。
- 建议附录给约 40 行 PyTorch 复现（如 `nn.Embedding(5, 3)`），并标出预期输出（1.7984、1.6114），再附 Colab 链接或二维码。
- 加一道"参数怎么数"：
  - 第 22 章玩具模型共 99 个参数（E 15 + P 9 + Wq/Wk/Wv/Wo 36 + Wup 12 + Wdown 12 + Wout 15）。
  - GPT-2 small 约 124M：词嵌入 50257×768 ≈ 38.6M，每块约 12d² ≈ 7.08M，12 层约 85M，再加位置嵌入。
- 这样能把第 14.3 节的尺度卡、第 21 章的形状和第 29 章的显存估算串起来。

**9. 生态与结尾。**
- 第 29.6 节补一张表：CUDA、PyTorch、Hugging Face、Ollama、vLLM 等，并标注"易过期"。
- 结尾（不是附录）放一页"技术底座回顾"：数学 → 神经网络/损失/反传 → MLP、CNN、RNN → Attention/Transformer。现在的 C.3 总图埋在附录里，可以提到正文末尾。
- 第 31 章可补文字稿提到的莫拉维克悖论作为第三条"定律"，并把"架构创新空间收窄"作为**有争议的观点**列出，写明证据和反方。

**10. 第 20.4 节编码器–解码器太简略。**
- 建议加一张"原论文架构图 ↔ 本书术语"对照表（文字稿 4.5 的表很好用），再加一个翻译训练示例，说明掩码为何必要。
- 这样读者读原论文时能无缝衔接。

## 二、一致性与准确性问题

- **修订痕迹泄露到正文：**
  - 第 13.5 节的"其余二维算例将在 M3 与完整 Transformer 的数值链一并迁移"，这是内部里程碑。
  - 第 13.2 节"新版完整贯通实验"、"避免了原二维示例中'开了=春天+花'的偶然构造"，读者看不到旧版，读不懂。
  - 第 25.1 节"先收回前面那张尺度卡"，第 26.2 节"沿用下一章要处理的任务"，都是前后引用错位。
- **多套玩具参数并存，靠反复警告"不能混用"。**
  - 第 17–19 章用 2 维局部例，第 19.4 节和第 25.2 节还有独立的 d_model=4 双头例，主线却是 3 维。
  - 第 13.5 节自己也承认"尚未迁移"。
  - 要么把 17–19 章迁到 3 维主线，要么给所有独立例子统一加"局部例"标记，取代每次重复的文字警告。
- **术语索引不一致：** C.1 把"预训练"标为第 26 章 p58，C.4 标为第 27 章 p59。其他术语（Key、Softmax、缩放点积、Logits）在两张表里粒度不同，前者精确到小节，后者只到章。建议统一精确到小节，并用"§"。
- **练习编号重复：** B.1 与 B.2 各有"练习 1–14"，B.3 另有"题 1–11"，正文引用时易混。建议改成 B1-1、B2-1、B3-1。

## 三、设计与阅读体验

- **"易错"框的用法与图例不符。** 图例说它只提示"形状、转置、信息泄漏"，但大量被用来做范围声明（"不能证明理解真实中文""不等于真实 GPT"）。建议新增"边界"框，并把重复声明合并到前言的"数字约定"一页。
- **防御性措辞过密**（"不保证/并非/不等于"）会稀释真正重要的提醒，每章保留 1–2 条影响判断的即可。
- **第 22 章矩阵过密。**
  - 连续堆了近十个 3×3 和 3×5 矩阵。
  - 正文只留 A、H、P̂ 三个，其余折叠或放附录。
  - 加注意力 A 的热力图（带因果掩码）、概率条形图，以及一张全程标注 T×d 的"形状流水线"图。
- **第 7 张图（训练前后 Embedding 的前两坐标散点）信息量低。** 可以改成"各坐标变化量"的条形图。
- **行/列向量约定。** 第九部分用列向量，其余用行向量。建议要么改成行向量（只需转置），要么在前言用一张小图固定约定，这样能减少很多重复的转置警告。
- **导读。**
  - 文字稿的"部分 / 主题 / 要回答的问题"表很好，建议放到目录前。
  - 再加三条阅读路线（速读 / 标准 / 动手）和每部分预计时长。
  - 另加版本说明和勘误页。
- **交互。** Softmax 温度、注意力权重、学习率很适合做小滑块或 Notebook。

## 四、不建议照搬文字稿的部分

- 口语和玩笑（"死了""诈骗""破玩意儿"）、产品点名、"套壳/卖铲子"，这些会破坏教材的语气，也容易过期。

- "架构已死"的结论，应作为争议观点呈现，而不是书的立场。

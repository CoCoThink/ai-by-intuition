# 勘误

本页记录已确认、会影响读者理解或计算的错误。排版小问题和措辞改进直接在主分支修订，不逐条列出；版本之间的整体变化见 [CHANGELOG](../CHANGELOG.md)。

## 怎样报告

请在 [Issues](https://github.com/CoCoThink/ai-by-intuition/issues) 中写明：

- PDF 的版本与提交号（印在版权页和附录 G）、页码和章节；
- 原文、你算出的结果和期望结果，最好附上输入数据或复算步骤；
- 图形问题附截图。

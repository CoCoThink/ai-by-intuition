- 《一小时从函数到 Transformer》：https://www.bilibili.com/video/BV1NCgVzoEG9/

Agent 章节的早期稿件使用“任务负责人／员工小 L”叙事，
并以 Prompt、Memory、RAG、Function Calling、MCP、Agent、
Skill/Subagent 的顺序添加能力，与参考讲解的教学组织高度重合。
**当前正文已经取消人物／员工比喻**，改以季度报表的
任务约束、证据完备、计算核验、系统状态、异常编排和输出审计为主线；
七行图也已换成\textbf{任务核对关口}，而非逐层安装组件。
仍需作者对照原视频和讲稿，核实是否存在其他实质性表达的沿用；

## 0. 为什么要改，以及什么不能丢

本计划综合 [REVIEW.md](REVIEW.md)、[文字稿](从函数到Transformer再到大模型_文字稿.md)、现有 [ROADMAP.md](../ROADMAP.md)、[book/README.md](../book/README.md) 与 [book/main.tex](../book/main.tex)。文字稿提供“为什么需要下一项技术”的叙事动力；已成书内容提供矩阵形状检查、精确手算、训练边界、工具权限、可复现构建等严谨性。**目标是融合两者，不是把教材改写成视频口播稿。**

**核心问题：**一套可训练的数字运算，怎样从样本中学到语言模式，借助上下文预测下一个 Token，并逐步成为能处理真实任务的助手？

**预期读者收获：**
1. 不背术语清单，也能沿“上一个方案哪里不够用”解释新技术出现的必要性；
2. 从标量参数更新走到可复算的 Decoder-only Transformer 前向、联合损失、梯度更新和生成；
3. 分清模型权重、训练策略、推理策略、外部数据、工具协议与应用编排；
4. 读到新模型/新缩写时，能按问题、输入输出、代价、实证来判断它究竟改变了什么。

**必须保留：**一个正式 PDF；分文件维护的 LaTeX/TikZ；主线行向量约定；已有矩阵/梯度/归一化/多头数字推导与提示注入安全边界；PDF/UA-2、MathML-AF 和现有机器验证门槛。已发布 v0.1.0 是历史基线，不回写修改旧 Release。

## 1. 四条设计原则与执行口径

### 原则一：缺口驱动，每章解决一个**主缺口**

全书主线：

**规则无法写尽 → 假设带参数的函数 → 衡量误差 → 求参数/迭代调整 → 非线性与反向传播 → 一个数不够用，向量和矩阵 → 文本数值化 → 单 Token 缺上下文 → 按需读取 → 完整 Transformer → 训练、生成语言 → 规模与后训练 → 可用助手 → 现代架构与技术判断。**

每章有：
- **入口缺口**：上一阶段还不能做什么；不只说“上一章讲过什么”；
- **最朴素方案**：先试一个简单、可计算的办法；
- **失败条件**：具体反例、数值或约束说明它哪里不够；
- **本章新设计**：组件角色、必要时给形式化定义；
- **出口缺口**：一句本章所得、一句尚未解决的问题。

“每章一个主缺口”不等于只能讲一个部件。例如 Block 可同时包含残差、Norm、FFN，因为它们共同回答“如何稳定组织可堆叠的上下文计算”，但其各自职责要明确。跨部分跳转时，写“上一**阶段**的缺口”，不能伪造历史技术发明顺序。

### 原则二：先建立“学习的闭环”，再推广到向量和矩阵

第一部分仅依赖标量、简单代数、少量导数，建立：

**猜函数 → 量损失 → 能直接解时先直接解 → 复杂网络为何要迭代 → 梯度下降 → 链式法则和更新 → 训练集以外能否适用。**

第二部分才用“特征不止一个、参数太多、重复运算需统一表示”引出向量、点积和矩阵。此处将标量网络写成 MLP 的矩阵版，但**不重复完整讲一遍标量反传**。

数学工具不应成为 4 页开场门槛：需要时给局部最小解释；完整符号、形状和公式放书末速查。允许按前置知识明确回链。

### 原则三：一个贯通实验、一个数值来源、逐章升级

主线固定教学短句：**“春天 / 花 / 开了 / 。”**，假定 Token ID **[1,3,4,2]**、小词表 **5 项**（含 ID 0）。

“只出现一次”的可实施含义是：**词表、初始参数、标签和标准结果维护在一个权威数据源；不同章可以引用同一算例，但只展开新增运算，不重复抄写相同推导。** 标量拟合/梯度的入门例和语言模型贯通例属于不同教学阶段，分别有自己的唯一数据源。

实验必须遵守：
1. 主贯通例 **d_model = 3**，初始三个关键词向量明确选为线性无关；禁止再采用“开了 = 春天 + 花”的偶然关系作为语义说明。例子是教学设定，不声称现实 Embedding 满足特定几何法则。
2. 主贯通例采用 **单头因果 Attention**，使用明确的、可训练的 Q/K/V 投影而非所有投影恒为单位阵；要有**上下文反事实对照**，展示替换早期 Token 如何改变最后 logits 或正确词概率。
3. **位置编码不得使用使不同输入意外坍缩的退化设计**；位置实验和主实验使用一致约定。
4. 完整前向至少含 **输入嵌入 + 位置、Pre-Norm、因果单头 Attention、残差、第二次 Norm、FFN、第二次残差、输出头、Softmax**。说明是教学用一个 Block，而不是声称涵盖所有现代模型。
5. 多头可以用**独立 d_model = 4、2 个头各 2 维**的实验教清楚，不强行把 3 维主实验平均拆为 2 头。若以后改成多头主实验，需先整体更新统一参数表与所有预期数值。
6. 第 23 章对 [1,3,4] → [3,4,2] **三个位置一起算预测与平均交叉熵**；至少一次反向更新明确展示共享参数收到多位置梯度之和，并核查更新后各位置损失/概率的变化。单位置推导可以保留作为梯度原理插图，但不能冒充最终联合训练。
7. 参数、矩阵、中间状态、浮点精度、Mask 约定与预期结果以**可执行 NumPy 参考实现**为准；若正文四舍五入，要指定误差容差与取值来源。
8. 所有演示数据必须标“人为设定”，不能暗示已训练的真实模型权重；训练前后点云只是示意还是实际训练实验，应在图注说明。

### 原则四：主线、扩展与速查分层

- **主线 1–31 章**：只采用“每个 Token 占矩阵一行、行向量右乘参数矩阵”的约定。需要列向量讲导数等场合明确标记为数学记法，不偷偷改模型数据约定；第 10 章集中讲转置，后文按需引用。
- **扩展 X1 CNN/ViT**：使用图像张量及其维度说明，不强制改用列向量；如采用与主线不同的铺排方式，篇首声明。
- **扩展 X2 联想记忆**：明确改用列向量检索，提供主线行向量与列向量的一次对照；后续按统一列向量约定推导。
- **速查**：书末提供一页可打印“核心关系总览”；较完整的数学、符号、形状和术语允许增加附页，不为硬塞一页牺牲可读性。
- **序章**：约两页为目标而非硬性页数；一张可读的全景图、一个问题、阅读路线和三条心法。三条心法应表述为“先问输入输出；不易显式写规则时考虑可训练模型；抓住组件解决的原始问题”，避免“凡不知道的都交给神经网络”的无条件断言。

## 2. 新版目录与章节交付标准

**章节编号是目标编号**，迁移前的当前 PDF 编号不得与这里混淆。每章应有一句可单独验收的能力目标。

### 序章：全景与学习方法（目标约 2 页）

- 用户为什么会需要模型生成有用回答；
- 预测下一 Token 是贯穿全书的**具体训练目标，不是 AI 的终极目标**；
- 可视化全景图：函数 → 表示 → 参数学习 → 上下文 → Block → 语言模型 → 后训练与工具 → 架构演进；
- 三条心法、必读/扩展阅读路线；首次出现概念只作必要解释，不先塞完整数学速查表。

### 第一部分：学习是什么（只用一两个数）

| 章 | 主缺口（为什么需要本章） | 本章可验收交付 |
|---|---|---|
| 1 精确规则写不出来 | 猫、翻译和问答很难靠手写完备规则 | 说出为什么转向带参数函数，而非宣称所有规则都不可写 |
| 2 带参数的函数 | 既然不知道精确规则，先选什么可调形式 | 用 y=wx+b、三个数据点区分模型、参数、训练、推理 |
| 3 怎样量“猜得多差” | 两组参数谁更好 | MSE；**先解析解** L'(w)=0，再解释大型非凸网络为何通常不能这样直接求得全部最优参数 |
| 4 梯度下降 | 解不出来时如何有方向地调 | 一维到双参数的两步更新、学习率、下降/发散观察 |
| 5 为什么需要非线性 | 反复堆线性仍是线性 | 标量两层 + ReLU，展示有/无激活函数的差别 |
| 6 反向传播与一次完整更新 | 前层参数怎样影响最终误差 | 同一数值从前向、链式法则到同步更新；整合现有两层反传和四参数学习例，消除重复计算 |
| 7 训练得太好，新题反而错 | 训练损失低不代表泛化好 | 欠拟合/过拟合、训练/验证/测试、正则化、提前停止和 Dropout；类比不得取代定义 |

第 28 章的箭头代表**由任务痛点驱动的教学推导，不是各协议的历史时间线，也不是强制依赖**。RAG 可以独立用于固定工作流，MCP 不是模型推理机制；Function Calling 是模型与应用之间的结构化请求约定，真正的操作由授权系统执行。单独比较“训练参数变化”与“上下文/工具变化”。

### 第七部分：架构为什么在变，往哪走

| 章 | 主缺口 | 本章可验收交付 |
|---|---|---|
| 30 现代架构五问 | 经典 Block 的效率和规模限制如何改进 | 位置/RoPE、归一化、FFN/MoE、MHA-MQA-GQA/MLA、稀疏/线性/混合注意力；分别标注训练、预填充、解码、KV Cache 的收益与代价 |
| 31 大图景与新技术判断法 | 层出不穷的缩写怎样放回知识地图 | Scaling Law、Bitter Lesson、经典部件与变化空间；提供技术分类、输入输出、成本与证据的判断表，留出尚不确定的发展方向 |

**禁用没有证据的断言：**“所有架构都收敛”“位置编码已死”“模型差距缩小证明技术停滞”。对文字稿的 GLM-5.3、DeepSeek V4、67 个模型及能力差距百分比等材料，逐条核验原始发布日期、模型型号、基准定义和统计方法；查不到可靠出处时**不放入事实表**，最多作为待核实的作者观点并显式标注。Scaling Law 是经验尺度关系，不能从单个榜单差值推断架构研究已无空间。

### 扩展篇（不影响 1–31 章独立连读）

## 3. 统一章节模板（不把模板变成新的阅读负担）

建议以如下顺序组织正文，但**不必每章真的打印 7 个小标题**：

1. **缺口句**（1–3 句）：上一步还能做不到什么；
2. **三问卡**：输入？输出？形状？对于不涉及张量的历史/工程章节，第三问改成“系统边界/改变了什么状态”，不写无意义的形状；
3. **最小反例/朴素方案与手算**：让读者先预测会怎样，再观察真实数字；
4. **公式或接口定义**：在必要直觉建立后给正式表达，核心公式统一设计；
5. **易错与边界**：易错提醒操作错误（形状、标签泄漏等）；边界集中表达适用条件和不能推出的结论，不能因放入侧栏而删除关键警告；
6. **自测三层**：回忆、手算、迁移，答案统一在书末；
7. **收尾**：一句结论 + 下一章/阶段仍要解决的一句缺口。

**视觉语义：四类框——直觉、动手算、易错、边界。** “小结”改为短正文收尾而非第五种框；“本部分会学会”“从这里出发”按篇首模板呈现，不再增加任意提示框类型。Q（蓝）/K（青）/V（橙）保持稳定，易错需有独立警示色且**颜色不是唯一识别方式**。

有用的类比（齿轮、军队中的高手、秘书笔记、资料索引）只作为直觉入口，随即说明类比失效点；技术判断以可检验的定义、实验和数据为准。

## 7. 变更优先级与不做什么

**P0：**结构映射、标量学习先行、Embedding 动机、贯穿样例真实闭环、预训练到大模型能力的解释、数值复算、CI/发布门槛。  
**P1：**Agent 因果重排、现代架构总图、扩展篇压缩、习题迁移性与导航设计、版式清理。  
**P2：**大量新增前沿型号、产品盘点、时效性排行榜与额外装饰插图；除非真正帮助教学，否则不纳入核心结构。

**不做：**
- 不照搬文字稿未经核实的“某技术已死”“所有模型 MoE 化”“规模越大必然涌现”或榜单数字；
- 不把主贯通算例做到多层多头全参数逐项手算，致使正文不可读；必要的复杂度放独立算例、附录或代码；
- 不为减少页数删除因果掩码、权限边界、提示注入防护和失效条件；
- 不在重排过程中破坏旧 Release、不用新的正文页码去机械替代老 REVIEW.md 页码；
- 不把 NumPy 示例当成实际训练大型 GPT 的性能基准。

# AI by Intuition · V2 候选版变更说明（待正式出版）

> **状态：候选稿，非 Release。** 本文不指定最终发行号；实际发布时须根据已验收的源码 SHA、构建运行 ID、最终页数和审计文件更新，再经作者确认。

## 面向读者的变化

本次修订将原来的“五个必读部分、两个选读专题”整理为 **七个必读部分、两个独立选读专题、五组 A–E 附录**，主线共 **31 个显示章节**。阅读顺序从“为什么需要学习参数”开始，先理解标量损失、梯度与反传，再学习向量、矩阵和文本数字化，最后完整构建 Transformer、观察训练生成过程，并讨论助手系统和架构判断。

- **学习先于矩阵：**标量损失中先展示可以直接求解的情形，再解释梯度下降的价值；训练与泛化先于第二部分的矩阵运算。
- **统一三维主实验：**固定词表与 `[1,3,4] → [3,4,2]`，完整给出 Embedding、位置、因果 Q/K/V、两次 Pre-Norm 与残差、FFN、词表输出头、三个位置的联合交叉熵和一次共享权重更新。一次训练后损失从 `1.7984303789` 降至 `1.6113771577`；该结果不等于大模型的泛化性能。
- **因果动机更完整：**补足逐 Token MLP 看不到上下文的限制、非退化位置换位对照、Teacher Forcing 与真正推理的区别；另用独立四维双头例讲清矩阵形状。
- **模型到助手：**区分预训练、Few-shot 上下文学习和 SFT；围绕虚构季度报告任务依次讲清 RAG、工具调用、固定工作流、Agent、MCP、Subagent/A2A 的职责和安全边界。
- **选读与附录：**视觉专题加入独立的 ViT Patch 手算，联想记忆整理成四个显示章节；书末集中提供公式卡、分类练习、127 条基础及现代术语、参考答案和文献。
- **文字修订：**修复原评审报告列出的答案内部文件名、习题错位、Attention 到 logits 脱节、任务契约与教师强制缺失等问题。

## 技术和发布变化

- 仍然是一份可再生的 **LuaLaTeX/Tagged PDF**，没有把章节分别发布成多份 PDF。
- 保留 PDF/UA-2 和全公式 MathML-AF，维持表头、图片 Alt、结构化标题、交叉链接和页面边界的机器验收。
- 发布流程改用名称中**不包含 Volume 01** 的 `AI-by-Intuition-Book.pdf`；新版本不再沿用旧版固定的 99 页、1,472 条公式做拒绝阈值，而是核对 PDF 与同次审计的实际统计。
- 发布仍须作者手动指定版本号和成功构建 ID，工作流检查源码祖先关系，不会自动修改或重传 `v0.1.0` 资产。每次正式 Release 只附 PDF、`SHA256SUMS`、`build-audit.zip` 三项资产。
- 教材文本与图采用 CC BY 4.0；`scripts/` 和工作流采用 MIT；第三方资料按原权利条件处理。

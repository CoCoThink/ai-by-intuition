## 第一部分　地基：从函数到神经网络

### 1.1 万物皆函数：两条路线

现在，请你清空大脑，忘掉所有熟悉或不熟悉的概念，只留下一个出发点：**函数**。

后面所有内容的前提是：世界上的逻辑与知识，都可以用一个函数来表示（Functions describe the world）。我们只需要把现实抽象成符号，设定好运算规则（也就是函数），再用算出来的结果去解释现实。比如：

- 输入直角三角形的两条直角边，由勾股定理得到斜边；
- 输入物体的质量和加速度，由牛顿第二定律得到力。

这就是人工智能早期的思路——**符号主义**：相信一切都能找到明确、精确的规律。

但这条路很快走到了头，因为很多问题，人类根本想不出该写成什么样的函数。判断一张图片里有没有猫，对人来说简单到爆炸，对程序来说却是史诗级难题；就连有明确语法和词典的翻译，也很难做得丝滑；更别说复杂多变的人类智能了。

既然不知道函数长什么样，就别硬找了，换个思路。先看一个小例子：已知一些 x 和 y 的值，想找出它们之间的函数关系。

- 如果数据一眼就能看出是 `y = 2x`，那这是符号主义的做法；
- 如果一眼看不出来，就用人类有史以来最具智慧的办法——**猜**：把数据画在坐标轴上，先随便猜一条直线（比如 `y = wx + b` 里令 w = 1、b = 0），再一点点调整 w 和 b，让直线越来越贴近真实数据，直到完全吻合；
- 如果怎么调都不能完全吻合，那就退一步，**简化问题**：大差不差、能近似就行，差不多的时候就停。

"猜"和"简化问题"，就是现代人工智能的思路，称为**连接主义**。说白了，就是人类承认自己"摆烂"了：不再追求精确函数，而是连蒙带猜，逐步逼近一个足够接近真实答案的近似解。

这听上去不太靠谱，早年很多专家也这么想。但事实证明，这种办法用很少的参数就能完成手写数字识别之类的任务，在越来越多的地方展示出有效性，人们才真正重视起来。

### 1.2 从线性函数到神经网络

直线方程 `y = wx + b` 是**线性**函数。数据稍微复杂一点，无论怎么调 w 和 b，直线都够不着了，这时需要让直线"弯一弯"，也就是从线性进化到**非线性**。

办法很简单：在线性函数的最外层再套一个非线性运算，比如平方、sin、eˣ。这就是**激活函数**，它把死气沉沉的线性关系盘活，变成表达能力更强的非线性关系。别怕"非线性"这个词，常用的激活函数简单得很，但效果出奇地好。

接着继续推广：

1. **多个输入**：每个 x 都对应一个自己的 w；
2. **套娃**：只套一层还不够灵活时，就把前面那一大坨当成整体，再做一次线性变换、再套一个激活函数，如此无限套下去。

这样可以构造出极其复杂的非线性关系，理论上能逼近任意连续函数。

不过函数写出来太让人头大，普通人看两层就炸了，所以我们换一种更直观的画法：

- 每个小圈圈叫一个**神经元**。（不建议把它和生物神经元类比，两者其实没什么关系，类比反而影响理解。）
- 最左边是**输入层**，最右边是**输出层**，中间被包裹在复杂函数里、看不到的叫**隐藏层**。
- 整个由神经元相互连接形成的结构，就是**神经网络**。

信号从输入层一层层算到输出层，这个过程叫**前向传播**——其实就是把一个函数的值一步一步算出来而已。每层的神经元数量和隐藏层的层数都可以无限增加，由此能构成非常复杂的函数。

虽然函数可能极其复杂，但我们的目标始终简单明确：**根据已知的一组 x 和 y，猜出所有的 w 和 b。**

### 1.3 怎样算出参数：损失函数与梯度下降

先别碰复杂的非线性，从最简单的线性函数入手，依次回答三个问题。

**什么样的 w、b 是好的？**
能让函数输出尽可能贴近真实数据的那一组。

**什么叫"贴近"？怎么用数学表达？**
在每个数据点上画一条竖线，连接真实值 y 与直线上的预测值 ŷ，线段长度就是误差；把所有误差加起来，就能衡量整体拟合程度。这个表示"预测值与真实值之差"的函数，叫**损失函数**。

直接用绝对值不方便（带绝对值的优化题让人头疼，要各种分类讨论），于是改用平方：既解决了不平滑的问题，又放大了大误差的影响；再按样本数求平均，消除样本数量的影响。最终得到的就是**均方误差**：

```
L = (1/n) · Σ (yᵢ − ŷᵢ)²
```

从参数的角度看，L 就是关于 w 和 b 的函数。

**怎么让损失最小？**
初中就学过：让导数等于零，求极值点。举个具体的例子：四个样本 (1,1)、(2,2)、(3,3)、(4,4)，模型简化为过原点的直线 `y = wx`。把数据代入损失函数，展开化简后，L 就是一个关于 w 的开口向上的二次函数（一条抛物线）；对 w 求导并令其为零，得到 w = 1，也就是 `y = x`，正是最拟合数据的那条直线。

如果把 b 也算进来，损失函数的图像就变成三维的"碗"，要让**每个参数的偏导数**都等于零。偏导数其实很简单：对 w 求偏导，就是把 b 当常数，按一元函数来求导。

这种用线性函数拟合 x 与 y 关系的方法，就是机器学习中最基本的分析方法——**线性回归**。

**神经网络怎么办？**
神经网络是一个极其复杂的非线性函数，它的损失函数更复杂，无法直接令导数为零求出答案。人们的办法简单粗暴：**一点点试**。

举例：假设 w 和 b 都是 5，损失为 10。

- 把 w 增加 1 变成 6，损失变成 9——这次调整对了；
- 把 b 增加 1 变成 6，损失涨到 11——方向反了，那就往小调。

如此循环往复，每次都看"调整某个参数对损失的影响"，再朝着让损失变小的方向挪一点点，直到损失足够小。

把它形式化：

- "w 变化一点点，损失变化多少"，就是损失函数对 w 的**偏导数**；
- 让 w、b 沿着偏导数的**反方向**更新，更新的快慢由一个系数控制，叫**学习率**；
- 这些偏导数组成的向量叫**梯度**；
- 不断更新参数、让损失逐渐变小的过程，叫**梯度下降**。

```
w ← w − η · ∂L/∂w        （η 为学习率）
```

**偏导数怎么求？链式法则与反向传播。**
神经网络整体虽然复杂，层与层之间的关系却很简单。拿一个"一个输入、一个隐藏神经元、一个输出"的小网络来说：先由 x 算出隐藏层 a（经过激活函数 g），再由 a 算出输出 ŷ，最后由 ŷ 和真实值 y 算出损失 L，网络里共有四个参数。

要求最难的 w₁ 的偏导数，其实就是问："w₁ 变化一点点，L 会变化多少？"拆开来看：

1. w₁ 变一点，a 变多少；
2. a 变一点，ŷ 变多少；
3. ŷ 变一点，L 变多少。

每一步都是简单的偏导数，三者**相乘**，就是 L 对 w₁ 的偏导数。就像一串齿轮：第一个齿轮转一圈，最后一个转几圈？把传动比乘起来就行。这就是**链式法则**，本质上就是微积分里的复合函数求导。

由于可以从右往左依次求导，前面算过的中间结果后面还要用，不必重复计算，只需让这些值从右向左"传播"过去即可。这个过程叫**反向传播**。

把两头合起来：

> **前向传播**由输入算出输出 → **反向传播**算出损失对每个参数的梯度 → 每个参数朝梯度的反方向挪一点点。
> 这就是神经网络的**一次训练**。经过很多轮训练，参数一点点变化，直到损失足够小，我们就找到了想要的函数。

### 1.4 调教神经网络：过拟合与各种对策

既然训练方法有了，是不是网络足够大，就什么问题都能解决？理想很丰满，现实很骨感，麻烦很快接踵而至。

**过拟合。** 看两条拟合曲线：只从"预测值与真实值的误差"看，那条把每个点都穿过去的曲线损失最小；但直觉告诉我们，它好得太过头了，只适合训练数据，对新数据反而不如简单的直线准。这种在训练数据上表现完美、在没见过的数据上表现糟糕的现象，叫**过拟合**；模型在新数据上的表现能力，叫**泛化能力**。

原因通常是：数据背后的规律很简单，但模型太复杂，把噪声和随机波动也学会了。对策有以下几类：

| 思路 | 方法 | 要点 |
| --- | --- | --- |
| 从模型入手 | 简化模型 | 神经网络不是越大越好，复杂网络的效果可能还不如一条直线 |
| 从数据入手 | 增加数据量 | 数据足够多，原本复杂的模型就相对"变简单"了 |
| | 数据增强 | 对图像旋转、翻转、裁剪、加噪声，创造更多样本；还能让模型不因输入的小变化而剧烈波动，即增强**鲁棒性** |
| 从训练过程入手 | 提前终止 | 差不多就行，别追求完美；方法粗糙但有效 |
| | 正则化 | 把参数本身加进损失函数作为**惩罚项**，抑制参数的野蛮增长 |
| | Dropout | 训练时每次随机丢弃一部分参数 |

**正则化**多说两句：参数变大时，如果损失下降得不够多，加上惩罚项后总损失反而变大，这次调整就"不划算"，参数增长因此被抑制。惩罚项用参数的绝对值之和，叫 **L1 正则化**；用平方和，叫 **L2 正则化**（参数越大，抑制越强）。控制惩罚力度的系数叫**正则化系数**；像学习率、正则化系数这类"控制参数的参数"，统称**超参数**。（名字的由来：绝对值之和是 L1 范数，平方和再开方是 L2 范数。光念术语比讲原理还长，其实它们只是为了抑制参数的野蛮增长。）

**Dropout** 的思想更反直觉：把神经网络的参数想象成一支军队，里面混入了一位战斗力极强的高手。如果每次训练都由他主导战局，你会误以为整支军队很强，一遇特殊情况就败北——这就是过度依赖少数参数。于是在训练中每次随机让一部分参数"缺席"，逼模型学会依赖更多普通士兵。听起来有点玄学、有点儿戏，但确实有效，而且它出自"深度学习之父"辛顿。

**除了过拟合，训练还会遇到其他问题**，每个问题都有对应的办法：

| 问题 | 表现 | 常见对策 |
| --- | --- | --- |
| 梯度消失 | 网络越深，反向传播时梯度越小，参数难以更新 | 残差网络等合理结构 |
| 梯度爆炸 | 梯度越来越大，参数调整幅度失控 | 梯度裁剪 |
| 收敛慢 | 陷入局部最优或来回震荡 | 动量法、RMSProp、Adam 等自适应优化器 |
| 分布不平滑 | 训练不稳定 | 合理的权重初始化、输入归一化 |
| 计算开销大 | 数据量庞大，每次完整前向、反向传播都很耗时 | mini-batch：把数据切成小批次 |

这里每个概念展开都是一个全新的世界，但和上面的方法一样，目的都是让训练过程更好。可见深度学习并不是"网络够大就能包打天下"，正是各种困境逼出了五花八门的应对策略，所以人们才感叹它像一门玄学。

## 第二部分　把公式变简洁：矩阵与 CNN

### 2.1 用矩阵改写神经网络

最简单的神经网络是 `y = wx + b` 再套一个激活函数。输入变成两个，就有两个 w 和两个 x；输出变成两个，就再来一行公式。w 的下标用来区分，比如 w₁₂ 表示第一个神经元的第二个参数。

这样写下去很麻烦，神经元一多，公式就密密麻麻。于是把加减乘除换成**矩阵运算**：先忽略激活函数，重点看中间的矩阵乘法——W 的一行与 X 的一列对应相乘再求和，结果放在对应位置，每一行都如此。然后把各个矩阵分别用大写字母 Y、W、X 和小写的 b 代替，整个公式就化简成：

```
Y = WX + b
```

再把层数也体现进来：不再区分输入层、隐藏层、输出层，统一用 A 表示，输入层是第 0 层 `A[0]`，用 l 表示第几层，通用公式就是：

```
A[l] = g( W[l] · A[l−1] + b[l] )
```

每一层神经元的值，都是上一层的函数。

费这么大劲儿简化公式，有两个好处：

1. **更简洁、更抽象**，便于进一步讨论更深的问题；
2. 把繁琐的加减乘除换成矩阵运算，可以充分利用 **GPU 的并行计算**，加速训练和推理——这不只是秀写法。

### 2.2 全连接层的局限

到目前为止，每个神经元都与上一层的所有神经元相连，这种结构叫**全连接层**。它只是神经网络结构的一种，并且有问题。

以图像识别为例：输入是一张 30×30 的灰度图，平铺展开后喂给输入层就是 900 个神经元；若下一层有 1000 个神经元，仅这一层就有 90 万个参数，太大了。

更要命的是，平铺展开会**丢掉像素之间的空间关系**：图片稍微平移一下，所有神经元的取值可能和原来完全不同，而从整体上看只是平移或变暗。也就是说，全连接不擅长理解图像的局部模式。

### 2.3 卷积与 CNN

换个办法：在图像上取一个 3×3 的小区域，里面的数值是像素灰度；再准备一个固定的 3×3 矩阵，把两个矩阵**对应位置相乘再求和**，得到一个数；然后让这个小窗口遍历整张图，得到的数值拼成一幅新图像。这就是**卷积运算**，那个固定的矩阵叫**卷积核**。

卷积核并不是新概念。在传统图像处理里，卷积核是已知的，不同的核对应模糊、浮雕、轮廓、锐化等效果，就是 PS 里的常规操作。而在深度学习里，**卷积核的值是未知的，和其他参数一样，是训练出来的**。

把神经网络里的某个全连接层换成卷积层，一举两得：

- 大幅减少权重参数的数量；
- 更有效地捕捉图像的局部特征。

从公式上看，只是把矩阵的标准乘法换成了卷积运算。

此后，神经网络不必再画成一个个小圈，可以用更抽象的方块图表示。图像识别网络里，除了卷积层，通常还有**池化层**，作用是对特征图降维，减少计算量，同时保留主要特征。卷积层、池化层、全连接层都可以有多个，这类适用于图像的结构，就是**卷积神经网络（CNN）**。

手写数字识别的可视化就是一个典型 CNN：输入层写下一个"6"，依次经过卷积层、池化层、卷积层、池化层、两个全连接层，最终输出"6"。CNN 的一大魅力是方便可视化——我们能看到训练出来的卷积核从原图中提取了什么特征，虽然是隐藏层里的事，却能观察出实际的意义。

### 2.4 CNN 的局限：引出语言

CNN 也只是神经网络结构的一种，它有个致命的局限：主要用于**静态数据**，比如图片。如果要处理时间序列、文本、语音、视频这类**动态数据**，就需要另外的结构。这条路，将通向今天的大语言模型。

到这里，所需的铺垫已全部推完：从函数到神经网络，从损失函数到反向传播，从过拟合对策到矩阵与卷积。接下来，我们坐上这些知识搭成的火箭，冲向现代 AI 技术的最前沿。

## 第三部分　让神经网络读懂文字

### 3.1 大模型的起点：预测下一个词的函数

今天的大语言模型，起点其实非常简单：**我们要找到这样一个函数——输入是多个词，输出是预测的下一个词。** 比如输入"飞天闪客"或"今天天气真好"，输出紧跟其后的那个词。

怎么找这个函数？前面的内容已经给出了答案，浓缩成两句话：

- 世界上的任何函数，都能用一个神经网络表示；
- 神经网络，就是一个通用的函数形式，里面包含未知参数。

最简单的形式，就是 `y = wx + b`（去掉激活函数后只剩线性函数）。输入 x 可以有多个，输出 y 也可以有多个。然后，我们用大量已知的 x 和 y 去求解未知的 w 和 b：左边的 x、y 就是**训练数据**，右边的 w、b 就是**模型参数（权重）**。

在大模型的视角里，这两部分的量都特别特别大，除此之外没有本质区别。比如即便是不算大的 GPT-2，其中 FFN 层的输入就有 768 个神经元，中间隐藏层有 3072 个，最后线性投影层的输出更是高达 50257 个。现在看不懂这些数字不要紧，后面的每一层都会讲到。

### 3.2 先把问题定义清楚：输入与输出

我们知道，神经网络的输入可以是多个数字，输出也可以是多个数字。但现在的输入和输出都是文字，所以第一步显然是：**文字变数字**。很自然地，应该把每个词都变成**一组**数字（为什么是一组而不是一个，下一节解释）。具体怎么变，我们先不管——你现在是架构师，不屑于讨论细节，反正给我变就行。

输出则反过来：要把神经网络输出的一组数字变回文字。这一步我们可以现在就设计：

- 让输出的这组数字里，**每个位置对应词表里的一个词**；
- 看哪个位置的数字最大，对应的就是预测的下一个词。比如第 98 位数字最大，对应的词是"好"，一组数字就这样变成了文字。

这意味着，输出数字的个数必须等于**词表的大小**。GPT-2 的输出是 50257 个数，正是它的词表大小。

而且，只要改变一下输出的定义，同一套架构就能完成不同的任务：判断这句话的褒贬，只需要两个数字；判断这句话属于一百种场景中的哪一类，就输出一百个数字。归根结底，**所有问题都可以转化为分类问题**，只不过"预测下一个词"这个分类问题的类别特别特别多而已。

> **作者的话：定义问题是关键。**
> 初学者觉得 AI 难懂，讲解的人没讲清楚，核心往往是没有把"问题的定义"搞清楚。很多 AI 问题，只要把"输入是什么、输出是什么"说清楚，中间无非就是用一个神经网络强行求解，根本没有什么复杂性。
> 整个 Transformer 内部，其实就是大大小小的各种神经网络，而每个神经网络最关键的，仍然是它的定义：输入是什么，输出是什么，向量有多长。剩下的东西没什么好研究的——靠大量输入输出数据去训练就是了。
> 我们人类所做的努力，无非是把问题拆成一个个神经网络的输入输出，让它们便于训练；最难的、无法用数学公式写出来的部分，交给神经网络。所以接下来看每个环节，请永远先问：**输入是什么？输出是什么？**

### 3.3 为什么要用"一组数字"：向量与维度

先看一个小游戏。有一群男生和女生，每人用**一个数字**编号，现在要根据编号判断性别。观察发现，女生的编号都是 2 的幂次，于是可以用这个特征来分类。可如果换一种编号方式，**每人用两个数字**表示，这时只需看第一个数字是 0 还是 1，划分起来简单多了。

回到数学本质：

- 在一维数轴上，把男生想象成黑点、女生想象成粉点，要用**一个点**把它们一分为二，几乎做不到，只能用一条非常拐弯的线；
- 升到二维空间（相当于每人两个数字），就可以直接用一条**直线**划分了——第一个数字表示性别特征，甚至第二个数字还能表示内向或外向，也同样能用直线划分。

一个数字叫一维向量，两个数字叫二维向量。显然，维度越高，信息表达越灵活，也越容易**线性可分**。（冷知识：把向量从低维变高维叫**升维**，反之叫**降维**。）

回到文字：只用一个数字表示一个字，灵活度显然不够，需要一个维度足够多的向量。另外，我们先把最小单位从"字"改成"词"，这个让大模型理解的最小单位就叫 **token**（词元），把句子切成 token 的过程叫**分词（tokenize）**。

### 3.4 词向量：从人工定义到训练得到

那么每个 token 对应的向量应该长什么样呢？

**最直观的想法：人为定义每个位置的含义。** 比如第一位表示"食物属性"：苹果的食物属性很高，"喜欢"几乎没有，"我"嘛，可能稍微有点。把所有位置的值都填好，就用向量表示了一个词。

有了这样的向量，就能做很多事。高维空间不好画，类比到二维：苹果、喜欢、我这三个词彼此很远，毫不相干；而"苹果"可能既靠近"香蕉"（都是水果），又靠近"小米"（都是电子设备）。严格地说，是向量的**方向**一致，用数学语言就是两个向量的**点积**或**余弦相似度**较大。

可是要让向量具备这样的性质，若靠人工定义每个维度的含义，几乎不可能：每个词的含义与变化太丰富，就算真有神人做出来，每个特征也会抽象到不可理解。

**另一个极端：one-hot（独热编码）。** 向量维度等于整个词表大小，每个词只有一个位置是 1，其余全是 0——只有一个位置是"热"的。它有两个问题：词表大，则向量维度大；而且任何两个词的点积或余弦相似度都是 0，**无法度量词与词的相似性**。

（还有一种更低端的极端，是用一个数字 ID 代表一个词：维度太低，数字本身对语言理解毫无意义，也没法衡量词与词的相关性。）

**折中的答案：词嵌入。** 既然维度太高、太低都不好，那就取个不高不低的。关键思路是：**不要人为规定每个特征的含义，爱啥啥。** 每个位置先随机初始化一个值，作为模型的参数，指定一个任务去训练，训练出几就是几；至于每一维代表什么，不管。人类也许完全看不懂这些特征，但它们确实能表达词与词之间的语义关系。（古话说得好：遇事不决上神经网络。）

这些向量拼在一起，就是一个大矩阵，叫**嵌入矩阵**：纵向是词表大小，横向是词向量维度，每一个词对应其中的一个向量。

**早期的做法：Word2Vec。** 流程大致如下：

1. 把所有词向量拼成大矩阵，初始值随机；
2. 准备大量文本作语料，分词后选一个中间词，其余作为上下文词；
3. 训练目标：让中间词与上下文词的向量**点积越大越好**；同时选一些不相关的词作**负样本**，让点积**越小越好**；
4. 在大量正负样本训练后，这个矩阵就训练好了。

（实际的 Word2Vec 中，中心词和上下文词用两个不同的矩阵，这里做了简化。）

这样训练出的词向量表现出许多令人惊艳的效果：降到三维观察，相似的词距离很近；甚至会出现这样的语义运算：`man − woman ≈ king − queen`，或者"桌子 − 椅子 ≈ 鼠标 − 键盘"。你可以暂停下来，体会一下其中蕴含的深意。

但 Word2Vec 有两个主要问题：

1. **词向量是静态的**，不考虑上下文。比如两句话里的"苹果"意思完全不同，向量却一模一样；
2. **不是端到端训练**：训练出的矩阵往往作为下游任务固定的输入，下游任务训练时要把它固化，有种割裂感。

随着算力的突破，后来基于 Transformer 的 BERT 和 GPT 干脆**简单粗暴地随机初始化这个词向量矩阵**，让它随着整个模型的训练一起更新。这个矩阵也获得了正式的名字：**嵌入矩阵（embedding matrix）**。所以，经历了多年演进，词嵌入最终变成了最简单的模样：一个随机矩阵而已。

于是，把文字变成数字的完整流程是：

1. **分词**：句子切成一个个 token，在计算机里表现为一个个数字，称为 **ID**，它同时是嵌入矩阵的**行索引**；
2. 按 ID 在嵌入矩阵里取出对应的词向量，这一步正式叫**词嵌入（token embedding）**；
3. 送入 Transformer 模型，进入后面的流程。

随着整个模型在"预测下一个词"任务上不断训练，最初的嵌入矩阵也被不断更新。代码实现也极其简单：定义两个变量，词表大小 `vocab_size` 和词向量维度 `embedding_dim`，再用 PyTorch 的 `nn.Embedding(vocab_size, embedding_dim)` 就把这个矩阵创建出来了。GPT-2 中词向量的维度是 768。

补充两个常见概念：词向量所在的高维空间叫**潜空间**；人类只能想象二、三维，所以人们会把潜空间降维投影到二维或三维来观察不同词之间的距离，虽然不够准确，但很直观。

### 3.5 神经网络的主体：FFN 与线性投影

输入和输出都设计好了，接下来解剖中间的神经网络。先改造一下输出结构：**在真正的 Transformer 里，网络的输出是多个向量**（每个词对应一个，每个向量长度都是词表大小）。模型的任务是预测下一个词，所以预测时只看最后一个向量即可；而训练时，每个位置的输出都可以被利用起来——你可以理解为每个词都经过同一个神经网络，各自输出自己的"下一个词"，因此可以并行处理。

以最后一个位置为例，在 GPT-2 中，这个神经网络的输入是 768，输出是 50257。中间要设计多少层、每层多少神经元？这没有标准答案，这正是 AI 最玄学的部分。Transformer 的设计是：

1. 先来一层 **3072** 个神经元，叫**升维**（上采样）；
2. 再来一层还原为 **768** 个神经元，叫**降维**（下采样）。经验表明，这样能更好地在高维潜空间中学到有用的特征；
3. 最后来一层 **50257**（词表大小）。虽然从维度上看也是升维，但这一步通常叫**投影**，而且可以根据分类的数量灵活决定神经元个数。

前面那部分，叫 **FFN（前馈神经网络）**，也有叫 FC、MLP 的，都可以；后面那部分叫 **linear（线性投影）**，直译就是"投影"。FFN 输入输出维度完全一致（768 → 768），所以可以**堆叠很多层**——这就是输入输出维度一致的好处。

到这里，只要给足够多的输入和输出文本，模型就已经可以训练了。是不是非常简单？

> **作者的话：真正的核心是这个大神经网络。**
> 很多人一提 Transformer，第一个想到的是注意力机制、多头注意力。但对初学者来说，真正困惑的并不是注意力怎么计算。从模型要解决的问题、从第一性原理看，这个大的神经网络才是最核心的环节。很多人不提，是因为这件事太显然了：任何模型最终都是一个神经网络在起作用。
> 所谓注意力机制，说白了无非是给神经网络的输入"做点手脚"，让输入里包含上下文信息，仅此而已，更像一个**外挂**。对懂行的人，神经网络是默认前提，根本不用提；对小白，真正拦住你理解的恰恰是：它由一个很简单的神经网络实现，输入输出是什么，文字怎么变成数字、数字怎么变成文字。

但这个模型还有一个致命的问题，也正是 Transformer 要解决的核心问题，我们进入下一部分。

## 第四部分　Transformer：把上下文送进网络

### 4.1 致命问题：缺少上下文

先看这个问题：单独拿出最后一个位置的神经网络，它的输入仅仅是"真"这一个词的信息，却要预测出下一个词"好"。可实际上，"好"是**前面所有词共同作用**的结果，前面每个词的信息都会影响下一个词是什么。神经网络再厉害，也有个大前提：得给它足够的信息，至于怎么计算，那才是它的强项。

所以问题的核心就是：**怎样把上下文的信息送进网络？** 历史上有两种方案，先看第一种。

### 4.2 老方案：循环神经网络（RNN）

**先想想最朴素的做法。** 要给一句话里的每个词判断褒贬，或者给几个字让模型生成下一个字，就得先把文字编码成数字（前面已经讲过：嵌入）。如果一句话有 5 个词、每个词是 300 维向量，直接把它们平铺展开，输入层就要 1500 个神经元。能行吗？可以，但有两个问题：

- 输入层太大，而且随句子长度变化，是不确定的变长；
- 平铺展开无法体现词语的先后顺序，就像把图片所有像素展开后一股脑送入输入层一样，既增加神经元个数，又抽象不出特征和关联，费力不讨好。

**RNN 的思路。** 先用经典神经网络处理一个词：输入一个词，输出这个词的褒贬。第二个词来了，也经过同样的网络，并用尖括号标出"第几个词"（即时间步）来体现顺序。但此时第二个词的计算完全没有用到第一个词的任何信息。办法已经写在脸上：**让第一个词参与进来。**

具体做法：第一个词经过非线性变换后，先别急着输出结果，而是输出一个**隐藏状态 h₁**，再由 h₁ 变换得到输出 y₁；然后 h₁ 与第二个词 x₂ 一起参与运算，得到 h₂，继续往后传。这样前面词的信息就一路传递下去，直到最后一个词，整句话所有词的信息都被囊括进来了。

此时权重矩阵需要区分：专门处理词向量的 W_xh，处理隐藏状态的 W_hh，以及计算输出的 W_hy。对比公式，其实很简单：**和经典神经网络相比，只是多了一个"前一时刻的隐藏状态"。** 这个结构就是**循环神经网络（RNN）**，它具备了理解词序的能力，可以做词性褒贬判断、逐字生成、翻译等多种自然语言任务，可以说是大语言模型的鼻祖。

**但 RNN 有两个严重的问题：**

1. **信息随时间步增多而逐渐丢失**，无法捕捉长期依赖；而有的句子，恰恰是距离很远的地方起到了关键作用；
2. **必须按顺序处理**：每个时间步都依赖上一步的隐藏状态，无法并行。

后来人们用 GRU 和 LSTM 改进了 RNN，但它们仍然建立在"让信息按时间步一点点传递"的思路上，只能缓解，无法根治。能不能彻底抛弃顺序计算，**一眼把全部信息尽收眼底**？有的，那就是 Transformer。

### 4.3 新方案：注意力机制就是"加权求和"

做个翻译任务：`I love you, baby` → `我爱你宝贝儿`。把每个词直接丢进全连接网络，没有上下文，长度还只能一一对应；用 RNN，又面临串行计算和长句子的长期依赖。那这也不行、那也不行，怎么办？**小孩子才做选择，成年人全都不要，直接发明一个全新的方案。**

**第一步：最朴素的想法。**
既然下一个词取决于前面所有词，那就把前面所有词的词向量都加进来，得到一个新的词向量。

**第二步：不同的词重要性不同。**
无差别相加不合理，应该给每个词配上不同的权重——也就是把"求和"升级为**加权求和**。

**第三步：权重从哪来？**
权重可以理解为"这个上下文词与当前词的相关性"：系数越大，要包含的这部分信息就越多。两个向量的相关性可以用**点积**表示——对应位置相乘再相加。至于它具体意味着什么不用管，最重要的是这个运算包含了两个词的全部信息，这对神经网络来说就够了。

**第四步：再灵活一点。**
直接用词向量做点积，对神经网络来说缺少灵活性。所以我们可以单独弄出一组新的向量，专门用于点积，而不影响原词向量。甚至"用来和别人做点积的向量"与"被别人做点积的向量"也可以不一样：

- **查询向量 Query（Q）**：用于和其他词做点积；
- **键向量 Key（K）**：用于被其他词做点积。

比如要算"真"这个词与其他词的系数，就用"真"的 Q 向量和其他所有词的 K 向量做点积。还没完，接下来系数要作为权重去加权求和，被加的向量也可以与原始词向量区分开：

- **值向量 Value（V）**：被加权求和的那一组向量。

**总结：** 让每个词的向量分裂出三个新向量 Q、K、V；用 Q 与每个 K 做点积，得到相关性系数；再让系数分别乘以 V，加权求和，得到一个新向量。这个"由词向量加权求和得到新词向量"的过程，就叫**注意力机制（attention）**。恭喜你，学会了 Transformer 最核心的内容。

用翻译例子再走一遍（设词向量维度为 6）：

1. 对每个词的词向量，分别乘以三个矩阵 W_Q、W_K、W_V，得到 Q、K、V，维度不变；
2. 以第一个词的视角：Q₁ 与 K₂ 点积，得到"第一个词与第二个词的相似度"；依次与 K₃、K₄ 点积，最后与自己的 K₁ 也点积；
3. 拿这些相似度系数分别乘以对应的 V 再相加，得到 a₁。a₁ 就是"从第一个词的视角，按相似度权重，把每个词的信息都加到一起"，全部上下文信息都包含进来了；
4. 其他词同理。

（实际在 GPU 里，是把所有词向量拼成大矩阵一次相乘，直接得到包含所有词的 Q、K、V 矩阵，而不是一个词一个词地算。）

**QKV 从哪来？** 既然不知道什么样的 QKV 最有利于预测下一个词，那就按 AI 世界的老规矩——**不知道的事，就上神经网络**。用原始词向量分别乘以三个**可训练的矩阵**即可：乘以一个矩阵，本质上就是一个单层、纯线性（没有激活函数）、输入输出维度相同的神经网络，矩阵里的数字就是未知参数 w 和 b，一开始随机赋值，再靠训练得到。

**多头注意力。** 还可以更灵活：不同视角下，词与词的关系可能不一样，只算一次相关性，灵活度大大降低。于是让每个词分裂出**多组** QKV，每组在自己内部做注意力计算，最后把结果拼接起来（并再乘一个权重矩阵）。这样效果比只有一组更好。每一组叫一个**头（head）**，这种方式叫**多头注意力（Multi-Head Attention，MHA）**。比如两个头，就是给每个词两次学习机会，学出两种不同的相似度关系。

用公式写出来，注意力运算就是：

```
Attention(Q, K, V) = softmax( Q·Kᵀ / √d ) · V
```

即 Q、K 相乘并缩放，再过一层 softmax，最后乘以 V。多头情况则是先把 QKV 通过多个权重矩阵拆分到多个头里，分别做注意力运算，再合并，最后再乘一个权重矩阵得到输出。

**一个关键提示：注意力层的输入输出向量长度不变。** 所以它可以和 FFN 层放在一起，作为一个整体，起个新名字叫 **Transformer Block**，并且可以堆叠很多很多层。

> **作者的话：注意力的本质，就是加权求和。**
> 注意力要解决的问题是：一个词的信息，永远算不出由之前所有词信息共同组成的逻辑——所以必须把上下文加进来。而"把上下文加进来"最直观的方式，就是加权求和。
> 它之所以越来越难，是因为我们不断优化细节：系数怎么算？先想到用词向量点积，发现不够灵活，于是分裂出 QKV；还不够灵活，于是分成多个头；后来现代模型又继续演进，有的为了减小 KV 向量的体积，有的为了降低上下文过长时点积的计算量。
> 但归根结底，出发点只有一个：把上下文信息想办法加进来。所有组件最初的那个"根"都特别简单，你只需要理解这个根，其余的优化手段就没什么难度了，甚至可以根据是否流行、是否是新趋势，选择性地学。

### 4.4 补齐其余零件：位置编码、残差、归一化与 Softmax

注意力机制的加权求和有一个副作用：**丢失了每个词的位置信息**。一个词离得很远和离得很近，影响可能是不一样的。解决办法同样是"再增加一个信息"：

- **位置编码（positional encoding）**：给每个词再加一个表示位置的向量。你不用管它具体表示什么，只是增加了一个信息维度，其余交给神经网络。它可以像词向量一样，从一个可训练的矩阵中取出；也可以有很多种获取逻辑（后文会讲）。把位置编码加到原来的词向量上，这个词就同时具有了位置信息和（经过注意力后的）上下文信息。

再看图中的 **Add & Norm**：

- **Add（残差连接，residual connection）**：把输入向量原封不动地加到输出上，让训练更稳定。
- **Norm（归一化，normalization）**：把向量调整到更稳定的范围，使均值更接近 0、方差更接近 1。不严谨地说，像是把数据"压扁"，但保留了彼此之间的相对差异。可以安插在 MHA 和 FFN 之后。

最后是 **Softmax**。神经网络最后一层 linear 输出的这组数字叫 **logits（分数）**，只要最大的那个能预测对下一个词，任务就完成了；但我们更希望它可读性高一点：让这些数字都落在 0 到 1 之间，并且总和为 1，表示**概率**。softmax 函数就是做这件事的，和归一化有点异曲同工，都是把数据归拢到稳定的范围。

至此，Transformer 的所有组件就都齐了。

### 4.5 完整流程回顾

现在，用一遍口述把全流程串起来：

1. **输入一句话**，先**分词**，每个词叫一个 token；
2. 从**嵌入矩阵**中取出每个 token 的词向量（token embedding）。这个矩阵是随机初始化、随模型一起训练出来的；
3. 此时词向量还不包含上下文，于是要用**加权求和**把上下文信息加进来；
4. 每个词分裂成 **Q、K、V**（由可训练矩阵线性变换得到，本质上是简单的单层神经网络），经过注意力得到包含上下文信息的词向量；
5. 加上**位置编码**，把位置信息也带进来。此时，最后一个词就已经包含了整句话的信息；
6. 把它输入一个神经网络，**输出的定义根据任务灵活决定**：判断褒贬，输出一两个神经元；判断一百种场景，输出一百个神经元；预测下一个词，就弄一个特别大的词表，让输出表示每个词出现的可能性（概率），神经元就非常多了，光是 GPT-2 这种小模型就有五万多个；
7. 中间的神经网络通常是先升维再降维，这就是 **FFN**；**MHA 和 FFN 可以堆叠很多层**，因为它们前后的向量维度不变，这就是常说的 Transformer 的"层"；
8. 最后一层 **linear 线性投影**，把词向量投影成词表大小的向量，它也是一个简单的单层网络，只有线性变换，没有激活函数；
9. 输出的 logits 再经过 **softmax**，变成概率；
10. 此外，还有为训练稳定性增加的小技巧：残差连接、归一化，以及架构图中没有体现的 dropout 等。它们不影响整体理解，但对训练非常重要。

对照原论文的架构图（现代大语言模型基本只使用 Transformer 的解码器部分，所以下表以简化版为准）：

| 我们讲的概念 | 架构图上的名称 |
| --- | --- |
| 输入文字 + token embedding | input / input embedding |
| MHA 多头注意力 | multi-head attention |
| FFN 前馈神经网络 | feed forward（network） |
| 整个 Transformer Block 堆叠 n 次 | N× |
| linear 线性投影 | linear |
| 词表大小的向量，标注各词出现的可能性 | output probabilities |
| 位置编码 | positional encoding |
| 残差连接 + 归一化 | add & norm |
| softmax | softmax |

你会发现，Transformer 其实原本就没有多复杂：除了多头注意力，其余的词嵌入、位置编码、残差归一化、经典神经网络、softmax，都是前面已经见过的"老零件"。把这些老东西拼凑拼凑，就诞生了今天大模型技术的鼻祖。

### 4.6 补充：原论文里的编码器—解码器与翻译训练

原论文《Attention Is All You Need》的完整架构，左边是**编码器**，右边是**解码器**，原本是为翻译任务设计的。以 `I love you, baby` → `我爱你宝贝儿` 为例：

- **编码器**：输入要翻译的文本，经过词嵌入、位置编码、多头注意力、残差与归一化，再送进全连接网络（再残差与归一化），其结果送入解码器的多头注意力，充当 **K、V** 矩阵；
- **解码器**：输入已经翻译出的文本，同样经过词嵌入、位置编码、多头注意力、残差与归一化，然后作为 **Q** 矩阵，与编码器送来的 K、V 一起再做一次多头注意力，再经过全连接网络，最后用线性层投影到词表、再用 softmax 转成概率，概率最高的就是预测的下一个词。

这里有个小区别：**掩码（mask）**。真正推理翻译时是一个词一个词翻的，翻到"我"时，下一个词应该是"爱"，所以输出"我"时不能看到后面的词，需要用掩码把后面的词遮住，让训练时模拟真实推理的过程。

训练过程：输入 `I love you, baby`，解码器输入只有"我"，期望最后输出的词表概率分布里，"爱"的概率最大；如果有偏差，就计算损失函数，反向传播，调整 Transformer 中的各种权重矩阵，直到学好为止。

而 **GPT 的底层，其实就是 Transformer 的一半——只有解码器**：不翻译谁，只管看前面的词、猜下一个词。别看它不停地猜词，猜着猜着就变成了聊天、写代码、解数学题的全能选手。

理解了本章的内容，你再去读《Attention Is All You Need》，会发现它非常容易理解：架构简单粗暴，效果却出奇地好，所以才广为流传，成为今天大模型的基础。

## 第五部分　训练出一个大模型

### 5.1 预训练：文字接龙与自监督学习

现在，如果不看细节，我们得到了一个可以不断预测下一个词的模型。它是怎么训练出来的？答案非常简单。

Transformer 的输入输出是这样对应的：比如"飞天闪客的读者"这句话，下一个字是"们"；"飞天闪客的读者们最帅了"，下一个字是"嘿"。训练阶段每个位置的输出都可以被利用。所以，我们只需要在网上找到**海量文本**，就能当训练数据：

1. 把一段文字的一部分作为输入，看模型的预测值；
2. 把这段文字真实的后续部分作为真实值，与预测值对比；
3. 计算误差（损失函数）、梯度下降、反向传播、更新参数，直到满意为止。

这种"文字接龙"任务最舒服的地方在于**不需要人工标注**：随便找一段文本，把后面的词抠掉，就形成一次训练。这种让数据自己给自己当标准答案的方式，叫**自监督学习**；通过海量文本数据训练、让模型具备初步语言与知识能力的阶段，叫**预训练（pre-training）**。ChatGPT 里的 GPT，全称就是 Generative Pre-trained Transformer，即"生成式预训练 Transformer"。

你可能觉得这也太无脑了，但只要参数和数据量给够，这样一股脑喂出来的模型就会**涌现**出许多神奇的能力。

### 5.2 少样本学习：不训练也能学会新任务

举个例子：先在输入里给几组词语翻译的例子，再给出一个新词，模型就能接着输出对应的译文（比如 orange）。你并没有训练它做翻译，它却通过你给的例子，等价地完成了翻译。也就是说，**不用重新训练模型，只需在输入里举几个例子，它就能照猫画虎地学会一个新任务。**

这就意味着，之前为某个专门任务训练的语言模型，都可以被一个超级通用的预训练大模型替代。这种从上下文示例中学习的能力，叫**少样本学习（few-shot learning）**。只要能用语言把任务描述清楚，这个模型就近乎万能。

### 5.3 后训练：从通才到专才

预训练搞出了一个**通才**，接下来很自然的一个阶段是**后训练**，把模型变成**专才**。

比如问模型一个问题，纯预训练的模型可能只会跟你玩文字接龙；而我们想要的，是它遇到问题就别再玩接龙，而是直接回答。怎么办？很简单：继续用更多文本训练，只不过这次的数据专门是**问答形式**的、**人工精心标注**的数据。这种二次训练的方式叫**监督微调（supervised fine-tuning，SFT）**。

| | 预训练 | 后训练 |
| --- | --- | --- |
| 方式 | 自监督 | 有监督 |
| 数据 | 海量但粗糙 | 少量但精致 |
| 目的 | 训练成通才 | 训练成专才 |

这和人很像：我们先在自然环境中接触大量信息、自己消化，再专门找时间做题、做专项训练，提升具体能力。

随着训练范式的迭代，两者在量级上的差距正在逐渐缩小，后训练变得越来越重要、越来越通用。作者举例说，GLM-5.3 的所有提升就均来自后训练，所以它常被称为"后训练之神"。

### 5.4 思维链与强化学习：榨干智能的上限

为进一步榨干模型的智能，人们又想出了一些小妙招，并且正逐渐成为现代大模型训练的重点。

**思维链（chain of thought，CoT）。** 如果让模型直接给出复杂问题的最终答案，其实很难：因为大模型的底层原理就是不断输出下一个词，它没有像人一样的"心算"过程，所有的话必须说出来。所以，只需在提示词里加一句类似"请一步步思考"的话，模型就会自说自话地把推理过程写出来。由于它把心里话说出来了，从效果上看就像智力水平提高了。参数没动，模型架构没变，仅仅增加了一句提示词就获得了智能的提升，非常划算。

**强化学习。** 除了提示词里的表面技巧，还可以在训练阶段直接激发模型的推理能力，最著名的方式就是强化学习，具体分为：

- **RLHF**：基于人类反馈的强化学习，让模型说的话更合人的心意；
- **RLVR**：基于可验证奖励的强化学习。

强化学习本身是一个庞大的体系，这里不展开。

现在，我们手里的模型不仅会说，还会思考了。但本质上，它仍然只是个文字接龙游戏，充其量改造一下，能成为一个高级的智能客服。我们还能怎么继续榨干它？答案在应用层。

## 第六部分　从模型到应用：一个"文字接龙"模型如何变成 Agent

这一部分会冒出很多新名词。为了看清来龙去脉，我们先把基础概念捋一遍，再玩一个角色扮演的游戏：假设你是老板，手下有个只会"一问一答"的员工，你要想尽办法榨干他的价值——你会"发明"出哪些东西？

### 6.1 先捋清基础概念

回到最初的信念：万物皆函数。

- 先不管三七二十一弄一个非常复杂的函数，根据预测值与真实值的误差，不断调整里面的未知参数。这个函数叫**模型**，里面的参数叫**权重**；
- 参数量特别大，就叫**大模型**；用于自然语言处理的，叫**大语言模型（LLM）**；
- 调整参数的过程叫**训练**；事先训练好一个基础模型，叫**预训练**；在预训练模型基础上继续训练，让它学会具体任务，叫**微调**；
- 参数调好后，根据输入计算输出，叫**推理**；
- 当参数量足够大时，对话能力有了质的提升，产生了一定程度的推理能力。这种量变引起质变、突然出现此前没有的能力的现象，叫**涌现**；
- 大语言模型的本质就是个大函数：根据前面的话，不断计算下一个词是什么。这种基于输入自动生成新内容的 AI 系统，叫**生成式 AI**（不止文本，也包括图像、声音、视频等）；
- 切成最小粒度的词，叫 **token**。

**产品、模型、公司：三个常被混淆的概念。** 2023 年爆火的产品是 ChatGPT，它是个聊天产品；它背后的大语言模型是 GPT（一个系列）；开发它的公司是 OpenAI。（顺便一句玩笑：这家公司的产品一直不开源，所以它"正式更名为 ClosedAI"。）

**开源与闭源。** 一个模型需要训练代码，有了代码可以训练出一组权重，有了权重就可以推理，也就能对外提供服务。据此区分：

| 类型 | 开放了什么 | 例子 |
| --- | --- | --- |
| 闭源模型 | 代码、权重都不开放，只对外提供服务 | ChatGPT、Claude、Gemini |
| 开放权重模型（通常说的"开源"） | 开放模型结构和权重，可下载部署；通常不开放训练代码和训练数据 | DeepSeek、Llama |
| 完全开源模型 | 连训练代码也开放 | Mistral |

有了权重，就可以下载到本地部署使用，很少有人需要重新训练它。这种不依赖他人服务、把模型下载到本地使用的方式，叫**私有化部署**。私有化部署需要复杂的环境配置（装很多依赖软件和工具包），还需要性能强劲的 GPU。个人只想尝鲜，专门买台电脑不划算，于是有了**云桌面**：直接使用别人打包好的环境和软件，这个打包好的东西叫**镜像**。

### 6.2 角色扮演（一）：从文字接龙到"对话"

大语言模型起初只能做文字接龙，不断输出下一个字。如果只是这么用，看起来仍像个智障。小模型确实如此，但参数越来越大，居然在某个临界点涌现出了智能。为了与之前的"智障模型"区分，你在前面加了个"大"字，就有了**大语言模型（LLM）**。

如果把角色人为划分成一问一答两个角色，就实现了第一种有点智能的用法——**对话**。

现在，你是老板，LLM 是你的员工，姑且叫他"小 L"。只是他服务你的方式有点特别：**只能一问一答，然后就结束，不能追问**（这点非常重要）。那接下来你要做的，就是压榨这个只会一问一答的小 L。

- 你给每次对话起了个洋气的名字，叫 **prompt（提示词）**；
- 你发现这部分内容还可以进一步区分：一部分是背景信息，一部分是最终的指示。于是把背景信息单独起名叫 **context（上下文）**；
- 你想追问，但小 L 只能一问一答。于是想了个巧妙的办法：每次沟通前，把之前的对话历史塞进 context，再提出新问题，**伪装成多轮对话**。这些特殊的上下文又被你起名为 **memory（记忆）**。memory 还可以再次调用大模型进行总结，从而压缩记忆、减少上下文长度。

这样，一个原本只能词语接龙的小 L，就被你玩成了能对话、能追问的优秀牛马员工。

几点相关的补充：

- **上下文长度**：不同模型有不同的上下文长度限制，越长，就越能记住前面的信息。对话时给到大模型的所有信息，都叫上下文；从另一个角度看，也可以叫提示词，它能指导模型的回答流程和风格，但本质上就是上下文而已。
- **提示词工程**：早期出现过很多提示词工程师和教程，其实本质就是教你怎么和大模型说话。现在 AI 的对话越来越贴近人的方式，你与人沟通有什么毛病，与 AI 沟通就有什么毛病。你真正缺的是**把自己的意思表达清楚**，而不是 prompt 技巧。
- **温度与 top-k**：大模型是个函数，函数是死的，根据前面的词，输出的下一个词应是固定的。但可以通过**温度**这一参数调节输出的随机性，让下一个词不总是取概率最高的那个；**top-k** 则限定只从概率最高的 k 个词里选。随机性太高，模型容易胡说八道；太低又过于保守，也可能说错。
- **幻觉**：语言上说得通、事实上狗屁不通，甚至是虚假信息的现象，叫大模型的**幻觉**。

### 6.3 角色扮演（二）：联网搜索与 RAG

不久之后，你发现小 L 没有上网查资料的能力：要么不知道，要么胡说八道，说的还都是过时消息。给小 L 配台电脑？不行，小 L 本身只会词语接龙，其他任何逻辑都无法独立完成。

好办：告诉小 L，"如果需要上网搜索，就告诉我，我查完再给你"。但很快你发现这样显得自己有点蠢——**到底谁才是牛马？** 于是你把"上网"的逻辑写成一段程序，让它**代理你和小 L 沟通**，并完成搜索。在外人看来，你仍然是一问一答就拿到了结果，只不过面对的是这个神秘的程序。

这个程序似乎本身就拥有了智能，而且是能操作工具的更高级别的智能。你给它取名叫**智能体（agent）**。（别觉得"写一段程序"叫这么科幻的名字有心理负担：一些早期所谓的智能体，实现逻辑仅仅是多加了一段 prompt，现在回看简直是诈骗。）

**联网搜索**的原理其实就是：在大模型回答之前，先去互联网上查找相关信息，把这些信息和你的问题拼在一起发给大模型，相当于"带着答案回答问题"。这也是缓解幻觉的主要办法之一。（曾有自媒体把"联网能力"吹成重大突破、人类要完蛋，其实就这么个玩意儿。）

既然能搜互联网，自然也可以搜本地文档或数据库——有些数据网上查不到，或是企业不方便公开。这时搜索方式和传统数据库不同：知识通常以向量的形式存储在**向量数据库**中，用词嵌入把文字转成向量，再比较向量之间的相似度，在**知识库**中找出语义相近的片段，这叫**向量检索**。把检索到的信息加入上下文、增强生成内容可靠性的做法，叫**检索增强生成（Retrieval-Augmented Generation，RAG）**。

不妨把联网搜索和 RAG 统称为"搜索"：它们都是**获取模型参数以外的信息的能力**。

### 6.4 角色扮演（三）：Function Calling、MCP 与 A2A

现在的整体架构是：你和小 L 之间隔了一层 **Agent** 程序，它减少你与大模型直接沟通的次数，并处理小 L 无法操作的事——搜索，以及将来可能出现的各种工具调用。

问题来了：Agent 与大模型之间若始终用自然语言沟通，程序很难解析，"鬼知道大模型会怎么描述自己的需求"。所以最好有个约定，让大模型按**指定的死板格式**（如 JSON）回复，程序就能直接解析。这种 Agent 与大模型之间关于工具调用的**对话格式约定**，叫 **function calling**。它就是个约定，好比开发中前后端约定接口格式。

再看工具这边：如果工具的实现写在 Agent 主程序里，就没有与核心功能解耦。把它单独写成一个服务，Agent 如何发现、调用它，又需要一套规范，比如约定 `tools/list` 返回工具列表，`tools/call` 调用具体工具。这套约定叫 **MCP（模型上下文协议）**，由 Anthropic 在 2024 年底提出，为 AI 操作外部世界提供了统一标准。

此时整体架构是：

- **大模型**：只会说话不会做事的智者；
- **MCP 服务**：提供各种工具的程序集；
- **Agent**：传话筒——把大模型的话翻译成工具调用代码，把调用结果原封不动传回大模型，同时还要给你这个老板传话。主打一个：我不生产信息，我只是信息的搬运工。

另有一个协议，是谷歌在 2025 年 4 月推出的 **A2A 协议**，用于 Agent 与 Agent 之间的通信。

Agent 与你交互的形式则可以丰富多彩：像 CLI 一样的命令行窗口、编程 IDE、更通用的桌面助手（比如最近爆火的 Clawdbot、Moltbot、OpenClaw，这三个其实是同一个东西）。作者顺带吐槽，Claude Code 这个名字起得不太好：一开始很多人以为它是大模型的名字，后来好不容易大家接受它是个编程 agent，它却早已走上通用 agent 的道路。早期的 ChatGPT 插件系统、昙花一现的 AutoGPT，以及后来的 Manus，在作者看来都属于智能体。

### 6.5 角色扮演（四）：Workflow、LangChain、Skill 与 Sub Agent

不论什么形式的智能体，都有一个共同缺点。假设任务是：从一份英文 PDF 中提取内容，翻译成中文，再保存为 Markdown。你可以把需求直接描述给 Agent，让它自己规划流程；但如果这个流程相对稳定，每次都让 Agent 自由发挥，不但不稳定，还浪费 token。"提取 PDF"和"保存 Markdown"完全可以固化成固定脚本，中间的翻译直接和大模型沟通，整个流程不需要智能体插手。

- 用**编程**方式固化流程，为方便编写这类链式任务，你发明了一个框架，叫 **LangChain**；
- 为照顾非程序员，又发明了低代码方式：在页面上傻瓜式拖拽，上手难度更低，叫 **Workflow（工作流）**，比如**扣子（Coze）**。

换句话说：有时需要多次使用大模型的能力，比如第一步把口播稿分段，第二步给每段写成文生图提示词，第三步生成图片——把多个步骤编排成一个流程，就是工作流。

但新问题又来了：如果处理的文档不只有 PDF，还可能是 Word、TXT、PPT，输出格式也可能是 HTML、PDF 甚至图片，难道为每种排列组合都写一套工作流？写一堆 if-else 判断也不行，因为你希望用户仍以自然语言触发任务，不牺牲体验。

你可以这样设计：准备一个目录，把所有可能用到的转换脚本都放进去，再写一个统一的说明文件，把整体流程描述清楚，告诉 Agent 按文件格式灵活选取脚本；下达任务前，加一句"先读取这份说明，再按要求完成任务"。这样既保证灵活，又比较可控。

接着继续优化：约定好一个固定位置，在 Agent 中写死一段程序去读取这个位置的 `SKILL.md`，相当于把那句话固化成程序，不必每次都加。虽然你知道这"破玩意儿"本质上就是把提示词换了个地方存起来，还是给它起了个新名字，叫 **skill（Agent 的技能）**——这是往游戏里英雄的方向设计了。

最后，对于复杂任务，Agent 的上下文可能变得非常大，于是又发明了 **sub agent（子智能体）**：独立的子任务在子 Agent 里单独完成，本质上就是**上下文隔离**——子 Agent 产生的上下文不会保留在主 Agent 中，仅此而已。多个智能体相互协作完成更复杂任务的程序，也叫**多智能体**。

> 在这段"发明"的过程中，总共冒出了十几个新词。它们的共同特点是：大多是**应用层、工程层**的约定与组合，并非模型本身的突破。大模型自身能力已经发展得快到极限了（见第七部分）。

### 6.6 另外几个容易混淆的词

- **PGC / UGC / AIGC**：传统由专业机构（影视公司、媒体、权威专家）创作的内容叫 PGC；移动互联网和自媒体时代，由普通用户创作的内容叫 UGC；AI 时代，由 AI 创作或辅助创作的内容叫 AIGC。正面案例是内容公司借 AI 提升产出速度和质量；反面案例是有人用 AI 洗稿、疯狂产出内容，污染互联网内容生态。
- **AGI**：人们对 AI 最终形态的畅想，即**通用人工智能**。容易与上面的词混淆。
- **多模态**：模型不仅能处理文本，还能处理图片、声音、视频等多种形式的内容。

## 第七部分　模型架构的演进：Transformer 还剩多少新花样

### 7.1 忒修斯之船

我们已经看到，人们在应用层做了许多改进，榨干了这个"只会文字接龙"的模型的智力。再看模型本身的架构层面，有哪些演进？这里不像发明 agent 时那样可以搞虚头巴脑的名词，必须是实打实能提升性能的技术，所以更扎实。

先说一个有点扎心的事实：现在的大模型架构与原始 Transformer 相比，已经有点像**忒修斯之船**——每隔一段时间，一个组件就被替换成另一种实现，如今几乎所有零件都换了一遍。那它还是不是原来的 Transformer？有人认为已完全不是，该改名；有人认为本质要解决的问题没变，所以仍是 Transformer。

为了弄清这个问题，作者梳理了从 2019 年的 GPT-2 到 2026 年的 DeepSeek V4，共 **67 个核心开源模型**的架构变化，发现 Transformer 的底座似乎已经没有多少新花样可玩，模型与模型之间的差距也在逐渐缩小。你有没有这种感觉：好久没遇到一个像当年 GPT-4 那样让人震惊的模型了？

把架构简化来看：前后各有一个把文字与数字相互转换的部分，中间是**注意力层 + 前馈神经网络**，承担大部分计算。下面逐个组件看人们做了哪些"手脚"。

### 7.2 位置编码：基本被"挖干净"

- 原论文：**固定位置编码**，用正余弦函数算出一组固定的值，加到词向量上；
- 后来被**旋转位置编码（RoPE）**淘汰，它能让向量点积时具备一些友好的位置特性；
- 再后来有人扩展了旋转位置编码，提出 **YaRN**，用以支持更长的上下文；
- 甚至有人提出 **NoPE**：没有位置编码的位置编码方式，并在一些场景中证明了有效。

实际应用也基本收束到一条时间线上。作者宣布：位置编码，"死"。

### 7.3 归一化：所有组合都被玩过

把向量变换到更稳定的范围（比如均值为 0、方差为 1）的方法叫**归一化**。

- 计算方式：原论文用 **LayerNorm（层归一化）**，现代大模型更常用 **RMSNorm**，更适合当代大模型训练；
- 安插位置：放在注意力层之前叫 **Pre-Norm**，之后叫 **Post-Norm**，前后各来一个也行；与残差连接的组合，还可以放在残差之前或之后；
- 作用对象：不仅可以作用于词向量，还可以作用于注意力层里的 QKV 向量——Q norm、K norm、V norm、QK norm、KV norm……

这些组合，都已经被人类玩遍了。归一化，"死"。

### 7.4 残差连接：连"默认正确"的部分也被动了刀

原始 Transformer 里，残差连接就是一个简单的加法，多年来没人敢动。但后来字节、DeepSeek、Kimi 分别提出了 **HC、mHC、Attention Residuals**，连这个"所有人都觉得肯定正确"的默认部分也被改了。不过这块比较新，目前还处于探索阶段，花样有限。残差连接，"死"。

### 7.5 FFN：从稠密到混合专家（MoE）

FFN 层本质上是普通的全连接神经网络，属于深度学习入门级的结构，但在大模型中**占地面积特别大**（图中每条线都代表一个参数）。怎么办？变小点就好了：

1. 把一个大 FFN 拆成多个小 FFN；
2. 增加一个**可训练的路由层**，每个 token 的计算只路由到其中一部分小 FFN 上；
3. 这样总参数量仍然很大，但推理时只激活少量参数，实现一种平衡。

每个小 FFN 叫一个**专家（expert）**，整个结构叫**混合专家模型（MoE）**。后来 DeepSeek 又做了优化，比如把专家拆得更细、引入共享专家，称为 **DeepSeekMoE**。

现在你在很多模型名字里看到的"A××B"（例如总参数 397B、每次只激活 17B），就是 MoE 架构：总参数量很大，每次只激活其中一部分。现在的大模型基本都已经 MoE 化，只是专家数量和激活比例各有各的配法。人们也因此有了新词：所有参数都参与计算的叫 **dense（稠密模型）**，只激活部分参数的叫 **sparse（稀疏模型）**。FFN 这一块，也"死"。

### 7.6 注意力层：卷到极致

最后是最经典、最精髓的注意力层，人们在这上面花的功夫可以说"恐怖如斯"。

| 方向 | 思路 | 代表 |
| --- | --- | --- |
| 原始做法 | 多头注意力 | MHA |
| 每个 token 仍两两计算，但降低单次计算难度（比如缩短向量） | 数量没变，难度降低 | MQA、GQA、MLA（DeepSeek） |
| 减少计算的数量 | 只算固定窗口内的 token，或挑选一部分 token | DSA、SWA、CSA、HCA 等稀疏注意力 |
| 把复杂度变成线性增长 | 另类的线性注意力 | KDA（Kimi）、Gated DeltaNet、Lightning Attention、Mamba |

传统注意力与线性注意力混合使用，称为**混合注意力（Hybrid Attention）**。这一块暂时没有那么统一，百花齐放，谁也不知道哪个更好；但也正因为太卷，能创新的点基本都被挖干净了。注意力，"死"。

这些花样看着眼花缭乱，本质要解决的问题却很简单：**注意力层最大的问题，是每个 token 向量都要和其他向量做一次计算**（所谓烧 token，烧的就是这玩意儿）。

### 7.7 结论：架构这条路，空间已经不大

总结一下：位置编码、归一化、残差连接、FFN、注意力，整个架构已经没多少可动刀的地方了。

作者特别说明：这期内容有点标题党。严谨地说，他的判断是——**在语言模型领域，单靠继续优化 Transformer 架构来突破模型能力上限，这条路的空间已经不大了。**

证据与推理：

- 从斯坦福的年度 AI 报告可以看出，开源与闭源模型的差距在缩小，各厂商之间的差距也在缩小。（据作者引用的数据：前十名模型的能力差距，从两年前的约 12% 缩小到 2025 年初的约 5.4%；前两名之间则从约 4.9% 缩小到约 0.7%。）
- 道理很好理解：假如大模型的发展是线性的，差距应保持不变；假如是指数型的，差距应越拉越大；**只有发展逐渐放缓，差距才会逐渐缩小**。
- 体感也一致：能大幅提升性能的简单手段，越来越少了。训练一个顶级大语言模型的成本已超过一亿美元，模型规模也到了极限。

从更宏观的视角，作者找到了 AI 发展的三条"定律"：

1. **Scaling Law（缩放定律）**：大力出奇迹。但互联网上的数据基本已被人类挖干净，算力和模型规模短期内也难以大幅提升，所以遇到瓶颈；
2. **Bitter Lesson（苦涩的教训）**：长期来看，人类在模型架构层面设计的小巧思，在更大的模型面前反而是阻碍。说得更狠一点：人类的自以为是，阻碍了模型的学习速度。尤其是现在大模型架构已被改了这么多刀，新想法在这条定律面前很可能是负优化；
3. **莫拉维克悖论**：对人类很简单的，对机器很难；反过来，对机器很简单的，对人类很难。比如机器做算术秒杀人类，但让它缝件衣服，就是世纪难题。语言模型里同样如此，所以底层的 Transformer 架构，并不一定就是正确的。

基于这些考虑，人们也早已在尝试别的路线，比如**多模态**和**世界模型**。但现在不少多模态，只是做了模态对齐，最终仍是在利用大语言模型的便利；世界模型则更模糊，边界和定义都不清晰。

> **作者的补充说明（"叠个甲"）**：视频里反复说"某某死了"，并非对技术的不尊重，而是想用这种形象的方式展示架构的变迁。我们每天接触很多新名词，每个新技术出现时总伴随一些过度宣传，但看完这一部分你会发现，归根结底也就是一堆固定的套路翻来覆去地改，很少有完全出乎意料的花样。所以，**我们不应高估单个技术的贡献，也不应低估量变产生质变的过程**。以后再遇到新技术，不妨回看这一部分，从"上帝视角"重新审视，也许能很快判断它的地位和影响。

## 第八部分　大模型的周边生态与技术底座

### 8.1 模型本身还能怎么"卷"

大模型能力到了边际收益递减的阶段，人们就开始在别的方向寻找出路：

- **模型压缩**：让模型更小，以降低成本、方便个人使用。包括：
  - **量化**：把模型中的浮点数用更低精度表示，减少显存和计算量；
  - **蒸馏**：用参数量较大的模型指导参数量较小的模型；
  - **剪枝**：删除不重要的神经元，让模型更稀疏，提升速度；
- **更低成本的微调**：如 **LoRA、QLoRA、Adapter**；
- **增强推理能力**：如**思维链**；
- **让模型说的话更合人心意**：**RLHF**（基于人类反馈的强化学习）。

### 8.2 围绕大模型做生意

当什么方向都卷不动时，企业可以封装现有的大模型接口，对外提供服务，通俗叫**套壳**；也可以提供 AI 工具、AI 服务、AI 课程、AI 社区等，帮助别人开发和使用 AI 能力。这种在 AI 淘金热里帮别人淘金、自己赚钱的方式，叫**卖铲子**。别看不起卖铲子的——这可得对 AI 各领域的产品和生态都了如指掌才行。

### 8.3 应用领域一览

| 领域 | 方向 | 代表 |
| --- | --- | --- |
| 文字 | 自然语言处理 | ChatGPT、Claude、Gemini、DeepSeek、豆包、通义千问、腾讯元宝 |
| 图片 | 计算机视觉（AI 绘画） | 闭源的 Midjourney、开源的 Stable Diffusion、绘画工作流软件 ComfyUI |
| 语音 | 文字转语音（TTS）、语音转文字（ASR） | — |
| 视频 | AI 视频生成、数字人 | Sora、可灵、即梦 |

### 8.4 基础设施：帮开发者更好地用 AI

- **硬件**：英伟达这样提供好显卡（GPU）及其配套开发框架 **CUDA**；专门针对 AI 的处理器，如用于大规模神经网络训练与推理的 **TPU**，用于终端设备推理的 AI 加速芯片 **NPU**；
- **软件**：适合 AI 的编程语言 **Python**；针对 AI 编程的库 **PyTorch**、**TensorFlow**；AI 开源平台和社区 **Hugging Face**；方便本地运行大模型的工具 **Ollama**；提升推理速度的推理引擎 **vLLM**；AI 编程助手，包括独立软件形式的 **Cursor** 和插件形式的 **GitHub Copilot** 等等。

可做的事情太多了，作者也欢迎观众补充遗漏的重要内容。

### 8.5 万变不离其宗：技术底座

AI 时代瞬息万变，产品工具层出不穷，但技术底座依然保持不变：

1. 最底层是**数学**：线性代数、微积分、概率论、最优化；
2. 深度学习中，用**神经网络表示函数**，以**损失函数最小化**为目标，通过**反向传播**训练参数；
3. 再往上是经典神经网络结构：**MLP**；处理图像数据的 **CNN**；处理序列数据的 **RNN**；
4. 以及引爆整个大模型时代的 **Attention 机制**，和基于它发明的 **Transformer 架构**。

它们共同撑起了现代 AI 技术的大厦。

## 结语：一张图串起全部

回头看，整条线索其实只有一条：

> **万物皆函数** → 精确函数找不到，那就**猜**一个带未知参数的函数（神经网络）→ 用**损失函数**衡量好坏，用**梯度下降 + 反向传播**调参 → 图像用**卷积**，文字要先变成**词向量** → 一个词的信息不够，要把**上下文**加进来：RNN 一步步传，**注意力**一眼看全（本质是加权求和）→ 堆叠 Transformer Block，"预测下一个词"就能训练出大模型 → 预训练铸就通才，后训练、思维链、强化学习打磨专才 → 再往外，是 prompt、RAG、Agent、MCP、Skill 等一层层**工程化**的应用 → 而架构本身的创新空间，已越来越小。

理解 AI 的三个小诀窍，也是作者反复强调的：

1. **永远先问：输入是什么，输出是什么。**
2. **不知道的事，就弄个神经网络去求解。**
3. **抓住每个组件最初的那个"根"，其余的优化细节就没那么难。**

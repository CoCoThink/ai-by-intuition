## 带日期断言与来源核验

- 断言清单的唯一来源是 [dated-claims.json](../book/dated-claims.json)，附录 G 的表格由 `python3 scripts/check_dated_claims.py --write` 生成。所有断言共用“90 天或新修订先到者”的复查周期时，表头只说明一次；周期不同时，生成器自动恢复逐行周期列。
- [check-dated-claims.yml](../.github/workflows/check-dated-claims.yml) 每周定时运行 `python3 scripts/check_dated_claims.py --self-test --online --check-due`，比较 MCP 官方当前入口指向的修订与书中采用的版本，并在到期时失败；每次整书构建也检查到期日期。
- MCP 当前入口指向新修订时，先重新审阅规范、请求字段与正文示例，再更新版本与 `checked_utc`。编译日期、链接可访问或 CI 成功都不能替代内容核验，也不能自动刷新日期。
- 附录 F 的逐条链接记录在 [source-audit.json](../book/source-audit.json)，网页清单 [REFERENCES.md](REFERENCES.md) 与二维码由 `python3 scripts/generate_reference_assets.py` 生成。

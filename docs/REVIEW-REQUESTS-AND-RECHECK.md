# 请求示例、分页与定期复查修订

针对 2026-10-25 的小问题复核，修改当前主分支；归档 Release 保持原样。

| 问题 | 修订与验证 |
| --- | --- |
| MCP 引导句留在页底，JSON 请求移至下一页 | 将引导句放入同一个不可分页的代码框。PDF 门禁按文本定位引导句和协议元数据，要求两者唯一且同页，不依赖固定页码。 |
| Claude 请求说明遗漏 `max_tokens` 和请求头 | 正文明确 `model`、`messages`、`max_tokens`，工具示例另带 `tools`；写明 Bearer 认证、JSON 类型、固定 API 版本和跨工作区密钥的工作区头。脚本使用相同版本，离线检查实际构造的 HTTP 请求，无需密钥或联网推理。 |
| 清单没有复查周期，只有提交触发 CI | 八条断言均注明“90 天／新修订”，说明以先到者为准。内容核验日期独立于编译时间；每次构建及每周一 03:17 UTC 的轻量工作流检查到期日期和 MCP 官方当前修订。到期或发现新修订时失败，要求先人工审阅再更新记录。 |
| 评测与幻觉缺少独立章节 | 记入 [下一版计划](NEXT_EDITION.md)，列出已有内容、待补的手算案例、脚本与练习；本版不增章。 |

Claude 请求必填字段依据 [Messages API](https://platform.claude.com/docs/en/api/messages/create)，认证、版本和工作区要求依据 [API 概览](https://platform.claude.com/docs/en/api/overview)。本例固定 `2026-10-21`，不把模型标识与 API 版本混为一谈。完整运行入口为 [claude_function_call_demo.py](../scripts/claude_function_call_demo.py)；默认只运行离线检查，显式启用真实调用时还需可用模型、凭据及相应权限。

此前 CI 已检查图题、章节起始和稀疏尾页，但未把普通引导句与代码块作为一个整体核对，所以漏过这处分页。此次增加成品同页检查与拆页负例。之前版本检查随构建触发，长期没有提交就不运行；此次增加独立定时工作流。90 天到期测试使用固定日期，覆盖到期前一天、当天和逾期，避免测试随当前时间漂移。本地离线构建历史版本不强制刷新核验日期。

本地稳定编译仍为 220 页、41 章、57 图、71 表；新增同页门禁、既有章首与收尾密度、引用目的地、3213 条公式的 MathML 关联、全书灰度及色觉模拟检查均通过。人工抽查覆盖第 111 页请求说明、第 112–113 页衔接，以及第 218–220 页清单与收尾。

最终排版、链接、公式、灰度和 PDF/UA-2 验收以本次提交对应的 GitHub Actions 工件为准。

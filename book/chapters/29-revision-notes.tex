\subsubsection*{从可复算的例子开始}

\begin{itemize}[itemsep=1pt,parsep=0pt,topsep=3pt]
\item \textbf{三维 Transformer：}
运行 \texttt{python3 scripts/teaching\_reference.py --json}，
检查三个位置的概率、损失和一次联合参数更新。
\item \textbf{连续训练与自动求导：}以下命令各自运行：
\begin{verbatim}
python3 scripts/teaching_trace.py
python3 scripts/pytorch_starter.py
\end{verbatim}
前者打印第 0--20 步的损失与贪心预测（需要 NumPy）；后者用 PyTorch 自动求导复核同一模型的梯度和更新（需要 NumPy、PyTorch）。
\item \textbf{预训练数据去重：}
运行 \texttt{python3 scripts/pretraining\_data\_demo.py}，
核对小文本的规范化、SHA-256 哈希及二元组 Jaccard 相似度；只用 Python 标准库。
\item \textbf{测试时计算：}
运行 \texttt{python3 scripts/test\_time\_compute\_demo.py}，
枚举核对 Best-of-$n$ 的成功率、候选相关性、错误核验器与 $90\%$ 预算门槛；只用 Python 标准库。
\item \textbf{联想记忆：}
运行 \texttt{python3 scripts/memory\_demo.py}，
检查外积写入、串扰、Delta 残差与交替重访。
\item \textbf{Tokenizer、检索与工具：}三项实验各自运行：
\begin{verbatim}
python3 scripts/bpe_demo.py
python3 scripts/rag_demo.py
python3 scripts/agent_loop.py
\end{verbatim}
\item \textbf{现代架构与视觉：}以下命令各自运行：
\begin{verbatim}
python3 scripts/config_table.py
python3 scripts/architecture_demo.py
python3 scripts/vision_bridge_demo.py
\end{verbatim}
架构缓存与视觉桥接数据是独立教学设定。
\item \textbf{综合练习数值：}
运行 \texttt{python3 scripts/review\_exercises\_demo.py}，
核对 C-021、C-028、C-084、C-095、C-031、C-096 的中间计算。
\item \texttt{python3 scripts/context\_contrast\_demo.py}：相同 Token、相同位置、不同前文的消融训练，比较逐位置损失下界与上下文读取。
\item \texttt{python3 scripts/attention\_selection\_demo.py}：相同均值、不同记录绑定的四例训练，核对 Q/K 选择性、恢复均匀后的退化与梯度。
\item \texttt{python3 scripts/mini\_transformer\_demo.py}：二维分数参数的完整前向与反向，有限差分核对全部 $24$ 个导数。
\item \texttt{python3 scripts/cache\_budget\_demo.py}：从固定配置计算每 Token 与 32K 的 KV 字节数，同时核对缓存练习答案。
\end{itemize}

\subsubsection*{真实 GPT-2：运行方式与实测来源}

\texttt{python3 scripts/gpt2\_demo.py}
不加载权重时复核概率公式。安装兼容的 \texttt{torch} 和 \texttt{transformers} 后，
用 \texttt{--real} 加载固定版本的 GPT-2 small，核对 Token、logits 与概率。

\texttt{--local-files-only} 仅读本地缓存，安装 Matplotlib 后可用
\texttt{--heatmap} 保存注意力图。复现时保留输入、权重修订和环境信息。

正文中的 GPT-2 small 实测示例来自
\href{https://github.com/CoCoThink/ai-by-intuition/actions/runs/39897932969}{GitHub Actions 运行记录 \#39897932969}，
对应源码短 SHA \texttt{a20a0c15}。
Token ID、Top-5 及首层注意力热图以该记录的环境、Prompt 与权重修订为准；
本书 99 参数网络另属教学设定。

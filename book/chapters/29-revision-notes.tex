\subsection{版本、勘误与复算入口}
\phantomsection\label{app:revision-notes}

本书将可手算的\textbf{教学小模型}和可以运行的\textbf{真实公开模型}
分开标注。复算时首先核对输入、矩阵形状、计算规则，
再根据所使用的模型确认版本和依赖。

\subsubsection*{从可复算的例子开始}

\begin{itemize}
\item \textbf{三维 Transformer：}
运行 \texttt{python3 scripts/teaching\_reference.py --json}，
检查三个位置的概率、损失和一次联合参数更新。
\item \textbf{联想记忆：}
运行 \texttt{python3 scripts/memory\_demo.py}，
检查外积写入、串扰、Delta 残差与交替重访。
\item \textbf{Tokenizer、检索与工具：}三项实验各自运行：
\begin{verbatim}
python3 scripts/bpe_demo.py
python3 scripts/rag_demo.py
python3 scripts/agent_loop.py
\end{verbatim}
\item \textbf{现代架构与视觉：}以下命令各自运行：
\begin{verbatim}
python3 scripts/config_table.py
python3 scripts/architecture_demo.py
python3 scripts/vision_bridge_demo.py
\end{verbatim}
架构缓存与视觉桥接数据是独立教学设定。
\end{itemize}

\subsubsection*{与真实 GPT-2 比较}

\texttt{python3 scripts/gpt2\_demo.py}
可在不加载模型的情况下复核概率公式；
安装兼容的 \texttt{torch} 和 \texttt{transformers} 后，
使用 \texttt{--real} 加载固定版本的公开 GPT-2 small，
检查 Token、logits、候选概率与温度变化。
增加 \texttt{--local-files-only} 可仅从本地缓存读取权重与分词器；
\texttt{--heatmap} 可在安装 Matplotlib 后保存注意力图。
结果随输入文本和实际运行环境而变化，建议保留输出的版本信息。

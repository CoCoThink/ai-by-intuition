\subsection{动手层：用 PyTorch 自动求导复现 99 参数主模型}
\label{app:pytorch-lab}

读过三维算例后，可以在电脑上用教学脚本核对
\textbf{同一套初值、同一组 Token、一次全参数更新}。
\texttt{scripts/pytorch\_starter.py} 从本书的唯一参数表
\texttt{teaching\_reference.parameters()} 读取数值，
再用 PyTorch 的自动求导实现与 NumPy 手工反传相同的运算。

\textbf{运行环境：}Python 3.10+、NumPy、PyTorch（在本地安装所选兼容版本）。
在仓库根目录执行：
\begin{verbatim}
python3 -m pip install numpy torch
python3 scripts/pytorch_starter.py
\end{verbatim}
不方便在本地安装时，可以在
\href{https://colab.research.google.com/github/CoCoThink/ai-by-intuition/blob/main/notebooks/pytorch_starter.ipynb}{在线 Colab 教学 Notebook}
执行同一套脚本；必须允许 Notebook 读取公开仓库代码，不需要连接任何私有数据。

\textbf{预期标准输出：}
\begin{verbatim}
Loss: 1.798430 -> 1.611377
Shape: (3, 5) Parameters: 99
\end{verbatim}

\textbf{自动求导关键步骤（节选）：}
\begin{verbatim}
loss_before, z_before = forward()
loss_before.backward()
with torch.no_grad():
    for value in weights.values():
        value -= LR * value.grad
        value.grad.zero_()
loss_after, z_after = forward()
\end{verbatim}
这里展示梯度的收集与同步更新；模型初始化、因果 Attention、
两次 LayerNorm、FFN 和断言保留在
\href{https://github.com/CoCoThink/ai-by-intuition/blob/main/scripts/pytorch_starter.py}{仓库完整可运行脚本}，避免纸质版印出数十行维护性代码。

脚本采用双精度以便与 NumPy 手算基线按容差对齐。观察代码时请检查：
\texttt{E[ids - 1]} 是三行查表，
\texttt{triu} 保证因果掩码，
\texttt{cross\_entropy} 使用 \texttt{targets - 1} 并对三行取平均，
\texttt{backward} 将梯度送回所有可训练矩阵，
最后一次性更新全部九组参数。
每次重新运行都从同一份初值开始。

\textbf{把 ID 与数组下标逐项对齐。}
五项词表依次是“其他、春天、。、花、开了”，输入 ID 是 $[2,4,5]$，
目标 ID 是 $[4,5,3]$；代码中仅在索引时转换为 $[1,3,4]$ 与 $[3,4,2]$。
因此 \texttt{probs[0,3]} 是第一位置预测“花”（ID 4）的概率，
而 \texttt{probs[1,4]} 是第二位置预测“开了”（ID 5）的概率。
\begin{verbatim}
python3 scripts/teaching_reference.py --json
\end{verbatim}
参考实现同时核对语义、首尾 ID 查表、目标列及梯度；本例第一位置正确类概率
从 $0.261653$ 升至 $0.326865$，第二位置从 $0.050747$ 升至 $0.068548$。

PyTorch 自动求导与 NumPy 手工反传是\textbf{两种独立实现途径}；跨硬件和 Torch 版本时，浮点结果按数值容差比较。


\subsection{参数计数小练习}

沿用上述脚本的模型：$E:5\times3$、$P:3\times3$，
四组 $3\times3$ Attention 投影、两组 $3\times4$ 和 $4\times3$ FFN 矩阵、
一个 $3\times5$ 输出头。忽略固定 LayerNorm 与中间激活，
手算可训练元素个数，再对照\hyperref[eq:toy-99-parameters]{正文参数总数公式}。
作为延伸：若输出头与 $E$ 共享权重，
需要明确转置的形状，以及哪些原有参数不再独立存储；
不能在不改结构的情况下简单从总数扣除 15。

\section{分类损失：预测错了哪一类，怎样调整分数？}
\label{intro:20c-classification-loss}
\chaptercompass{怎样把 logits 变成概率？}{Softmax 将一行候选分数归一化，交叉熵度量目标类别概率。}{$z:1\times C\to p:1\times C\to L:1\times1$}{Softmax 与交叉熵没有自身可训练参数；上游输出头的权重可学习}
\modelpipelinefocus{6}{词表 Softmax 与交叉熵}

预测下一 Token 是一个\textbf{多类别预测}问题：
模型要为词表里的每个候选 ID 打分，据此比较下一 Token 的候选。
回归问题可以用均方误差（MSE）；这里先算适用于类别概率的交叉熵，
再研究 Embedding 和网络怎样产生这些分数。

\subsection{先给每一类一个分数：Logits}
\phantomsection\label{concept:logits}

假设只有三类，模型输出
\[
\vect z=(0,\log 2,0)\quad(1\times3).
\]
这三个数称为 \textbf{logits（未归一化分数）}，
是实数分数；经过 Softmax 才得到概率。
输出维度为类别数：三分类有三个 logits；
本书五项词表的下一 Token 预测则有五个 logits。
二分类可以采用两个 logits，也可以采用一个 logit 加 Sigmoid，
两种参数化方式都常见。

\subsection{Softmax：把分数变成一份概率}
\phantomsection\label{concept:softmax}

对每个类别 $j$ 计算
\begin{equation}
\boxed{p_j=\frac{e^{z_j}}{\sum_{k=1}^{C}e^{z_k}}}\qquad
(C=\text{类别数}).
\label{eq:early-class-softmax}
\end{equation}
在三分类例子中，指数为 $(1,2,1)$，因此
\[
\vect p=(1/4,1/2,1/4),\qquad
\sum_jp_j=1.
\]
\input{figures/softmax-prob-bars}

Softmax 只在\textbf{类别维度}上归一化；后面 Attention
也会用同一运算把匹配分数变成读取权重，不过那里归一化的是可见 Key，
不是词表候选类别。


\begin{example}[breakable=false]
\noindent\emph{数值稳定的 Softmax：先减最大 logit}\par
面对 logits $(1000,1001)$，直接计算 $e^{1000}$ 容易溢出。
令 $m=\max_jz_j=1001$，统一减去 $m$：
\[
\frac{(e^{1000-1001},e^{1001-1001})}
{e^{1000-1001}+e^{1001-1001}}
=\frac{(e^{-1},1)}{e^{-1}+1}
\approx(0.2689,0.7311).
\]
分子分母同时除以 $e^m$ 不改变概率，
却避免计算巨大的指数。这也是 Attention 每一行 Softmax 的基础技巧。
\end{example}

\subsection{交叉熵：正确类的概率越小，惩罚越大}
\phantomsection\label{concept:cross-entropy}

若真实标签为第二类，用 One-hot 向量
$\vect y=(0,1,0)$ 表示，则单样本\textbf{交叉熵}为
\begin{equation}
\boxed{L=-\sum_{j=1}^{C}y_j\log p_j=-\log p_{\rm correct}.}
\label{eq:early-class-cross-entropy}
\end{equation}
本例 $L=-\log(1/2)=\log2\approx0.6931$。
假如正确类概率只有 $1/4$，损失就会上升为
$\log4\approx1.3863$。
这里用自然对数，$p_j>0$ 由 Softmax 保证；
实现时直接使用稳定的 logits 交叉熵运算，
以避免先求极小概率再取对数的数值误差。

\subsection{\texorpdfstring{为什么从 logits 反传得到 $p-y$？}{为什么从 logits 反传得到 p 减 y？}}
\phantomsection\label{concept:logit-gradient}

把 Softmax 代入交叉熵，可改写为
\[
L=-z_{\rm correct}+\log\!\left(\sum_k e^{z_k}\right).
\]
对任意第 $j$ 项 logit 求偏导：
\[
\frac{\partial L}{\partial z_j}
=-y_j+\frac{e^{z_j}}{\sum_k e^{z_k}}
=\boxed{p_j-y_j}.
\]
因此三分类例子的梯度是
\[
\nabla_{\vect z}L=(1/4,-1/2,1/4).
\]
正确类的梯度为负，梯度下降会倾向于提高它的 logit；
另外两项为正，会倾向于降低它们。
对 $N$ 个等权位置的\textbf{平均交叉熵}，
每个位置的这项梯度还要除以 $N$。
这正是后面三个 Token 位置联合训练时出现 $1/3$ 的原因。

\begin{warningbox}
“输出维度等于类别数”适用于这里的多类分类输出头，
不是所有任务都必须改写成分类；连续数值预测等任务可以使用其他输出与损失。
\end{warningbox}

\chapterchecktasks{20c-classification-loss}{正文基础三题}{
\item \textbf{辨析：}三类 logits 为 $(2,-1,0)$。为什么它们不是合法概率，Softmax 要满足哪些条件？
\item \textbf{手算：}三分类概率 $(1/4,1/2,1/4)$，正确类为第二类。求交叉熵以及正确类 logit 的梯度。
\item \textbf{预测：}标签固定不变时，正确类概率从 $0.2$ 升到 $0.4$，交叉熵的变化方向是什么？
}
\chapterrecallanswer{logits 经 Softmax 才是概率；正确类交叉熵为 $-\log p_y$，梯度采用 one-hot 标签。}



\begin{conclusion}
分类任务先输出 logits，再用 Softmax 得到概率，
用交叉熵衡量正确类概率的高低；logit 梯度为 $p-y$。
接下来要问：Token ID 如何变成神经网络可学习的输入？
\end{conclusion}

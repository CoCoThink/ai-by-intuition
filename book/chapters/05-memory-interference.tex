\subsection{多条记忆：为什么会互相干扰？}
\phantomsection\label{intro:05-memory-interference}
\phantomsection\label{concept:memory-interference}
对 $M$ 条行向量 Key--Value 配对，最直接的写入是外积累加：
\begin{equation}
\boxed{S=\sum_{i=1}^{M}k_i^\top v_i},
\qquad
\boxed{xS=\sum_{i=1}^{M}(xk_i^\top)v_i}.
\end{equation}
这里 $S:d_k\times d_v$，$x:1\times d_k$，读取输出仍是一行。

\subsubsection{两条记忆的二维例子}
\[
k_A=(1,0),\quad v_A=(1,0),\qquad
k_B=(0.6,0.8),\quad v_B=(0,1).
\]
写入矩阵分别是
\[
k_A^\top v_A=\begin{bmatrix}1&0\\0&0\end{bmatrix},
\qquad
k_B^\top v_B=\begin{bmatrix}0&0.6\\0&0.8\end{bmatrix}.
\]
因此
\[
\boxed{S_{\rm simple}=\begin{bmatrix}1&0.6\\0&0.8\end{bmatrix}}.
\]
查询 A：
\[
k_A S_{\rm simple}
=(1,0)\begin{bmatrix}1&0.6\\0&0.8\end{bmatrix}
=\boxed{(1,0.6)}
=\underbrace{(1,0)}_{\text{正确信号}}
+\underbrace{(0,0.6)}_{\text{来自 B 的串扰}}.
\]
B 被激活，是因为 $k_Ak_B^\top=0.6$ 不为零；
两条 Key 虽然都是单位长度，却不垂直。

\begin{example}
一行乘矩阵时，第一项是 $1\cdot1+0\cdot0=1$，
第二项是 $1\cdot0.6+0\cdot0.8=0.6$。
\textbf{数值结果与原列向量算例相同，但存储矩阵转置了。}
\end{example}

对单位行向量 Key $k_j$，通常有
\[
k_jS=v_j+\sum_{i\ne j}(k_jk_i^\top)v_i.
\]
其他 Key 的匹配分数不为零时，就会产生干扰。

\chapterchecktasks{04-key-value-outer-product}{形状／手算／预测／找错}{
\item \textbf{形状：}行向量 Key $k:1\times2$、Value $v:1\times3$。外积写入 $S=k^\top v$ 的形状是什么？查询 $q:1\times2$ 后 $qS$ 又是什么形状？
\item \textbf{手算：}$k=(1,0),v=(0,1)$，写出矩阵 $S=k^\top v$，再用 $q=(1,0)$ 读取。
\item \textbf{预测：}同一条记忆若把 Key 写入时改为 $k'=(0.5,0)$，再以 $q=k'$ 读取，恢复的 Value 是多少倍？
\item \textbf{找错：}同学把 $S$ 写成 $vk^\top$，仍称它是按行向量约定可供 $qS$ 查询的状态。说明为何形状或方向不匹配。
}
\chapterrecallanswer{行向量 Key 的外积写入方向是 $k^\top v$；查询 $qS$ 得到 Value 空间的一行。}

\chapterchecktasks{05-memory-interference}{解释／手算／预测／方案}{
\item \textbf{解释：}两条记忆各写入 $k_i^\top v_i$，为什么用 $k_A$ 读取时可能含有 $v_B$ 的一部分？指出交叉项。
\item \textbf{手算：}$k_A=(1,0),k_B=(0.6,0.8)$；$v_A=(1,0),v_B=(0,1)$。把两条外积相加，用 $k_A$ 查询得到什么？
\item \textbf{预测：}若把 $k_B$ 改为 $(0,1)$，保持其他项不变，$k_A$ 查询时串扰如何变化？
\item \textbf{方案：}比较让 Key 更接近正交、写入时按残差修正，以及读出时提高选择性的三条方向；它们分别在哪一步处理问题？
}
\chapterrecallanswer{串扰来自非正交 Key 的交叉匹配项；可在 Key、写入规则或读取权重上减少影响。}



\begin{conclusion}
减少串扰可从两边入手：\textbf{写入时消除已知误差}，
或者\textbf{读取时更有选择性}。
\end{conclusion}

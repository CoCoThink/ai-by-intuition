\modelpipelinefocus{3}{非线性记忆检索}


上一章的线性读取让所有非零匹配都参与输出。
现在让权重随匹配强弱非线性变化。

\subsection{为什么平方可能提高选择性？}
若相似度处于 $[0,1]$，则
\[
1^2=1,\quad0.6^2=0.36;\qquad
1^3=1,\quad0.6^3=0.216.
\]
弱相似度被进一步压低。为了避免负分数平方后变正，
可以先取 ReLU 再平方：$\sigma(s)=\relu(s)^2$。
但如果 $s>1$，幂次也可能放大它；
不能把这一招写成对所有输入都保证可靠的机制。

\subsection{用同一套行向量写出 MLP}
令每条 Key 和 Value 都占一行：
\[
f(x)=\sum_i\sigma(xk_i^\top)v_i
=\boxed{\sigma(xK^\top)V}.
\]
与两层 MLP 的计算
$\sigma(xW_1)W_2$ 对照：
第一层的列可扮演匹配模板，第二层的行可扮演输出模板；
偏置在这里只为突出结构而省略。
这种理解是一种\textbf{计算视角}，并不意味着每个神经元存一条独立事实。

\begin{idea}
MLP 的参数在训练中更新；Attention 的 Key/Value 往往由当前上下文生成。
两者可以共享“匹配—选择—读出”的数学描述，
但并非同一种记忆存储实现。
\end{idea}

\chapterchecktasks{09-nonlinearity-and-memory}{预测／手算／找错／比较}{
\item \textbf{预测：}当相似度在 $[0,1]$ 内时，提高幂次会怎样影响严格小于 $1$ 的匹配？恰为 $1$ 的匹配呢？
\item \textbf{手算：}分别算 $0.5^2$、$0.5^3$，再算 $(-0.5)^2$、$(-0.5)^3$。
\item \textbf{找错：}同学说“平方任何相似度都只会压小错误匹配，包括负值”。用上题反例指出问题。
\item \textbf{比较：}把 MLP 解释成“Key 匹配、Value 读取”有什么直觉收益？为什么不能据此宣称神经元一对一存储真实事实？
}
\chapterrecallanswer{非线性改变匹配的选择性，但必须说明分数范围；MLP 的记忆类比是计算视角而非事实库存证明。}



\begin{conclusion}
非线性筛选改变匹配权重，MLP 与联想记忆因此存在计算形式上的联系，
而非对真实知识如何存储的直接证明。
\end{conclusion}

\section{怎样量“猜得多差”？损失与一次直接求解}
\label{intro:16-loss-gradient}
\chaptercompass{怎样衡量同一组预测错得多远？}{平方误差汇成损失，简单二次式还可以直接求最小值。}{三个 $(x_i,y_i)$ 输入 $\to L(w,b)$ 输出}{$w,b$ 是待优化参数}
\modelpipelinefocus{0}{损失与解析解}



\subsection{预测值、真实值与均方误差}
\phantomsection\label{concept:loss}

对三点 $(-1,-1),(0,1),(1,3)$，取模型
$\widehat y=wx+b$。均方误差（MSE）为
\begin{equation}
\boxed{L(w,b)=\frac13\sum_{i=1}^{3}(\widehat y_i-y_i)^2.}
\label{eq:three-point-mse}
\end{equation}
平方使正负误差不会抵消，较大的误差也受到更大惩罚。
从初值 $w=1,b=0$ 出发，三项预测为 $(-1,0,1)$，
与真实结果 $(-1,1,3)$ 比较，残差是 $(0,-1,-2)$：
\[
L(1,0)=\frac{0^2+(-1)^2+(-2)^2}{3}=\boxed{\frac53}.
\]
三个点恰好位于直线 $y=2x+1$ 上。
把各项残差展开后，可把\textbf{同一损失函数}写成
\begin{equation}
\boxed{L(w,b)=\frac23(w-2)^2+(b-1)^2.}
\label{eq:three-point-loss-surface}
\end{equation}
可见理论最优参数是 $(w,b)=(2,1)$，此时训练损失为 $0$。

\Needspace{24\baselineskip}
\subsection{先固定一个参数：解析解能做什么？}

先固定 $b=1$，只调整 $w$；这不是另一套训练样本，
而是沿同一个二维损失曲面的 $b=1$ 截面：
\[
L(w,1)=\frac23(w-2)^2,\qquad
\frac{\mathrm dL(w,1)}{\mathrm dw}=\frac43(w-2).
\]
令导数为零，可直接解出 $w=2$，因此找到全局最小值。
为什么复杂神经网络不总这么做？
多层非线性网络的所有参数通常不能通过一个简单方程组直接解出，
而且导数为零并不总是全局最小值。
我们需要能从当前位置逐步改善损失的方法。

\chapterchecktasks{16-loss-analytic}{解释／手算／找错／预测}{
\item \textbf{解释：}三点线性拟合的 MSE 为什么是三个平方误差的平均，而不是把带符号误差相加？
\chapterinlinehint{16-loss-analytic}{1}
\item \textbf{手算：}固定 $b=1$ 且 $L(w,1)=\frac23(w-2)^2$，分别算 $w=2$ 与 $w=3$ 时的损失。
\chapterinlinehint{16-loss-analytic}{2}
\item \textbf{找错：}有人说“$w=2$ 后损失就一定为零，$b$ 可以随便取”。用完整的 $L(w,b)=\frac23(w-2)^2+(b-1)^2$ 订正。
\chapterinlinehint{16-loss-analytic}{3}
\item \textbf{预测：}从 $w=3$ 向 $w=2$ 移动一点而 $b=1$ 不变，损失初期会增大还是减小？根据平方项说明理由。
\chapterinlinehint{16-loss-analytic}{4}
}
\chapterrecallanswer{平方误差不会正负抵消；完整损失同时由斜率误差和偏置误差决定。}



\begin{conclusion}
同一份三点数据使我们得到一个具体的损失曲面；
简单二次损失可以直接求最优值，但复杂模型通常要用迭代优化。
\end{conclusion}

\section{当解析解不现实时：梯度下降怎样调参数？}
\label{intro:16a-gradient-descent}
\chaptercompass{不知道解析解时怎样移动参数？}{沿负梯度方向，以学习率控制每一步的更新。}{$(w,b),\nabla L,\eta\to(w',b')$}{$w,b$ 同步更新}
\modelpipelinefocus{0}{梯度下降与参数更新}

上节已通过固定 $b=1$ 直接求出最优斜率。
现在先练习一个参数的迭代更新，再回到真正需要同时更新的 $(w,b)$。

\subsection{导数告诉我们局部变化方向}

\noindent\emph{数学随手查：}导数表示函数在某个位置的局部变化率，相关符号见\hyperref[app:math-tools]{数学速查}。

当 $b=1$ 时，$L(w,1)=\frac23(w-2)^2$；
在 $w=1$ 的导数为 $-4/3$，意味着增大 $w$ 有望降低损失。
导数的严格定义为
\[
\frac{\mathrm dL}{\mathrm dw}
=\lim_{\varepsilon\to0}
\frac{L(w+\varepsilon)-L(w)}{\varepsilon}.
\]
这里表示保持 $b$ 不变，只比较斜率的微小变化。

\subsection{梯度下降：向梯度反方向更新}
\phantomsection\label{concept:gradient-descent}

采用学习率 $\eta=0.3$，固定 $b=1$，
根据 $\mathrm dL/\mathrm dw=\frac43(w-2)$ 更新：
\begin{equation}
\boxed{w_{\rm new}=w_{\rm old}-\eta\frac{\mathrm dL}{\mathrm dw}.}
\label{eq:gradient-simple}
\end{equation}
从 $w_0=1$ 开始，第一步为
\[
w_1=1-0.3(-4/3)=1.4,
\qquad L(w_1,1)=0.24.
\]
第二步的导数为 $\frac43(1.4-2)=-0.8$，
于是 $w_2=1.64$、$L(w_2,1)=0.0864$。
固定偏置的这条截面上，损失从 $2/3$ 降为 $0.24$，再降为 $0.0864$。

\subsection{两个参数同时调整：偏导数与梯度}
\phantomsection\label{concept:gradient}

固定 $b$ 的做法帮助我们练习了导数，但实际拟合要调整\textbf{两个参数}。
偏导数在求某一个参数的变化率时，把其他参数视为常数。
对同一个三点损失函数：
\[
\nabla L(w,b)=
\left(\frac{\partial L}{\partial w},\frac{\partial L}{\partial b}\right)
=\left(\frac43(w-2),2(b-1)\right).
\]
仍从本书最初选择的 $(w,b)=(1,0)$ 出发，
而不是上面固定 $b=1$ 的一维练习：
\[
L(1,0)=\frac53,\qquad
\nabla L(1,0)=\boxed{\left(-\frac43,-2\right)}.
\]
学习率同样取 $\eta=0.3$，\textbf{两个参数用同一组旧梯度一起更新}：
\[
(w',b')=(1,0)-0.3(-4/3,-2)=\boxed{(1.4,0.6)}.
\]
新预测为 $(-0.8,0.6,2.0)$，三个误差为 $(0.2,-0.4,-1)$，
因此
\[
L(1.4,0.6)
=\frac{0.2^2+(-0.4)^2+(-1)^2}{3}
=\boxed{0.4}<\frac53.
\]
这样就从单参数的调节，扩展到了\textbf{同时更新 $w$、$b$} 的训练。

\begin{warningbox}
梯度指出局部下降方向，不保证任意学习率都使损失下降，
也不能保证复杂非凸网络找到全局最优；学习率太大可能震荡或发散。
\end{warningbox}

\subsection{一次训练要做哪四件事？}
\begin{enumerate}
\item \textbf{前向传播}：用当前参数计算 $\widehat y$。
\item \textbf{计算损失}：比较预测 $\widehat y$ 与真实目标 $y$。
\item \textbf{求梯度}：在同一旧参数状态下求各项偏导数。
\item \textbf{更新参数}：统一执行 $\theta\leftarrow\theta-\eta\nabla_\theta L$。
\end{enumerate}

\section{把语言练习变成一道可计算的预测题}
\label{intro:20b-task-contract}

下一 Token 预测把已有文本变成训练答案，把新 Token 接回输入又能继续生成。
现在把这个任务写成一份\textbf{任务契约（Task Contract）}：
先确定输入、目标、输出形状和计分方式。\phantomsection\label{concept:task-contract}
模型结构随后遵守这份约定。

\subsection{贯穿全书的小例子}

沿用五项教学词表：$1=\text{其他}$、$2=\text{春天}$、
$3=\text{。}$、$4=\text{花}$、$5=\text{开了}$。
本次句子使用其中四个 Token“春天／花／开了／。”，编号为
\[
(t_1,t_2,t_3,t_4)=(2,4,5,3).
\]
在实际模型中，Token 的单位包括单字、词的一部分和标点。

我们希望读到“春天”时能预测“花”，
读到“春天、花”时能预测“开了”。
因此把一段数据\textbf{错开一个位置}：输入取完整序列的前三项，
目标取后三项。换句话说，目标就是输入\textbf{整体左移一位}（去掉首项，末尾接上下一 Token）：
\[
\underbrace{[2,\ 4,\ 5]}_{\text{输入 Token}}
\quad\longrightarrow\quad
\underbrace{[4,\ 5,\ 3]}_{\text{对应的下一 Token}}.
\]
第一行用“春天”预测“花”，第二行用“春天、花”预测“开了”，第三行预测句号。
输入查表成为三行向量，目标 ID 指出每行应该提高哪一列的概率。
分类交叉熵已给出计分公式；下面把输入、预测概率和目标接起来，再确定每个位置可以利用哪些输入。

\subsection{从输入到损失：先看预测任务}

词表的 $5$ 个 Token 各用 $3$ 维向量表示，Embedding 表为 $5\times3$。
三个输入 ID 经过查表，成为一个 $3\times3$ 的向量矩阵，每个位置一行。
模型根据这些输入，为每个位置计算五个候选 Token 的分数，
组成一个 $3\times5$ 的 logits 矩阵；再逐行通过 Softmax 得到同样形状的概率矩阵 $\Pi$。

图中把从输入 ID 到预测概率的计算统称为\textbf{预测模型}，
其内部结构将在后续章节逐步展开。
本章先确定它接收什么、输出什么，以及怎样衡量预测的好坏。

训练时，交叉熵读取每行目标 Token 对应的概率，计算三个位置的平均损失。
本例依次读取第一行“花”、第二行“开了”、第三行“。”的概率。
再通过反向传播，更新 Embedding 和模型中的其他可学习参数。

\subsection{每个位置能看到哪些输入？}

预测下一 Token 时，每个位置可以利用\textbf{当前位置及之前}的输入。
同一段训练数据因此对应三种可见范围：

\begin{center}
\small
\tagpdfsetup{table/header-rows={1}}
\begin{tabularx}{\linewidth}{@{}p{22mm}Xp{28mm}@{}}
\toprule
预测位置 & 该位置可以利用的输入 & 对应目标\\
\midrule
1 & 春天 & 花\\
2 & 春天、花 & 开了\\
3 & 春天、花、开了 & 。\\
\bottomrule
\end{tabularx}
\end{center}

训练文本虽然已经给出了完整序列，每个位置做预测时仍要遵守这条规则。
例如，第一位置要预测“花”，若计算预测时已经读到了第二位置的“花”，
就提前看到了答案，造成\textbf{信息泄漏}。
目标应当参与损失计算；预测模型怎样利用允许读取的前文，将从下一部分逐步展开。

\chapterchecktasks{20b-task-contract}{理解与复算}{
\item \textbf{对齐：}完整序列 $[2,4,5,3]$，采用三个输入位置 $[2,4,5]$。列出逐位置的三个下一 Token 目标。\chapterinlinehint{把完整序列整体左移一位（去掉首项），对齐三个位置。}
\item \textbf{形状：}词表大小为 $5$，批内这条示例的三个位置各输出五类分数。把 logits 组织成矩阵后是什么形状？\chapterinlinehint{一条位置对应一行，类别数对应列数。}
\item \textbf{找错：}同学让第一个位置直接读取第二个位置的“花”，再预测第一个位置的下一 Token。哪里发生信息泄漏？\chapterinlinehint{先写出第一个位置的目标，再检查它是否已出现在预测所用的输入中。}

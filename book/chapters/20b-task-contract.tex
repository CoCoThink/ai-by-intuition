\modelpipelinefocus{0}{训练样本与目标}

下一 Token 预测把已有文本变成训练答案，把新 Token 接回输入又能继续生成。
现在把这个任务写成一份\textbf{任务契约（Task Contract）}：
先确定输入、目标、输出形状和计分方式。\phantomsection\label{concept:task-contract}
模型结构随后遵守这份约定。

\subsection{贯穿全书的小例子}

沿用五项教学词表：$1=\text{其他}$、$2=\text{春天}$、
$3=\text{。}$、$4=\text{花}$、$5=\text{开了}$。
本次句子使用其中四个 Token“春天／花／开了／。”，编号为
\[
(t_1,t_2,t_3,t_4)=(2,4,5,3).
\]
在实际模型中，Token 的单位包括单字、词的一部分和标点。

我们希望读到“春天”时能预测“花”，
读到“春天、花”时能预测“开了”。
因此把一段数据\textbf{错开一个位置}：输入取完整序列的前三项，
目标取后三项。换句话说，目标就是输入\textbf{整体左移一位}（去掉首项，末尾接上下一 Token）：
\[
\underbrace{[2,\ 4,\ 5]}_{\text{输入 Token}}
\quad\longrightarrow\quad
\underbrace{[4,\ 5,\ 3]}_{\text{对应的下一 Token}}.
\]
第一行用“春天”预测“花”，第二行用“春天、花”预测“开了”，第三行预测句号。
输入查表成为三行向量，目标 ID 指出每行应该提高哪一列的概率。
分类交叉熵已给出计分公式；接下来还要建立上下文读取和因果可见性。

\subsection{先看全图：Attention 是网络内部的上下文读取步骤}

先看整套\textbf{可训练网络}：ID 查表后，Attention 读取此前可见的 Token，
逐位置 FFN 变换特征，输出头给词表候选打分。
训练时用右侧的目标计算损失，反向更新前面各组共享参数。

\subsection{先约定输入，再约定预测的输出}

\textbf{输入：}词表的 $5$ 个 Token 各用 $3$ 维向量表示，Embedding 表为 $5\times3$。
三个输入查表后组成 $3\times3$ 矩阵，每个位置一行。
\textbf{输出：}每行给 $5$ 个候选打分，三位置的 logits 合为 $3\times5$，逐行转成概率。

\chapterchecktasks{20b-task-contract}{正文基础三题}{
\item \textbf{对齐：}完整序列 $[2,4,5,3]$，采用三个输入位置 $[2,4,5]$。列出逐位置的三个下一 Token 目标。\chapterinlinehint{把完整序列整体左移一位（去掉首项），对齐三个位置。}
\item \textbf{形状：}词表大小为 $5$，批内这条示例的三个位置各输出五类分数。把 logits 组织成矩阵后是什么形状？\chapterinlinehint{一条位置对应一行，类别数对应列数。}
\item \textbf{找错：}同学让第一个位置通过 Attention 直接看见第二个位置的正确答案，再计算第一个位置的预测损失。哪里发生信息泄漏？\chapterinlinehint{画出目标 Token 流向第一个位置的路径。}
}
\chapterrecallanswer{下一 Token 的目标是完整序列整体左移一位（去掉首项）；因果掩码禁止当前位置读取未来输入。}



\begin{conclusion}
输入 $[2,4,5]$，目标 $[4,5,3]$；每位置输出五类分数，交叉熵读取目标列。
下一部分比较 RNN 与 Attention 怎样把前文送给当前位置。
\end{conclusion}

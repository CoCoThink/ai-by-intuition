\section{Attention 是什么？让一个词直接读取其他位置}
\phantomsection\label{concept:attention}
\label{intro:21b-why-attention}
\chaptercompass{为什么需要把提问、匹配与读取分成三种角色？}{Q 问问题，K 负责匹配，V 提供被读取的内容。}{$X:T\times d_{\rm model}\to Q,K,V\to Y:T\times d_v$}{$W_Q,W_K,W_V$}
\modelpipelinefocus{3}{Attention}

\begin{idea}
\noindent\emph{按相关性读取上下文}\par

Attention（注意力）是一种按相关性读取信息的方法：
当前这个位置先对\textbf{可读取的每个位置}算一个匹配分数，
再把这些分数变成\textbf{权重}，
最后把各位置提供的信息按权重\textbf{加起来}。

它最核心的三个动作就是
\textbf{比较 $\to$ 分配权重 $\to$ 加权读取}。
\end{idea}

\subsection{从逐步传递到直接读取}

前面介绍的 \conceptlink{rnn}{RNN} 让模型按顺序读：
\[
\text{春天}\ \longrightarrow\
\text{花}\ \longrightarrow\
\text{开了}.
\]
RNN 的第 3 步能读到\textbf{上一份状态} $h_2$，
但如果想重点利用第 1 个词的信息，
它必须依赖这份状态此前是否保留了相关内容。

现在试想另一种设计：当我们读到第三个词“开了”时，
不必只能通过 $h_2$ 间接获得过去的信息；
让第三个位置直接查看前三个位置，各自决定读多少。

\input{figures/attention-rnn-bridge}
图中，位置 3 可以直接读取位置 1、2、3 的信息，
不同位置的读取比例可以不同。接下来要解决的，就是怎样算出这些比例。

\subsection{从平均读取到按需读取}

设当前位置可以读取三个位置，它们各自提供一条\textbf{内容向量}：
\[
\vect v_1=\begin{bmatrix}1\\0\end{bmatrix},\quad
\vect v_2=\begin{bmatrix}0\\1\end{bmatrix},\quad
\vect v_3=\begin{bmatrix}1\\1\end{bmatrix}.
\]
最简单的方法是把它们\textbf{平均}：
\[
\vect y_{\rm avg}
=\frac13(\vect v_1+\vect v_2+\vect v_3)
=\begin{bmatrix}2/3\\2/3\end{bmatrix}.
\]
但无论当前位置想查找什么，只要内容不变，
平均结果就不变。它没有考虑当前的查找需要。

不妨先给三条内容分配权重 $a_1,a_2,a_3$，
且规定权重非负、总和为 $1$：
\begin{equation}
\boxed{\vect y=a_1\vect v_1+a_2\vect v_2+a_3\vect v_3,\qquad
a_i\ge0,\quad \sum_{i=1}^3 a_i=1.}
\label{eq:attention-design-goal}
\end{equation}
平均对应 $a_1=a_2=a_3=1/3$。
要让读取结果随着当前位置的需要而变化，就得让权重取决于当前查询与各个位置的匹配程度。

因此，一次按需读取分为两步：先比较\textbf{当前想找什么}与\textbf{各位置有哪些匹配特征}，算出权重；
再用权重组合各位置提供的内容。
这三种角色分别称为 Query（查询）、Key（键）和 Value（值）。


上章已经验证了零参数点积能产生注意力权重，
也看到原始分数对称性与向量范数的限制。
下面开始拆开 Q、K、V 三种角色。

\subsection{Query、Key、Value 各负责什么？}
\phantomsection\label{concept:qkv}

在点积 Attention 中，三者分工明确：
\begin{itemize}
\item \textbf{Query（查询，记作 $\vect q$）：}
当前这个位置\textbf{拿什么条件来查}？它用于发起匹配。
\item \textbf{Key（键，记作 $\vect k_i$）：}
第 $i$ 个位置\textbf{凭什么被找到}？它与 Query 比较，
产生一个\textbf{匹配分数}。
\item \textbf{Value（内容，记作 $\vect v_i$）：}
第 $i$ 个位置\textbf{被找到后交出什么}？
它不是匹配分数，而是最终\textbf{被加权相加}的向量。
\end{itemize}

\begin{center}\QKVlegend\end{center}
Query 和 Key 用来计算权重，Value 则是按权重组合的内容。

\input{figures/attention-why-qkv}

\textbf{Q、K、V 是三种角色。}在 Self-Attention 中，
第 3 个 Token 一方面能发出自己的 Query，
另一方面也像其他位置一样提供 Key 和 Value。
每个位置原本有一条输入表示 $\vect x_i$，
在真实网络中可以经过\textbf{不同的可训练投影}，得到
\[
\vect q_i^\top=\vect x_i^\top W_Q,\qquad
\vect k_i^\top=\vect x_i^\top W_K,\qquad
\vect v_i^\top=\vect x_i^\top W_V.
\]
这里约定每个 Token 的输入 $\vect x_i^\top$ 是\textbf{行向量}，
$W_Q:d_{\rm model}\times d_k$。若改写为列向量，
必须把权重也转置：$\vect q_i=W_Q^\top\vect x_i$，
而不是仍写 $W_Q\vect x_i$。
三组投影参数都可以通过训练学习。

为什么区分这三种向量？因为\textbf{用于判断相关性的特征}与\textbf{希望读出的内容}可以不同，
Value 的维度也不必等于 Key 的维度。
独立投影让网络能分别学习匹配和读出的表示；简化模型也可以让部分投影相同。

打个类比：查资料时，问题像 Query，索引像 Key，正文内容像 Value。

先看\textbf{一次查询}：
位置 3 发出 Query，分别与位置 1、2、3 的 Key 匹配，
得到三条权重，再从这三个位置的 Value 读取内容。

\subsection{匹配：独立投影让分数不再对称}

\localfixture{二维 Q/K/V，与上一章使用同一组 X；此处未缩放、未加因果 Mask}
沿用三个 Token“春天、花、开了”的行向量：
\[
X=\begin{bmatrix}1&0\\0&1\\1&1\end{bmatrix},\qquad
W_Q=I_2,\qquad
W_K=\begin{bmatrix}1&0\\1&1\end{bmatrix},\qquad W_V=I_2.
\]
这组权重只是\textbf{为了观察分工而设定的例子}，实际训练可学习不同的投影。
矩阵乘法得到
\[
Q=XW_Q=X,\quad
K=XW_K=\begin{bmatrix}1&0\\1&1\\2&1\end{bmatrix},\quad
V=XW_V=X.
\]
Key 的三行现在是 $(1,0)$、$(1,1)$、$(2,1)$；得分矩阵 $S$ 的尺寸为 $3\times3$，
它们已经不再与输入向量逐行相同。
将所有 Query 的点积合成矩阵：
\begin{equation}
S=QK^\top
=\boxed{\begin{bmatrix}1&1&2\\0&1&1\\1&2&3\end{bmatrix}}.
\label{eq:asymmetric-qk-example}
\end{equation}
\textbf{对照前一章：}原始 $XX^\top$ 必定对称，
而此处 $S_{12}=\boxed{1}$、$S_{21}=\boxed{0}$。
“春天”查询“花”与“花”查询“春天”的匹配分数可以不同；
这正是\textbf{拆开 Query 和 Key 的新增表达能力}。
逐行 Softmax 之后权重一般也不对称，但不能反过来用
Softmax 权重不对称来证明原始点积分数不对称。

\subsection{分配：以第三个位置为 Query 计算权重}

当前第三行 Query 是 $\vect q^\top=(1,1)$，
与三个 Key 的分数是 $(1,2,3)$：
\[
\vect a^\top=\softmax(1,2,3)
=\frac{(e,e^2,e^3)}{e+e^2+e^3}
\approx\boxed{(0.090,0.245,0.665)}.
\]
若是 Decoder-only 模型的第三个位置，三个 Key 均在可见前缀；
第一、二位置还应通过因果 Mask 排除各自的未来位置。
本节使用\textbf{未缩放}的原始点积以便比较投影；
标准缩放点积还会除以 $\sqrt{d_k}$。

\subsection{读出：Value 与 Key 分开设计}

由于 $W_V=I_2$，三行 Value 仍是
$(1,0)$、$(0,1)$、$(1,1)$。
\begin{example}
\[
\vect y^\top=\vect a^\top V
\approx(0.090,0.245,0.665)
\begin{bmatrix}1&0\\0&1\\1&1\end{bmatrix}
=\boxed{(0.755,0.910)}.
\]
这与上一章未投影时的 $(0.788,0.788)$ 不同：
\textbf{输入和 Value 没变，只改变 Key 的投影就改变了读取内容的比例。}
\end{example}

如果只把第一行 Value 改成 $(0,2)$，
分数和权重完全不变，输出则约为
$(0.665,\;0.090\times2+0.245+0.665)=(0.665,1.090)$。
所以 Key 决定匹配、Value 决定取出的内容，
两者的作用可以分别核对。

\subsection{Attention 与 RNN 怎样传递信息？}

\begin{center}
\small

\tagpdfsetup{table/header-rows={1}}
\begin{tabularx}{\linewidth}{@{}p{33mm}XX@{}}
\toprule
比较的问题 & RNN & 本章的 Attention\\
\midrule
当前位置怎样利用前文？ & 接收上一时刻传来的状态 & 直接对多个候选位置匹配和读取\\
输出是什么？ & 更新后的状态向量 & 多条 Value 的加权组合向量\\

回到主线，需要把两条规则放进模型：\textbf{因果 Mask}
让当前位置只读取已经可见的 Token；序列变长时，
注意力的匹配与缓存也要支付相应成本。
本章先算一个 Query，下章把所有行的 Softmax 和 Value 读取合成矩阵运算。

\chapterchecktasks{21b-why-attention}{正文基础三题}{
\item \textbf{定位：}一句话说明 Query、Key、Value 三者在“计算匹配／提供内容”中的分工，并标出分数和读出的形状：$q:1\times2,K:3\times2,V:3\times2$。\chapterinlinehint{分别追踪分数路径与内容加权路径。}
\item \textbf{手算：}只有两个 Value 为 $(1,0),(0,1)$，权重为 $(0.2,0.8)$，求加权读出。\chapterinlinehint{把每个 Value 乘其权重，再逐分量相加。}
\item \textbf{找错：}同学说“保持 Q、K 不变，修改第三条 Value 后，每条原始匹配分数必定改变”。指出混淆了哪两个路径。\chapterinlinehint{写出分数公式，检查其中是否出现 Value。}
}
\chapterrecallanswer{Q/K 决定匹配，V 决定被读取的内容；改变 Value 不直接改动 Q/K 的原始分数。}



\begin{conclusion}
先记住\textbf{为什么}：
要按当前需要读取前文，就得决定“读谁多少”和“取出什么”。
在本书使用的点积 Attention 中，
Query 和 Key 产生相关性分数，Softmax 分配比例，
Value 是真正加权求和的内容。

你已经亲手得到：三个候选位置 $\to$ 三个点积分数
$\to$ 三个权重 $\to$ 一条输出向量。
下一章唯一要新增的，是如何把同一运算更高效地组织成矩阵。
\end{conclusion}

\section*{阅读路线与学习时间}
\phantomsection\label{front:reading-routes}

本书围绕同一条主线：先学参数怎样被训练，
再把数字扩展为向量和矩阵，之后让 Token 读取上下文、
预测下一 Token，最后分清模型与外部系统的能力。
不必在第一次阅读时记住所有矩阵元素。

\textbf{三条阅读路线：}
\begin{itemize}
\item \textbf{速读：}先看每部分的“从这里出发”、章首问题与章末小结，
  浏览形状流程图和三个位置的预测结果；公式只看输入、输出及含义。
\item \textbf{标准：}依 I--VIII 的顺序阅读正文，亲手完成标量损失、
  双参数梯度更新、三分类交叉熵以及注意力的一次手算。
\item \textbf{动手：}完成标准路线后再做附录 C 的练习，
  使用 PyTorch 单步实验和交互 Notebook 的三个滑块观察参数或概率变化。
\end{itemize}

\subsection*{数学预备：开书前的四个小测试}
试算 $2(3)+1=7$，$(-2)^2=4$，
$\log(e^2)=2$，以及当 $z=wx+b,\ L=z^2/2$ 时
$\partial L/\partial w=zx$。
如果对数或最后一步不熟悉，可以先继续阅读，在梯度一章补上链式法则。
\textbf{“高中代数可起步”并不表示后文完全不用求导与对数。}

\textbf{现在就算第一题：}由三个样本 $(1,3),(2,5),(3,7)$ 猜测
$\widehat y=wx+b$，取 $w=2,b=1$，分别得到 $3,5,7$。
对新输入 $x=4$，得到预测 $\widehat y=9$；
这一步是代入计算，接下来才学习怎样从损失自动调整参数。

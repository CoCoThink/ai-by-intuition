\section*{阅读路线、学习时间与版本说明}
\phantomsection\label{front:reading-routes}

本书围绕同一条主线：先学参数怎样被训练，
再把数字扩展为向量和矩阵，之后让 Token 读取上下文、
预测下一 Token，最后分清模型与外部系统的能力。
不必在第一次阅读时记住所有矩阵元素。

\textbf{三条阅读路线：}
\begin{itemize}
\item \textbf{速读：}先看每部分的“从这里出发”、章首问题与章末小结，
  浏览形状流程图和三个位置的预测结果；公式只看输入、输出及含义。
\item \textbf{标准：}依 I--VII 的顺序阅读正文，亲手完成标量损失、
  双参数梯度更新、三分类交叉熵以及注意力的一次手算。
\item \textbf{动手：}完成标准路线后再做附录 B，
  使用 PyTorch 单步实验和三个交互 Notebook 观察参数或概率变化。
\end{itemize}

\textbf{七个必读部分各解决什么问题？}下列时间是
\textbf{第一次阅读正文的粗略参考}，
不包含独立练习，随数学背景、阅读速度与复算深度而变化。

\textbf{统一的向量约定：}I--VII 的矩阵主线让
\textbf{一个样本或一个 Token 占一行}，
即 $\vect x^\top:1\times d$，
$X:T\times d$，
前向投影写成 $XW$。
选读的联想记忆专题采用
\textbf{列向量} $\vect x:d\times1$；
同一线性映射换视角时必须转置权重，
并非网络改变了数学含义。
若看不清形状，返回第二部分的矩阵乘法章节。

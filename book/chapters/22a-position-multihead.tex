\subsection{交换两个 Token：统一三维参数为什么需要位置？}

取“春天、花”的两行 Embedding，再交换行得到 $X' $：
\[
X=\begin{bmatrix}1.2&0&-0.2\\-0.3&1.1&0.2\end{bmatrix}
\in\R^{2\times3},\qquad
X'=\begin{bmatrix}-0.3&1.1&0.2\\1.2&0&-0.2\end{bmatrix}.
\]
固定主例的 $W_Q,W_K,W_V$，暂不加位置、因果掩码、Norm 与残差：
\[
W_Q=\begin{bmatrix}.8&.2&-.1\\.1&.9&.25\\-.1&.15&.8\end{bmatrix},\quad
W_K=\begin{bmatrix}.85&0&.2\\-.1&.9&0\\.15&.2&.75\end{bmatrix},\quad
W_V=\begin{bmatrix}1&.2&0\\0&.9&.15\\.1&-.2&.85\end{bmatrix}.
\]
这些仍是三维主线的初始参数，仅在本次对照中固定不更新。
先展开第一行的 Query 投影：
\[
Q_{1,:}=(1.2,0,-0.2)W_Q=(0.98,0.21,-0.28),
\]
例如首项为 $1.2\times0.8+0\times0.1+(-0.2)\times(-0.1)=0.98$。
同法算得 $K_{1,:}=(0.99,-0.04,0.09)$、$K_{2,:}=(-0.335,1.03,0.09)$，
所以第一行缩放分数约为 $(0.5407,-0.0792)$，
Softmax 权重约为 $(0.6502,0.3498)$。
两行 Value 为 $(1.18,0.28,-0.17)$、$(-0.28,0.89,0.335)$；
第一行读出就是它们按上述权重的加权和，首项约为
$0.6502\times1.18+0.3498\times(-0.28)=0.6693$。
按同样步骤计算全部两行，得到
\[
O(X)=\softmax\left(\frac{(XW_Q)(XW_K)^\top}{\sqrt3}\right)XW_V
\approx\begin{bmatrix}
0.6693&0.4934&0.0066\\0.2019&0.6886&0.1683
\end{bmatrix}.
\]
交换输入两行，输出也只换行：这就是行置换的\textbf{等变性}，未加 Mask 时没有额外的顺序信号。
加上因果掩码后，位置 $i$ 只能看到前 $i$ 个 Token，各位置可见前缀长短不同，
这带来一点隐含的顺序线索；显式的位置向量则直接把“第几位”写进每一行。
现代模型常用的旋转位置表示（RoPE）见第~\ref*{intro:22d-modern-transformers}~章。

\subsection{加入位置绑定的向量，再观察交换后的区别}
取主例位置表的前两行，绑定位置而不随 Token 交换；该表在训练中可学习：
\[
{P_{\rm pos}}_{1:2}=\begin{bmatrix}
0.10&0.05&-0.10\\0&-0.05&0.12
\end{bmatrix},\quad
X_+=X+{P_{\rm pos}}_{1:2},\quad X'_+=X'+{P_{\rm pos}}_{1:2}.
\]
例如交换前第一行是 $(1.30,0.05,-0.30)$，交换后第一行变成
$(-0.20,1.15,0.10)$：第一位置仍加同一条位置向量，Token 内容则变了。
同一组 Q/K/V 投影得到：
\begin{equation}
O(X_+)\approx\begin{bmatrix}
0.7680&0.5138&-0.0265\\0.2324&0.6726&0.2092
\end{bmatrix},\qquad
O(X'_+)\approx\begin{bmatrix}
0.2812&0.7145&0.1440\\0.6956&0.4854&0.0441
\end{bmatrix}.
\label{eq:pos-swap-d3}
\end{equation}
第一坐标 $0.2812\ne0.2324$：输出不再只是换行。位置表提供了独立于内容的顺序信号。
完整自回归 Block 还会接回因果掩码、Norm 与残差。

\subsection{\texorpdfstring{为什么点积要除以 $\sqrt{d_k}$？算一次波动尺度}{为什么点积要除以 Key 维度平方根？}}
\label{concept:scaled-dot-product}

Q/K 各维独立、等概率取 $\pm1$ 时，点积均值为 $0$、方差为 $d_k$，
标准差为 $\sqrt{d_k}$（见\hyperref[app:variance-scaling]{数学速查中的四结果算例}）。
分数 $(8,0)$ 的第一项概率为 $e^8/(e^8+1)\approx0.9997$；
当 $d_k=64$，$\sqrt{64}=8$，除以 $8$ 后分数变成 $(1,0)$，概率为 $e/(e+1)\approx0.731$。
缩放控制的是典型分数的量级，并未规定分数的上限。
若分数差仍很大，权重仍会接近 $0/1$，此时对分数的小变化不敏感（称为饱和）。

\subsection{两个头各算二维，再拼接：数字完整走一遍}
\phantomsection\label{concept:multihead}

一个头为当前 Query 算出一份读取权重，并用这同一份权重加权各个 Value 特征。
如果我们想分别保留两种关系的读取结果，例如一份偏向当前动作、另一份偏向动作的主体，怎么办？
可以让同一输入经过不同的投影，各算一份权重与读出，再把结果并排保留。
这样的每条读取分支叫一个\textbf{注意力头}，多条一起使用就是\textbf{多头注意力}。
各头具体学到什么由训练决定；下面只用数字展示两份权重怎样重点读取不同位置。

\localfixture{四维双头；两个位置，与主线三维参数无关；圆括号元组均为行向量}
令模型宽度 $4$、每头宽度 $2$，序列有两个位置。
最后位置的输入经投影得到一条 $1\times4$ 的 Query 行
$\vect x^\top W_Q=(0,1,1,0)$，再\textbf{按列切成两段}：
前两列给头 1，后两列给头 2，即
$\vect q^{(1)\top}=(0,1)$、$\vect q^{(2)\top}=(1,0)$。
Key 矩阵 $XW_K:2\times4$ 也按同样的列切分，本例两段都恰为 $I_2$；
Value 两段分别为
\[
V^{(1)}=\begin{bmatrix}2&0\\0&2\end{bmatrix},
\qquad
V^{(2)}=\begin{bmatrix}0&1\\1&0\end{bmatrix}.
\]
按“点积 $\to$ 除以 $\sqrt2$ $\to$ Softmax $\to$ 加权 Value”逐头计算，
输出以未舍入的权重求和后保留三位小数：
\[
\begin{aligned}
\vect s^{(1)\top}&=(0,1)/\sqrt2,&
\vect a^{(1)\top}&\approx(0.330,0.670),&
\vect o^{(1)\top}&\approx(0.660,1.340),\\
\vect s^{(2)\top}&=(1,0)/\sqrt2,&
\vect a^{(2)\top}&\approx(0.670,0.330),&
\vect o^{(2)\top}&\approx(0.330,0.670).
\end{aligned}
\]
头 1 把 $0.670$ 的权重放在位置 2，头 2 则把 $0.670$ 放在位置 1：
\textbf{同一个位置的 Query 在两个子空间里重点读取了不同位置。}
沿\textbf{特征列}拼接，得到
$O_{\rm cat}\approx(0.660,1.340,0.330,0.670):1\times4$。
再取演示投影
\[
W_O=\begin{bmatrix}1&0&1&0\\0&1&0&1\end{bmatrix}^{\top},
\qquad O_{\rm cat}W_O\approx(0.991,2.009):1\times2.
\]
这里同样先用未舍入的读出相乘，最后再保留三位小数；
若直接相加上面已舍入的数字，会得到 $(0.990,2.010)$。
\textbf{多头拼接各头读出的特征，再投影到目标宽度。}
这里用 $4\times2$ 演示投影；完整四维残差 Block 的输出投影则应为 $4\times4$。

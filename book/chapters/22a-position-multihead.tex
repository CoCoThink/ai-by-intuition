\section{位置编码、缩放与多头注意力的手算}
\label{intro:22a-position-multihead}

\subsection{交换两个 Token：统一三维参数为什么需要位置？}

前面已经确定唯一三维 Embedding。为了比较顺序，
这里只拿两个已出现的 Token“春天、花”：
\[
X=\begin{bmatrix}1.2&0&-0.2\\-0.3&1.1&0.2\end{bmatrix}
\in\R^{2\times3},\qquad
X'=\begin{bmatrix}-0.3&1.1&0.2\\1.2&0&-0.2\end{bmatrix}.
\]
保持与统一教学参考脚本相同的 $W_Q,W_K,W_V$，先做\textbf{无位置、
无因果 Mask} 的一次双向 Attention。这里只隔离位置对比，
暂不执行 LayerNorm 与残差：
\[
O(X)=\softmax\left(\frac{(XW_Q)(XW_K)^\top}{\sqrt3}\right)XW_V
\approx\begin{bmatrix}
0.6693&0.4934&0.0066\\0.2019&0.6886&0.1683
\end{bmatrix}.
\]
因为没有任何位置相关信号，输入交换两行后，
输出也只是对应交换两行：
\[
O(X')\approx\begin{bmatrix}
0.2019&0.6886&0.1683\\0.6693&0.4934&0.0066
\end{bmatrix}.
\]
这说明不带位置的 Self-Attention 对行置换具有\textbf{等变性}：
换了输入行的次序，计算相应换行，并没有额外标记“原来在哪个位置”。

\subsection{加上固定位置向量，再观察交换后的区别}

位置向量取自贯通主实验的\textbf{前两行}，不因交换 Token 而移动：
\[
P_{1:2}=\begin{bmatrix}
0.10&0.05&-0.10\\0&-0.05&0.12
\end{bmatrix},\quad
X_+=X+P_{1:2},\quad X'_+=X'+P_{1:2}.
\]
仍用\textbf{相同的三组可训练投影}，只是输入加了位置信息：
\begin{equation}
\begin{aligned}
O(X_+)&\approx\begin{bmatrix}
0.7680&0.5138&-0.0265\\0.2324&0.6726&0.2092
\end{bmatrix},\\
O(X'_+)&\approx\begin{bmatrix}
0.2812&0.7145&0.1440\\0.6956&0.4854&0.0441
\end{bmatrix}.
\end{aligned}
\label{eq:pos-swap-d3}
\end{equation}
注意交换后的第一行\textbf{并不}等于交换前的第二行：
例如第一坐标分别为 $0.2812$ 和 $0.2324$。
位置向量提供了独立于内容的位置信号。
两种顺序下的输出也没有退化成两行完全相同。

\begin{warningbox}
为明确考察位置信号，这里\textbf{暂不加因果掩码}，
也暂不做完整 Pre-Norm Block 的 LayerNorm 和残差。
它是取自统一参数的\textbf{位置消融实验}，不是下一章完整自回归生成的前向输出。
完整 Block 会使用每行 Norm 和因果 Mask，两者不可混为一谈。
\end{warningbox}

\subsection{为什么点积要除以 $\sqrt{d_k}$？算一次波动尺度}
\phantomsection\label{concept:scaled-dot-product}

\noindent\emph{数学随手查：}这里的方差与标准差衡量随机数围绕平均值波动的大小。互相独立的零均值随机量相加时，方差相加而标准差取平方根；如需先复习求和与平方根，可返回\hyperref[app:math-tools]{数学速查}。


假设两个 Key/Query 向量的每一维都是\textbf{独立、等概率取 $\pm1$}
的随机变量，且维度之间也独立。
每个分量乘积平均为 $0$、方差为 $1$。
$d_k$ 个分量求和，点积的方差为 $d_k$，
标准差为 $\sqrt{d_k}$；当 $d_k=64$ 时约为 $8$。

比如两个候选的未缩放分数恰好是 $(8,0)$，
Softmax 第一项为
$\frac{e^8}{e^8+1}\approx0.9997$，
另一项几乎为零。除以 $\sqrt{64}=8$ 后，
分数变成 $(1,0)$，第一项变成
$\frac e{e+1}\approx0.731$。
缩放能防止高维点积的典型量级随着维度扩大而直接变得很尖锐；
这不是保证所有 Attention 都不会饱和的定理。

\subsection{两个头各算二维，再拼接：数字完整走一遍}
\phantomsection\label{concept:multihead}

\textbf{下面切换到独立的 $d_{\rm model}=4$ 双头形状例}，每个头宽度为 2。
这个例子不是将三维主实验强行分成两个 1.5 维的头。
考虑最后一个 Token 可以查看两个位置，
每个头的 $Q,K,V$ 都有二维特征。
为简化计算，直接给定两个注意力头\textbf{各自投影得到的数值}；


两个头使用不同的最后位置 Query 是有意设计的：头 1 为 $(0,1)$，头 2 为 $(1,0)$，让它们偏向不同位置。第一头让 $Q^{(1)}=K^{(1)}=I_2$，
$V^{(1)}=\begin{bmatrix}2&0\\0&2\end{bmatrix}$。
最后一行 Softmax 的权重为 $(0.330,0.670)$，因此
\[
\vect o^{(1)\top}
=(0.330,0.670)V^{(1)}
=\boxed{(0.660,1.340)}.
\]
第二头选最后位置的 Query 为 $(1,0)$、
两条 Key 为 $(1,0)$ 与 $(0,1)$，
并给出
$V^{(2)}=\begin{bmatrix}0&1\\1&0\end{bmatrix}$。
其最后位置的注意力权重变为 $(0.670,0.330)$，
于是
\[
\vect o^{(2)\top}
=(0.670,0.330)V^{(2)}
=\boxed{(0.330,0.670)}.
\]
沿特征列拼接而非沿 Token 行拼接：
\[
O_{\rm cat}=(0.660,1.340,0.330,0.670)
\quad(1\times4).
\]
取一个演示用输出投影
$W_O=\begin{bmatrix}1&0\\0&1\\1&0\\0&1\end{bmatrix}$，
得到
\[
O_{\rm cat}W_O=(0.990,2.010)\quad(1\times2).
\]
所以\textbf{多头不是把概率相加}：
每个头先读出自己的 Value 向量，
拼成更宽的特征，再使用 $W_O$ 投影回模型宽度。

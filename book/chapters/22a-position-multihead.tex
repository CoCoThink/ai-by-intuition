\section{位置编码与多头注意力：不用跳过的两次手算}
\label{intro:22a-position-multihead}

\subsection{如果交换“春天”和“花”，没有位置的 Attention 会怎样？}

沿用前面 Embedding 表的数值：
“春天”的向量为 $\vect x_{\text{春天}}^\top=(1,0)$，
“花”的向量为 $\vect x_{\text{花}}^\top=(0,1)$。
忽略位置，按行堆成 $X=\begin{bmatrix}1&0\\0&1\end{bmatrix}$，
让 $Q=K=V=X$，两个 Token 可以互相读取：
\[
A=\softmax\!\left(\frac{XX^\top}{\sqrt2}\right)
\approx\begin{bmatrix}0.670&0.330\\0.330&0.670\end{bmatrix},
\qquad
O=AX\approx\begin{bmatrix}0.670&0.330\\0.330&0.670\end{bmatrix}.
\]
如果交换输入的两行，计算结果也只是\textbf{相应交换两行}：
对一条固定 Token 内容来说，没有得到“在第一位还是第二位”的信息。
一般地，任何置换矩阵 $\Pi$ 都满足
$\operatorname{Attention}(\Pi X)=\Pi\operatorname{Attention}(X)$
（本例不使用因果掩码或位置偏置）。

\subsection{加入最简单的两行位置向量，再算一次}

这里仅演示\textbf{加性位置编码}，人为选
\[
P=\begin{bmatrix}1&0\\0&1\end{bmatrix},\qquad X_+=X+P.
\]
顺序为“春天、花”时，
$X_+=\begin{bmatrix}2&0\\0&2\end{bmatrix}$。
两个 Token 的自匹配分数为 $4/\sqrt2\approx2.828$，
交叉匹配是 $0$，第一行权重约 $(0.944,0.056)$，
所以第一行读取结果约为 $(1.888,0.112)$。

交换成“花、春天”后，保持位置向量\textbf{不随内容交换}：
\[
X'=\begin{bmatrix}0&1\\1&0\end{bmatrix},\quad
X'_+=X'+P=\begin{bmatrix}1&1\\1&1\end{bmatrix}.
\]
两行分数相同，各分得 $(0.5,0.5)$，
两行输出都是 $(1,1)$。
\textbf{此时输出不再只是原结果交换两行：位置已经影响了计算。}
示例选择的向量纯为演算方便，真实位置编码不要求使用单位矩阵。

\begin{warningbox}
因果掩码本身也携带了“谁可看谁”的方向约束。
上面的交换实验刻意使用\textbf{无掩码双向 Attention}，
是为单独观察位置表示的作用，不是说真实 Decoder-only 模型没有顺序信息。
\end{warningbox}

\subsection{为什么点积要除以 $\sqrt{d_k}$？算一次波动尺度}

假设两个 Key/Query 向量的每一维都是\textbf{独立、等概率取 $\pm1$}
的随机变量，且维度之间也独立。
每个分量乘积平均为 $0$、方差为 $1$。
$d_k$ 个分量求和，点积的方差为 $d_k$，
标准差为 $\sqrt{d_k}$；当 $d_k=64$ 时约为 $8$。

比如两个候选的未缩放分数恰好是 $(8,0)$，
Softmax 第一项为
$\frac{e^8}{e^8+1}\approx0.9997$，
另一项几乎为零。除以 $\sqrt{64}=8$ 后，
分数变成 $(1,0)$，第一项变成
$\frac e{e+1}\approx0.731$。
\textbf{缩放能防止高维点积的典型量级随着维度扩大而直接变得很尖锐}；
这不是保证所有 Attention 都不会饱和的定理。

\subsection{两个头各算二维，再拼接：数字完整走一遍}
\phantomsection\label{concept:multihead}

考虑最后一个 Token 可以查看两个位置，
每个头的 $Q,K,V$ 都有二维特征。
为简化计算，直接给定两个注意力头\textbf{各自投影得到的数值}；
它们并非由本例训练得出。

第一头让 $Q^{(1)}=K^{(1)}=I_2$，
$V^{(1)}=\begin{bmatrix}2&0\\0&2\end{bmatrix}$。
最后一行 Softmax 的权重为 $(0.330,0.670)$，因此
\[
\vect o^{(1)\top}
=(0.330,0.670)V^{(1)}
=\boxed{(0.660,1.340)}.
\]
第二头选最后位置的 Query 为 $(1,0)$、
两条 Key 为 $(1,0)$ 与 $(0,1)$，
并给出
$V^{(2)}=\begin{bmatrix}0&1\\1&0\end{bmatrix}$。
其最后位置的注意力权重变为 $(0.670,0.330)$，
于是
\[
\vect o^{(2)\top}
=(0.670,0.330)V^{(2)}
=\boxed{(0.330,0.670)}.
\]
沿特征列拼接而非沿 Token 行拼接：
\[
O_{\rm cat}=(0.660,1.340,0.330,0.670)
\quad(1\times4).
\]
取一个演示用输出投影
$W_O=\begin{bmatrix}1&0\\0&1\\1&0\\0&1\end{bmatrix}$，
得到
\[
O_{\rm cat}W_O=(0.990,2.010)\quad(1\times2).
\]
所以\textbf{多头不是把概率相加}：
每个头先读出自己的 Value 向量，
拼成更宽的特征，再使用 $W_O$ 投影回模型宽度。

\begin{conclusion}
两种问题需要不同设计：\textbf{位置信息}区分内容位于何处；
\textbf{多头}让模型在不同表示子空间执行多次可学习读取。
掌握上面的形状与数字后，接下来才把这些输出接进完整 Block。
\end{conclusion}

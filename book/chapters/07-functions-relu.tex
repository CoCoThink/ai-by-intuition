\section{非线性：为什么多叠两层直线仍不够？}
\label{intro:07-functions-relu}
\chaptercompass{为什么两层直线还不够？}{纯线性层能合并，ReLU 才带来分段非线性。}{$x\to h=\relu(w_1x+b_1)\to\widehat y$}{$w_1,b_1,w_2,b_2$}
\modelpipelinefocus{0}{非线性激活}

一个可调的线性函数只能画直线。目标关系如果带折角或弯曲，
把两层线性函数叠起来会不会更灵活？先算一遍再看问题在哪里。

\subsection{先算两层纯线性}

令第一层 $h=w_1x$，第二层 $\widehat y=w_2h$，那么
\[
\widehat y=w_2(w_1x)=(w_1w_2)x.
\]
结果还是一条直线。即使每层有偏置，两次仿射变换合起来仍是仿射变换。
\textbf{层数本身并不会自动创造非线性。}

\subsection{插入一个折角：ReLU}

定义逐个作用于数值的\textbf{激活函数}：
\begin{equation}
\relu(t)=\max(0,t)=
\begin{cases}t,&t>0,\\0,&t\le0.\end{cases}
\end{equation}
例如 $\relu(-2)=0$，$\relu(1)=1$。
$\relu(1+(-2))=0$，但
$\relu(1)+\relu(-2)=1$，所以 ReLU 不是线性函数。

把它插到中间：
\[
z=w_1x+b_1,\qquad h=\relu(z),\qquad
\widehat y=w_2h+b_2.
\]
如果 $w_1=w_2=1$，两个偏置为 $0$，
输入 $-2$ 得到 $0$，输入 $1$ 得到 $1$。
这条分段折线不能用一条固定直线在所有输入上复现。

\begin{idea}
第一层组合输入，ReLU 让不同输入产生不同激活状态，
第二层把它们组合成预测。先理解标量版本，再学向量和矩阵版。
\end{idea}

\subsection{新缺口：前层参数如何影响最后的损失？}

现在修改 $w_1$，会依次改变 $z$、$h$、最终预测和损失。
如果每个参数都从头展开所有公式会很繁琐；
下一章将沿这条计算链复用局部变化率。

\begin{warningbox}
ReLU 在 $t=0$ 处不可导，训练实现通常约定一个次梯度。
本章只研究正负输入时的前向计算；下一章解释其求导。
\end{warningbox}

\chapterchecktasks{07-functions-relu}{比较／手算／预测／找错}{
\item \textbf{比较：}为什么两次无激活的仿射变换可以合并成一次？给出一维形式 $(ax+b)c+d$。
\item \textbf{手算：}$f(x)=\relu(2x-1)$。分别算 $x=0$ 与 $x=1$ 的输出。
\item \textbf{预测：}当 $2x-1$ 从负值跨到正值时，函数局部斜率如何改变？这个折角为什么有助于拟合分段规律？
\item \textbf{找错：}同学说“ReLU 把网络的权重随机置零，所以同样输入每次都会给出不同输出”。指出混淆的操作。
}
\chapterrecallanswer{纯仿射层可合并；ReLU 对负输入输出零，对正输入保持原值，带来分段表达能力。}



\begin{conclusion}
叠加纯线性函数不能产生非线性，插入 ReLU 可以。
下一章要解决如何让最终误差高效传回最前面的参数。
\end{conclusion}

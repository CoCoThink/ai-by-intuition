\localfixture{二维 Q/K/V；承接上一章的独立投影，未缩放、未加因果 Mask}
上一章使用 $W_Q=I_2$、$W_K=\begin{bmatrix}1&0\\1&1\end{bmatrix}$、
$W_V=I_2$ 得到了\textbf{不对称}的匹配分数。
这里保持同一套投影与输入，先复核最后一条 Query，
再\textbf{对所有行并行归一化和读取 Value}。
相比\hyperref[intro:21c-naive-attention]{更早的未投影例子}，
现在 Key 已经由独立的矩阵生成。

\subsection{先复核第三条 Query 的单次读取}
\[
K=\begin{bmatrix}1&0\\1&1\\2&1\end{bmatrix},\quad
V=\begin{bmatrix}1&0\\0&1\\1&1\end{bmatrix},\quad
\vect q^\top=(1,1).
\]
\begin{example}
\[
\begin{aligned}
\vect q^\top K^\top&=(1,2,3),\\
\vect a^\top&=\softmax(\vect q^\top K^\top)
\approx(0.090,0.245,0.665),\\
\vect y^\top&=\vect a^\top V=\boxed{(0.755,0.910).}
\end{aligned}
\]
\end{example}
Key 与 Value 均按位置逐行排列。将 $K$ 转置后，
Query 与三个 Key 的分数一次求出；下面同时计算全部 Query。

\subsection{\texorpdfstring{为什么是 $K^\top$ 而不是 $K$？}{为什么是 K 转置而不是 K？}}
\label{sec:key-layout-card}
\input{figures/key-value-layout}
$K:M\times d_k$，$\vect q^\top:1\times d_k$。
因此 $\vect q^\top K^\top:1\times M$ 才能相乘；
权重乘 $V:M\times d_v$ 才有输出 $1\times d_v$。
列向量写法是对\textbf{整个等式转置}，两种写法的运算相同。

\subsection{从一个 Query 到整句：Q/K/V 如何生成？}
主线把 Token 放在输入矩阵 $X:T\times d_{\rm model}$ 的每一行。
可训练投影：
\begin{equation}
\boxed{Q=XW_Q,\qquad K=XW_K,\qquad V=XW_V.}
\label{eq:qkv-from-x}
\end{equation}
\[
W_Q,W_K:d_{\rm model}\times d_k,\qquad
W_V:d_{\rm model}\times d_v.
\]
例如 $\vect x^\top=(2,3)$，
$W_Q=\begin{bmatrix}1&1\\0&2\end{bmatrix}$，
则 $\vect q^\top=\vect x^\top W_Q=(2,8)$。
如果用列向量写同一映射，必须写
$\vect q=W_Q^\top\vect x$；输入与权重需要一起转置。

若一次有 $N$ 个 Query 和 $M$ 个 Key，
$Q:N\times d_k$、$K:M\times d_k$、
$V:M\times d_v$；Self-Attention 中 $N=M=T$。
第 $i$ 行 Query 与每条 Key 依次匹配，
一次矩阵乘法即可完成全部 Query 的匹配：
\[
QK^\top=S.
\]

\subsection{\texorpdfstring{完整三行复算：$S\to A\to Y$}{完整三行复算：S 到 A 到 Y}}
\localfixture{承接上一章的三位置非对称 Q/K/V 数值例}
继续使用 $Q=X$、$K=XW_K$、$V=X$，
上一章得到的原始分数为（\textbf{未缩放、未加因果 Mask}）
\[
S=QK^\top=\begin{bmatrix}
1&1&2\\
0&1&1\\
1&2&3
\end{bmatrix}\quad(3\times3).
\]
Softmax 对\textbf{每行分别归一化}，各行和为 $1$：
\begin{equation}
\label{eq:three-query-attention-weights}
A=\operatorname{softmax}_{\rm row}(S)
\approx\boxed{\begin{bmatrix}
0.212&0.212&0.576\\
0.155&0.422&0.422\\
0.090&0.245&0.665
\end{bmatrix}}\quad(3\times3).
\end{equation}
然后一次完成全部 Value 读取：
\begin{equation}
\label{eq:three-query-attention-output}
Y=AV=
\begin{bmatrix}
0.212&0.212&0.576\\
0.155&0.422&0.422\\
0.090&0.245&0.665
\end{bmatrix}
\begin{bmatrix}1&0\\0&1\\1&1\end{bmatrix}
\approx\boxed{\begin{bmatrix}
0.788&0.788\\
0.578&0.845\\
0.755&0.910
\end{bmatrix}}\quad(3\times2).
\end{equation}
第二行的两项是 $a_{21}+a_{23}$ 与 $a_{22}+a_{23}$。
输出以\textbf{未舍入的权重}求和后保留三位小数；
直接相加表里舍入后的数字会出现约 $0.001$ 的误差。
第三行 $(0.755,0.910)$ 与上一章单 Query 的结果一致。
可在\hyperref[exercise:batch-attention-new]{附录 C 的 C2-21}更换分数矩阵，
独立复算三行 $A'$ 和 $Y'$。



\subsection{缩放点积 Attention 的通用式}
\begin{equation}
\boxed{\operatorname{Attention}(Q,K,V)
=\softmax\!\left(\frac{QK^\top}{\sqrt{d_k}}\right)V=AV.}
\label{eq:attention-transformer}
\end{equation}
\phantomsection\label{eq:multi-query-attention}
Softmax 对每个 Query 的一行单独归一化，输出 $N\times d_v$。
除以 $\sqrt{d_k}$ 用于控制高维点积分数的典型量级；
缩放会改变 Softmax 权重，因此需要根据新的分数重新计算。

\begin{example}
若权重为 $(0.75,0.25)$、两条 Value 是 $(2,0)$、$(0,4)$，
则读取结果为
$(0.75,0.25)\begin{bmatrix}2&0\\0&4\end{bmatrix}=(1.5,1)$。
\end{example}

\subsection{FFN 与 Attention 分别处理什么？}
$XW$ 对每个 Token 行做固定特征组合，
$\sigma(XW_1)W_2$ 对每个 Token 行再施加非线性；
$AV$ 则按当前 Q/K 的匹配结果\textbf{在 Token 行之间读取}。
语言预测还必须借助因果掩码阻止读取未来 Token。

\item \textbf{预测：}只把同一行中的第一个匹配分数增大，保持第二个不变，Softmax 第一权重变化方向是什么？两者都加同一个常数呢？
}
\chapterrecallanswer{矩阵 Attention 先算跨位置匹配 $QK^\top$，逐行归一化，再用权重读取 Value。}



\begin{conclusion}
现在你能从单次 Query 的点积与加权求和，直接写出
$QK^\top\to\softmax\to AV$，并核对 $N,M,d_k,d_v$ 的形状。
\end{conclusion}

\subsection{先复核第三条 Query 的单次读取}
\[
K=\begin{bmatrix}1&0\\1&1\\2&1\end{bmatrix},\quad
V=\begin{bmatrix}1&0\\0&1\\1&1\end{bmatrix},\quad
\vect q^\top=(1,1).
\]
\begin{example}
\[
\begin{aligned}
\vect q^\top K^\top&=(1,2,3),\\
\vect a^\top&=\softmax(\vect q^\top K^\top)
\approx(0.090,0.245,0.665),\\
\vect y^\top&=\vect a^\top V=\boxed{(0.755,0.910).}
\end{aligned}
\]
\end{example}
Key 与 Value 均按位置逐行排列。将 $K$ 转置后，
Query 与三个 Key 的分数一次求出；下面同时计算全部 Query。

\subsection{从一个 Query 到整句：Q/K/V 如何生成？}
主线把 Token 放在输入矩阵 $X:T\times d_{\rm model}$ 的每一行。
可训练投影：
\begin{equation}
\boxed{Q=XW_Q,\qquad K=XW_K,\qquad V=XW_V.}
\label{eq:qkv-from-x}
\end{equation}
\[
W_Q,W_K:d_{\rm model}\times d_k,\qquad
W_V:d_{\rm model}\times d_v.
\]
例如 $\vect x^\top=(2,3)$，
$W_Q=\begin{bmatrix}1&1\\0&2\end{bmatrix}$，
则 $\vect q^\top=\vect x^\top W_Q=(2,8)$。
这里沿用\sectionentry{sec:layout-matrix-card}的行向量约定。

若一次有 $T_q$ 个 Query 和 $T_k$ 个 Key，
$Q:T_q\times d_k$、$K:T_k\times d_k$、
$V:T_k\times d_v$；Self-Attention 中 $T_q=T_k=T$。
第 $i$ 行 Query 与每条 Key 依次匹配，
一次矩阵乘法即可完成全部 Query 的匹配：
\[
QK^\top=S.
\]

\begin{tabular}{@{}lll@{}}
\toprule
计算 & 输入形状 & 输出形状\\\midrule

\subsection{\texorpdfstring{完整三行复算：$S\to A\to Y$}{完整三行复算：S 到 A 到 Y}}
继续使用 $Q=X$、$K=XW_K$、$V=X$，
上一章得到的原始分数为（\textbf{未缩放、未加因果掩码}）
\[
S=QK^\top=\begin{bmatrix}
1&1&2\\
0&1&1\\
1&2&3
\end{bmatrix}\quad(3\times3).
\]
Softmax 对\textbf{每行分别归一化}，各行和为 $1$：
\begin{equation}
\label{eq:three-query-attention-weights}
A=\operatorname{softmax}_{\rm row}(S)
\approx\boxed{\begin{bmatrix}
0.212&0.212&0.576\\
0.155&0.422&0.422\\
0.090&0.245&0.665
\end{bmatrix}}\quad(3\times3).
\end{equation}
然后一次完成全部 Value 读取：
\begin{equation}
\label{eq:three-query-attention-output}
Y=AV=
\begin{bmatrix}
0.212&0.212&0.576\\
0.155&0.422&0.422\\
0.090&0.245&0.665
\end{bmatrix}
\begin{bmatrix}1&0\\0&1\\1&1\end{bmatrix}
\approx\boxed{\begin{bmatrix}
0.788&0.788\\
0.578&0.845\\
0.755&0.910
\end{bmatrix}}\quad(3\times2).
\end{equation}
第二行的两项是 $a_{21}+a_{23}$ 与 $a_{22}+a_{23}$。
输出以\textbf{未舍入的权重}求和后保留三位小数；
直接相加表里舍入后的数字会出现约 $0.001$ 的误差。
第三行 $(0.755,0.910)$ 与上一章单 Query 的结果一致。
可在\hyperref[exercise:batch-attention-new]{附录 C 的 C-049}（第~\pageref*{exercise:batch-attention-new}~页）更换分数矩阵，
独立复算三行 $A'$ 和 $Y'$。

\subsection{\texorpdfstring{因果 Self-Attention：位置 $i$ 只读位置 $1$ 到 $i$}{因果 Self-Attention：位置 i 只读位置 1 到 i}}
\phantomsection\label{concept:causal-mask}

\textbf{结论先行：}语言模型训练时，三个位置在同一次前向中一起计算，
而位置 $i$ 要预测的是第 $i+1$ 个 Token。
\textbf{因果掩码（Causal Mask）}让第 $i$ 行只读第 $1$ 到 $i$ 列，
每个位置只用自己及以前的内容。

继续使用上一节未缩放的 $S$ 和同一份 $V$。在 Softmax 之前，
把 $S$ 中 $j>i$ 的项（对角线以上）换成 $-\infty$：
\[
S_{\rm causal}=\begin{bmatrix}
1&-\infty&-\infty\\
0&1&-\infty\\
1&2&3
\end{bmatrix}.
\]
因为 $e^{-\infty}=0$，被遮住的位置权重恰为零，
其余可见项按原分数重新归一化：
\[
A_{\rm causal}=\softmax_{\rm row}(S_{\rm causal})
\approx\boxed{\begin{bmatrix}
1&0&0\\
0.269&0.731&0\\
0.090&0.245&0.665
\end{bmatrix}},
\]
\[
Y_{\rm causal}=A_{\rm causal}V
\approx\boxed{\begin{bmatrix}
1&0\\
0.269&0.731\\
0.755&0.910
\end{bmatrix}}.
\]
逐行核对：第一行只剩自己，读出就是 $\vect v_1^\top=(1,0)$；
第二行在前两项 $(0,1)$ 上归一化，$1/(1+e)\approx0.269$、$e/(1+e)\approx0.731$；
第三行三项都可见，与未加掩码 时相同，仍读出 $(0.755,0.910)$。
对照上一节，前两行的读出从 $(0.788,0.788)$、$(0.578,0.845)$
变成了只含前缀信息的结果。

\textbf{训练时为什么需要它？}以\hyperref[intro:20b-task-contract]{预测任务}的主线为例：
输入 $[2,4,5]$、目标 $[4,5,3]$，位置 1 的目标“花”正是位置 2 的输入。
第一行若能读到第二列，就能直接抄到答案，训练损失下降却没有学会预测；
生成时也没有未来 Token 可读。
因果掩码让一次前向同时为全部位置计分，又让每行只用前缀。
每行至少保留对角线上的自身，所以每行 Softmax 的分母都大于零，
沿用\hyperref[intro:20c-classification-loss]{分类损失章的减最大值技巧}，稳定实现只对\textbf{每行可见的分数}减去最大值。
若别的掩码（如填充位置）把某一行全部遮住，分母为零，需要实现另行处理。


\subsection{缩放点积 Attention 的通用式}
\begin{equation}
\boxed{\operatorname{Attention}(Q,K,V)
=\softmax\!\left(\frac{QK^\top}{\sqrt{d_k}}\right)V=AV.}
\label{eq:attention-transformer}
\end{equation}
\phantomsection\label{eq:multi-query-attention}
Softmax 对每个 Query 的一行单独归一化，输出 $T_q\times d_v$。
除以 $\sqrt{d_k}$ 用于控制高维点积分数的典型量级；
缩放会改变 Softmax 权重，因此需要根据新的分数重新计算。

\begin{example}
若权重为 $(0.75,0.25)$、两条 Value 是 $(2,0)$、$(0,4)$，
则读取结果为
$(0.75,0.25)\begin{bmatrix}2&0\\0&4\end{bmatrix}=(1.5,1)$。
\end{example}

\subsection{FFN 与 Attention 分别处理什么？}
$XW$ 对每个 Token 行做固定特征组合，
$\phi(XW_1)W_2$ 对每个 Token 行再施加非线性；
$AV$ 则按当前 Q/K 的匹配结果\textbf{在 Token 行之间读取}。
语言模型中的这次跨行读取还要配合上面的因果掩码，只读当前位置及以前的行。

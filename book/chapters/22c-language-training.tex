\section{三个位置一起训练：从交叉熵到共享参数更新}
\label{intro:22c-language-training}
\chaptercompass{三个位置怎样联合训练同一套参数？}{按三位置平均损失，沿完整计算图反传并统一更新。}{$P:3\times5\to L\to\nabla_\theta L$}{Embedding、位置、Q/K/V、FFN、输出头共同更新}

上一章已经用\textbf{同一组初始参数}得到三个位置的词表概率。
我们不再只挑最后一行、冻结所有前层参数反复调输出头；
现在要让整段数据在\textbf{一次前向和一次反向传播}中共同训练完整网络。

\subsection{错开一个位置：为什么能从文本自己得到标签？}
\phantomsection\label{concept:shifted-targets}

完整四个 Token 的 ID 是 $[1,3,4,2]$，
输入及对应目标错开一位：
\[
\underbrace{[1,3,4]}_{\text{输入位置 }1,2,3}
\quad\longrightarrow\quad
\underbrace{[3,4,2]}_{\text{下一 Token 目标}}.
\]
同一段训练文本提供三道自监督预测题。
训练时三个输入 Token 已经给出，却\textbf{不代表}位置 1
可通过 Attention 读取位置 2 的内容：
第 $i$ 行能看见的最多是自己的位置及以前的内容。

\phantomsection\label{concept:teacher-forcing}
这里使用了\textbf{Teacher Forcing（教师强制）}：
训练时将\textbf{真实的已知前缀 Token} 输入模型，
一次算出多个位置的下一 Token 损失，
而不是先采样第 1 个预测 Token，再把这个预测作为第 2 个位置的输入。
这仍然必须使用\textbf{因果 Mask}，以阻止每个位置读取自己的目标或未来位置。
推理时没有现成的后续正确答案，才需要将模型选出的 Token 追加到上下文。
因此，Teacher Forcing 指的是\textbf{训练条件输入的安排}，
并不是“让 Attention 偷看未来答案”。

\subsection{因果掩码决定可见性，损失掩码决定计分}
\phantomsection\label{concept:loss-mask}

继续使用上一章的独立 Q/K 投影和 $3\times3$ 注意力：
\[
C=\begin{bmatrix}
0&-\infty&-\infty\\
0&0&-\infty\\
0&0&0
\end{bmatrix}.
\]
\begin{equation}
\boxed{A=\softmax\!\left(\frac{QK^\top}{\sqrt3}+C\right).}
\label{eq:masked-language-model}
\end{equation}
这是\textbf{因果 Mask}，约束“能读取哪些 Token”；
实际训练中也可能使用\textbf{损失 Mask}，
只让某些位置参与计分。两种 Mask 不是一回事。
本章的三个位置\textbf{全部参与损失}，因此平均时除以 $3$。

\subsection{所有位置输出同一个词表的五项分数}

令 $Z=HW_{\rm out}\in\R^{3\times5}$，逐行 Softmax 得到 $\widehat P$。
一行 logits 是五个未归一化的分数，不是五个独立训练标签；
每行正确答案是词表中的一个 ID。第 $i$ 行交叉熵为
\[
L_i=-\log \widehat P_{i,y_i},\qquad (y_1,y_2,y_3)=(3,4,2).
\]
三行共享\textbf{同一模型参数}，平均损失是
\begin{equation}
\boxed{L=-\frac13
\bigl(\log\widehat P_{1,3}+
      \log\widehat P_{2,4}+
      \log\widehat P_{3,2}\bigr).}
\label{eq:three-position-joint-loss}
\end{equation}
将前一章的初始正确类概率 $(0.261653,\ 0.050747,\ 0.341761)$
代入，逐位置损失约为
\[
(L_1,L_2,L_3)=(1.340736,\ 2.980911,\ 1.073644),
\qquad
\boxed{L_{\rm before}=1.798430}.
\]
初始第二位置错得最严重；第三位置已经预测正确，但仍参与优化。

\subsection{反向传播：先从全部 logits 求梯度}
\label{sec:transformer-gradient-step}

对\textbf{平均}交叉熵，每行的五类梯度必须除以 $3$：
\begin{equation}
\boxed{\frac{\partial L}{\partial Z_{i,:}}
=\frac13\bigl(\widehat P_{i,:}
-\operatorname{onehot}(y_i)\bigr).}
\label{eq:three-position-logit-grad}
\end{equation}
例如第二行正确类别 ID 4 的 logit 梯度为
$(0.050747-1)/3\approx-0.316418$，而它误选的
ID 3 列梯度为 $0.676124/3\approx0.225375$。
负梯度方向会提高正确类相对分数，不等于手工指定新的概率。

输出头共享矩阵 $W_{\rm out}:3\times5$，
因此它的梯度同时累加\textbf{三个位置}的贡献：
\[
\frac{\partial L}{\partial W_{\rm out}}
=\underbrace{H^\top}_{3\times3}
\underbrace{\frac{\partial L}{\partial Z}}_{3\times5}
\quad(3\times5).
\]
依照统一参数，数值为
\[
\frac{\partial L}{\partial W_{\rm out}}
\approx\begin{bmatrix}
0.1211&0.2472&0.1153&-0.8595&0.3760\\
0.0303&0.0404&0.1355&0.4251&-0.6313\\
0.0543&-0.0182&-0.4674&0.3902&0.0411
\end{bmatrix}.
\]
例如 $(W_{\rm out})_{0,3}$ 的原值 $0.2$，
学习率为 $\eta=0.04$ 时会更新为
$0.2-0.04(-0.859532)\approx0.23438$。
\textbf{这里只展示一个元素以便手算，不代表只更新这一个元素。}

\subsection{梯度能走回 Query、Key、Value、Norm、FFN 和词向量吗？}

误差经输出头先传回隐藏状态 $H$：
$G_H=G_ZW_{\rm out}^\top$。
沿第二条残差分成恒等通路和 FFN 通路，
FFN 的权重梯度、ReLU 传导与第二次 LayerNorm
又把误差传回 $X_{\rm att}$；
沿第一条残差、输出投影与 $AV$ 则可继续到 Value，
并沿 Softmax 与 $QK^\top$ 返回 Query、Key。
最后，经第一层 LayerNorm 回到 $X=E+P$，
每个出现过的 Token ID 汇总梯度到 Embedding 行。

这条链的非零数值可以核对：
\[
\begin{aligned}
\bigl(\nabla_{W_Q}L\bigr)_{0,0}&\approx 0.014711,&
\bigl(\nabla_{W_K}L\bigr)_{0,0}&\approx 0.005830,\\
\bigl(\nabla_{W_V}L\bigr)_{0,0}&\approx-0.119632,&
\bigl(\nabla_{W_O}L\bigr)_{0,0}&\approx-0.135640.
\end{aligned}
\]
输入中的三个 Token ID 为 $1,3,4$，对应的梯度行是
\[
\begin{aligned}
\nabla_{E[1]}L&\approx(0.00188,-0.44502,0.11176),\\
\nabla_{E[3]}L&\approx(0.25764,0.52483,-0.29562),\\
\nabla_{E[4]}L&\approx(-0.01061,0.02563,-0.06889).
\end{aligned}
\]
比如词“花”向量第一个坐标从 $-0.30$
更新为 $-0.30-0.04(0.257642)\approx-0.31031$。
ID 2 是本次的\textbf{目标 Token}，但没有作为输入出现，
所以它在本次迭代的\textbf{输入 Embedding 梯度为零}；
这并不意味着 ID 2 的输出头列没有梯度。
位置向量 $P$ 的梯度也来自 $X=E+P$ 的加法支路。
本教学模型把 LayerNorm 的 $\gamma=1$、$\beta=0$ 固定，
所以\textbf{不会更新它们}；有可学习仿射参数的常规 LayerNorm 则可更新。

\subsection{全部参数同时更新，再重新前向计算}

现在从\textbf{同一组旧参数}收集全部梯度，
对 $E,P,W_Q,W_K,W_V,W_O,W_{\rm up},W_{\rm down},W_{\rm out}$
同时执行一次 SGD：
\[
\theta_{\rm new}=\theta_{\rm old}-0.04\nabla_\theta L.
\]
不能边算反向梯度边把后面的旧权重替换为新权重；
同一个损失的梯度必须在同一旧参数状态下求完。
重新执行\textbf{完整的}前向计算，而不是固定旧 Attention
或旧隐藏向量，结果如下：

\begin{center}\small
\tagpdfsetup{table/header-rows={1}}
\begin{tabularx}{\linewidth}{@{}p{25mm}p{23mm}p{27mm}X@{}}
\toprule
预测位置及目标 & 更新前正确类概率 & 更新后正确类概率 & 更新前/后损失\\\midrule
位置 1：ID 3“花” & $0.261653$ & $0.326865$ & $1.340736\to1.118208$\\
位置 2：ID 4“开了” & $0.050747$ & $0.068548$ & $2.980911\to2.680220$\\

\end{center}
\[
\boxed{L_{\rm before}=1.798430\quad\longrightarrow\quad
L_{\rm after}=1.611377.}
\]
这是一\textbf{步}联合参数更新；
从同样初值继续训练至第 20 步，平均损失约为 $0.483173$。
完整轨迹见本章后文。
这一步三个位置正确类概率都上升，平均损失下降。
但并非所有贪心预测都立刻正确：
更新后位置 1 预测已变成“花”，位置 2 仍偏向“花”而不是“开了”，
位置 3 仍预测“。”；\textbf{优化一步不等于学会所有题。}

\begin{boundarybox}
九组可训练参数的梯度均在同一旧参数状态下求取。
这一小样本上的训练损失下降，只验证优化过程，
不能代表未见文本的泛化质量。
\end{boundarybox}

\subsection{同一网络继续做 20 步，会发生什么？}

不换数据、不重设权重，每一步都重新前向、反传，
并同步更新全部九组可训练参数：
\[
\begin{aligned}
&E,\ P,\ W_Q,\ W_K,\ W_V,\ W_O,\\
&W_{\rm up},\ W_{\rm down},\ W_{\rm out}.
\end{aligned}
\]

\subsection{怎样独立检查数值不是手工凑的？}

在仓库根目录运行：
\begin{center}
\small\ttfamily
python3 scripts/teaching\_reference.py --json
\end{center}
然后在 JSON 输出中分别查找以下字段：
\begin{itemize}
\item \texttt{position\_losses\_before}：三位置初始损失；
\item \texttt{position\_losses\_after}：更新后三位置损失；
\item \texttt{gradient\_norms}：各参数梯度的数值规模；
\item \texttt{states\_before}：每层中间张量和词表分数。
\end{itemize}
脚本的反向传播使用矩阵链式法则，
并用每个参数张量的中心有限差分抽样进行数值核验。
下游真正部署的语言模型会有不同宽度、层数、归一化及更多参数，
但本章的共享训练原则不会改变。

\begin{conclusion}
三个位置同时提供训练信号，所有共享参数沿完整图累积梯度，
在同一旧参数状态下统一更新。
现在整条“ID $\to$ 概率 $\to$ 损失 $\to$ 梯度 $\to$ 再预测”已可复算。

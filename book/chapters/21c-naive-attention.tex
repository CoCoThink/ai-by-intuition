\section{最朴素的注意力：直接用词向量做点积}
\label{intro:21c-naive-attention}
\chaptercompass{不增加 Q/K/V 参数，能否先做一次按需读取？}{用原始词向量点积匹配，再用 Softmax 加权求和。}{$X:3\times2\to XX^\top:3\times3\to Y:3\times2$}{本章无新可训练投影参数}
\modelpipelinefocus{3}{朴素点积注意力}


顺序传递状态会把早先信息压进连续更新的向量。
现在换一个思路：直接将当前词与可见位置逐个比较，
先检验\textbf{不增加投影参数}的简单读取能做到什么。

\subsection{三个二维输入，零参数读取}

\localfixture{无参数二维注意力；每行一个 Token}
先不要立即引入三种新参数。设三个 Token 的输入就是
$x_1=(1,0),\,x_2=(0,1),\,x_3=(1,1)$，
直接让每条输入向量同时承担查询、匹配和读取的职责：
\[
X=\begin{bmatrix}1&0\\0&1\\1&1\end{bmatrix}
\ (3\times2),\quad
\underbrace{S}_{3\times3}=XX^\top
=\boxed{\begin{bmatrix}1&0&1\\0&1&1\\1&1&2\end{bmatrix}}.
\]
此处\textbf{［未缩放］、未加因果 Mask}。例如第三行
$(1,1,2)$ 经 Softmax 得
$(0.212,0.212,0.576)$，继续把输入作为 Value，
读出约为 $(0.788,0.788)$。
这说明不增加投影也可以做一次“比较、分配、读取”。

\begin{boundarybox}
\textbf{朴素方案有两个缺口：}
(1) 未加 Mask 的原始分数矩阵满足 $S=S^\top$，
无法让“位置 $i$ 对 $j$ 的原始匹配分数”独立于反方向；
但逐行 Softmax 后的权重矩阵\textbf{不一定对称}。
(2) 点积受到向量范数影响，有时偏向自身；
\textbf{不是每个位置与自身的分数都必然最高}，
本例第一行的自匹配分数就与第三条 Key 打成平手。
\end{boundarybox}

要放宽这些限制，就让“拿什么询问”和“凭什么被找到”
不再必须是同一条表示，并把“读出什么内容”也分开。
这便是接下来引入 Query、Key、Value 三种角色的动机。


\chapterchecktasks{21c-naive-attention}{手算／预测／找错／比较}{
\item \textbf{手算：}本章 $x_1=(1,0),x_2=(0,1),x_3=(1,1)$。计算 $S=XX^\top$ 的第一行和第三行，标出 $S_{13}$ 与 $S_{31}$。
\item \textbf{预测：}对每一行分开做 Softmax 后，$A_{13}$ 与 $A_{31}$ 还一定相等吗？请先比较两行的分母。
\item \textbf{找错：}同学说“直接点积能自定义‘我如何问’和‘别人如何被问’这两套不同视角”。这一零参数方案缺少什么？
\item \textbf{比较：}保持三个输入不变，改用独立可训练 $W_Q,W_K$，哪一种对称性约束可能被打破？为什么它更灵活？
}
\chapterrecallanswer{直接点积 $XX^	op$ 的原始分数对称，但逐行 Softmax 的归一化分母可不同；独立 Q/K 投影可以表达不对称匹配。}



\begin{conclusion}
最朴素的点积已经能计算权重，却把“拿什么提问”和“凭什么被匹配”绑定在一起。
接下来拆开 Q/K/V 三种角色，让模型能分别学习匹配与读出的表示。
\end{conclusion}

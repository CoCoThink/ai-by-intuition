\section{Embedding：让 Token ID 变成可训练的向量}
\label{intro:20-embeddings}
\phantomsection\label{concept:embedding}

前面已把文字转成整数 ID，并学过分类损失，但编号本身没有语义大小：
ID 表示词表位置，语义特征由可训练向量承载。
我们要找一种表示，让\textbf{每个 ID 有自己的特征，而且这些特征能在训练时调整}。

\subsection{四种表示：为什么不能直接把 ID 当特征？}
\phantomsection\label{partq:tokens}

先固定一份五项词表，将同一个 Token 表成数字，有四种常见思路：
\begin{center}\small
\tagpdfsetup{table/header-rows={1}}
\begin{tabularx}{\linewidth}{@{}p{25mm}p{34mm}X@{}}
\toprule
表示方法 & “春天”（ID 2）的示意 & 能力与限制\\\midrule
人工特征 & $(1,0)$（人为规定） & 容易解释，但难以穷举真实语言特征\\
直接用 ID & $(2)$ & 引入虚假大小：“开了”（ID 5）被当成“春天”（ID 2）的 $2.5$ 倍\\
One-hot & $(0,1,0,0,0)$ & 不引入虚假的 ID 大小关系，但维度随词表增长\\
可训练 Embedding & $(1.2,0,-0.2)$ & 用固定宽度可训练向量表示身份；数值由训练目标塑造\\
\bottomrule
\end{tabularx}
\end{center}
ID 4 的 One-hot 行向量是 $(0,0,0,1,0)$。
不同 One-hot 类别互相正交，点积为零，
“花”与“春天”的语境关联要由后续训练建立。
实际实现用整数索引直接查表，省去显式的高维 One-hot 矩阵。

\subsection{真实模型的参数如何开始？}
\phantomsection\label{concept:embedding-initialization}

本书手设下面这张 $5\times3$ 表，便于逐项核算；
从头训练时，常见做法是对 Embedding 和投影权重进行\textbf{随机初始化}，
再用大量训练样本、同一损失函数联合调整。
随机初始化的尺度应与层宽和结构匹配；常见做法包括
按输入/输出维度控制方差的 Xavier、He 等初始化，
但选哪种方案取决于激活与网络设计。

\textbf{为什么不把所有权重都置零？}
同层多个功能相同的隐藏单元若从完全相同的权重出发，
在对称结构下会得到相同梯度，很难学出不同特征；
适当随机初始化用于打破这种对称性。
偏置可初始化为零；本书词表 ID 1（“其他”）的 Embedding 初值也恰好为零。
零初值本身不妨碍更新，关键看这一行有没有梯度：
主线输入 $[2,4,5]$ 里没有 ID 1 和 ID 3，这两行的查表梯度为零，
下文 20 步训练后保持不变。


\textbf{升维、降维与潜在空间：}
Embedding 把类别身份映射到 $d_{\rm model}$ 维特征空间，
称为\textbf{嵌入空间或潜在表示空间}；
之后 $W_{\rm up}$ 可扩宽特征，$W_{\rm down}$ 可再缩回。
升降维改变特征宽度，训练目标与数据决定这些特征的用途。

\subsection{同一份三维教学参数：五行向量}

本节给出\textbf{三维贯通主算例}的参数。
后文的二维注意力、四维双头等示例都在开头标“独立例”，
各自使用独立的数值参数，不与这里的表混用。
从这里开始，\textbf{三维贯通实验的唯一初始 Embedding 表}
使用 $d_{\rm model}=3$，五个 ID 各对应一行：
\[
\begin{array}{c|ccccc}
\text{ID／表的行号}&1&2&3&4&5\\\hline
\text{Token}&\text{其他}&\text{春天}&\text{。}&\text{花}&\text{开了}
\end{array}
\]
“其他”是这份教学词表中保留的第一个类别，第一行就是它的向量；
该名称不表示真实 Tokenizer 都用同一个未知词机制。
\[
E=\begin{bmatrix}
0&0&0\\
1.2&0&-0.2\\
0.2&-0.4&0.7\\
-0.3&1.1&0.2\\
0.15&-0.2&1.25
\end{bmatrix}\in\R^{5\times3}.
\]
数值来自仓库 \texttt{scripts/teaching\_reference.py} 的
\texttt{parameters()}，用作\textbf{训练前的统一初始参数}。
其中“春天”是 ID 2 的 $(1.2,0,-0.2)$，“花”是 ID 4 的
$(-0.3,1.1,0.2)$，“开了”是 ID 5 的 $(0.15,-0.2,1.25)$。
本书为便于追踪数值而手设了这组三维初值；
它们不是训练得到的词义规律。

把输入 $[2,4,5]$ 逐行查表：
\begin{equation}
\boxed{
X=\begin{bmatrix}
1.2&0&-0.2\\
-0.3&1.1&0.2\\
0.15&-0.2&1.25
\end{bmatrix}\in\R^{3\times3}.
}
\label{eq:running-embedding}
\end{equation}
每一行对应一个 Token 位置，每行有三个可训练特征。

\subsection{按 ID 查表为什么等价于矩阵乘法？}

“花”（ID 4）的五维 One-hot 行向量右乘 $E$，只取出第 4 行：
\[
\underbrace{(0,0,0,1,0)}_{1\times5}\,
\underbrace{E}_{5\times3}
=\underbrace{(-0.3,1.1,0.2)}_{1\times3}.
\]
实际程序用整数索引直接读取，不会为了查询一次 Token 就构造整条 One-hot。
训练时，这张 Embedding 表与后续网络一样，可以根据预测误差更新。

\subsection{训练前后，向量真的变了什么？}

先观察后续完整模型的训练结果；模型的逐层计算与训练过程见
\hyperref[intro:22b-token-to-output]{完整前向计算}和\hyperref[intro:22c-language-training]{语言模型训练}两章。
在该模型中，以
$[2,4,5]$ 预测三个位置的目标 $[4,5,3]$，
所有参数同时用学习率 $0.04$ 做 \textbf{20 步全批次梯度下降}。
该训练样本的平均交叉熵从约 $1.7984$ 降为 $0.4832$。
这时对应的三行 Embedding 变为：
\[
\begin{aligned}
E_{20}[2]&\approx(1.2145,\,0.1364,\,-0.2272),\\
E_{20}[4]&\approx(-0.4298,\,0.8810,\,0.3345),\\
E_{20}[5]&\approx(0.1734,\,-0.2188,\,1.3136).
\end{aligned}
\]
这份结果可由 \texttt{python3 scripts/teaching\_reference.py --json}
复现。\textbf{这次训练确实改变了输入向量，并降低了同一样本的预测损失。}

\subsection{Word2Vec 与上下文化表示有什么关系？}

经典 Word2Vec 用词与上下文之间的预测关系训练\textbf{静态词向量}，
一些实验曾观察到类似“国王 $-$ 男人 $+$ 女人 $\approx$ 女王”的方向类比。
静态词向量为每个词保存一行；现代 Transformer 从同一行出发，
再由位置与 Attention 形成随上下文变化的隐藏表示。

词向量类比是特定语料和表示空间中的经验现象，也会反映语料偏差。

\chapterchecktasks{20-embeddings}{理解与复算}{
\item \textbf{形状：}词表有 $5$ 个 ID，Embedding 宽为 $3$，三个 Token 输入 ID 为 $[2,4,5]$。查表后形状是多少？解释每一行对应什么。\chapterinlinehint{每个输入 ID 选一行，向量宽度保持不变。}
\item \textbf{比较：}为什么直接拿 ID 数值相乘不能代替 Embedding 查表？one-hot 乘 Embedding 矩阵又为何可以得到同一向量？\chapterinlinehint{把 one-hot 与矩阵相乘展开为各行加权和。}
\item \textbf{预测：}一句话中同一 ID 出现在位置 $1$ 和 $3$，原始查表向量是否相同？训练更新了这个 ID 对应的表行后，下次在这两个位置查表会得到什么？\chapterinlinehint{两个位置都用同一个 ID 读取同一张表。}
}

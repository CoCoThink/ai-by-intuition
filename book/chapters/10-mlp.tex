\modelpipelinefocus{0}{MLP 与训练基础}

前面已学会行向量右乘矩阵；\hyperref[part:learning]{训练基础部分}也亲手训练过两层标量网络。
现在不再重复完整推导梯度，而是把同一结构推广到多个输入特征与隐藏单元。
MLP（多层感知机）把两个可训练线性层与一个非线性激活串联起来。

\subsection{什么是神经元、输入层、隐藏层与输出层？}
\phantomsection\label{concept:neuron}

一个\textbf{人工神经元}接收若干输入数字，
按权重加总、加偏置，再经过激活函数，例如
$h=\relu(x_1w_1+x_2w_2+b)$。
它只是可训练的计算单元，不是对生物神经元的精确模拟。
将多个这样的单元并排计算，就是一层向量运算。

下面的圆点分别是两个输入特征、三个\textbf{隐藏神经元}和两个输出。
\textbf{输入层}提供数据，\textbf{隐藏层}形成中间表示，
\textbf{输出层}产生任务需要的特征或候选分数。
箭头是带可训练权重的连接，激活在隐藏层计算之后进行。

\subsection{按行向量约定，手算一次}
令 $\vect x^\top=(2,-1)$，取
\[
W_1=\begin{bmatrix}1&0&1\\0&1&1\end{bmatrix},\quad
W_2=\begin{bmatrix}1&0\\0&2\\1&1\end{bmatrix}.
\]
\begin{example}
\[
\vect z^\top=\vect x^\top W_1=(2,-1,1),\qquad
\vect h^\top=\relu(\vect z^\top)=(2,0,1),
\]
\[
\widehat{\vect y}^\top=\vect h^\top W_2=\answerresult{(3,1)}.
\]
输入、隐藏和输出形状依次为 $1\times2$、
$1\times3$ 和 $1\times2$。
\end{example}

\subsection{加上偏置后，一般公式是什么？}
\begin{equation}
\boxed{\widehat{\vect y}^\top
=\sigma(\vect x^\top W_1+\vect b_1^\top)W_2+\vect b_2^\top,}
\label{eq:mlp-standard}
\end{equation}
其中 $W_1:d_{\rm in}\times d_{\rm ff}$，
$W_2:d_{\rm ff}\times d_{\rm out}$，偏置在相应层的行上相加。
多 Token 情况下，逐行使用\textbf{同一组参数}。

\subsection{\texorpdfstring{从两层推广到任意 $L$ 层}{从两层推广到任意 L 层}}

沿全书“一个样本/Token 占一行”的约定，
令 $A^{(0)}=X\in\R^{N\times d_0}$，对第 $\ell$ 层：
\begin{equation}
\boxed{A^{(\ell)}
=\sigma_\ell\!\left(A^{(\ell-1)}W_\ell+
\mathbf1_N\vect b_\ell^\top\right),\quad \ell=1,\ldots,L.}
\label{eq:mlp-l-layer-row}
\end{equation}
$W_\ell:d_{\ell-1}\times d_\ell$，
$\vect b_\ell^\top:1\times d_\ell$，所以结果为
$A^{(\ell)}:N\times d_\ell$；$\mathbf1_N$ 的作用
只是给 $N$ 行广播同一个偏置。输出层可以按任务选择
恒等激活（产生 logits）、Sigmoid 或其他映射。
若改用列向量，等价式可写成
$\vect a^{(\ell)}=\sigma_\ell(W_\ell^\top\vect a^{(\ell-1)}+\vect b_\ell)$；
这里权重转置不能省略。

\Needspace{18\baselineskip}
\subsection{为什么夹在中间的非线性不可少？}
去掉偏置和 ReLU，就有
$\vect x^\top(W_1W_2)$，两层可以合并成一层；
插入激活函数后，哪些中间分量为零随输入改变，不再能用一个固定矩阵普遍代替。

\subsection{它与 Transformer 中的 FFN 有什么关系？}
Transformer 的 FFN 也对每个 Token 分别应用共享的非线性网络；
跨位置的信息交互由 Attention 等机制承担。
例如有三个 Token，每行宽度为 2，
取 $X:3\times2$、$W_1:2\times3$、$W_2:3\times2$，
则 $\relu(XW_1)W_2:3\times2$。
三行分别对应三个 Token；FFN 虽改变每行的特征，
却没有在不同 Token 之间交换信息。

外积与读取的另一种理解路径，放在\hyperref[intro:04-key-value-outer-product]{附录 H--K 的联想记忆提高专题}。

\item \textbf{形状：}输入行 $x:1\times2$，两层权重分别 $W_1:2\times3,W_2:3\times2$。写出隐藏层与输出层的形状。
\chapterinlinehint{10-mlp}{1}
\item \textbf{手算：}计算 $\relu(-1)$ 和 $\relu(2)$，说明对负值隐藏单元发生了什么。
\chapterinlinehint{10-mlp}{2}
\item \textbf{找错：}同学认为两个 Token 共用 FFN 权重，故第二行的输入会直接改变第一行 FFN 的输出。指出错误。
\chapterinlinehint{10-mlp}{3}
\item \textbf{比较：}去掉两层中间的 ReLU 后，$xW_1W_2$ 能合并为怎样的一层运算？为何保留 ReLU 时一般不能照做？
\chapterinlinehint{10-mlp}{4}
}
\chapterrecallanswer{MLP 的逐行变换改变隐藏特征但不直接交换 Token；非线性让两层不等同于一层仿射。}



\begin{conclusion}
你现在可以用行向量手算两层 MLP，并核对每一步的形状。
一个输入行从 $1\times2$ 经第一层变为 $1\times3$，由 ReLU 筛选激活后再映射回 $1\times2$；不能仅看到两次矩阵乘法就把中间非线性忽略。对不同输入，隐藏单元可能分别处于正值分支和零值分支，这正是简单线性组合不能完全替代的地方。

多个 Token 可以共用 FFN 的参数，但仍各自在自己的那一行计算。共享参数不等于共享输入：第二个 Token 的变化不会直接让第一个 Token 的逐行 FFN 输出变化，只有经过 Attention 等跨位置读取，其他位置的内容才可能进入这一行。这一判断既可用来发现形状错误，也能帮助你在后面的 Transformer Block 中明确区分“逐位置变换”和“交换上下文信息”。

Mini-batch 与 SGD 见第~\ref*{intro:16a-gradient-descent}~章；Adam、AdamW 和 Warmup 的手算见附录 A。
\end{conclusion}

\section{贯通算例：从“春天、花”算到下一个 Token 的概率}
\label{intro:22b-token-to-output}

前两章说明了 Transformer 的各个组件。
但读者最终想知道的不是一串模块名称，而是：
\textbf{这些矩阵串起来，能不能真的算出“下一个 Token 是谁”？}

这次选一个只有两个输入位置、每条向量两个数字的\textbf{人工网络}，
从输入一直算到五个候选 Token 的概率。
为让数字能手算，我们只保留\textbf{单头因果 Attention、
两次残差、一个极简 FFN 和词表输出头}，
暂时省略位置编码、归一化、偏置和多层堆叠。
真实模型不是这个大小，也不会使用本例预先指定的参数。

\subsection{第一步：从文本查表，得到两行数字}

延续 Embedding 章的词表：
\[
\begin{array}{c|ccccc}
\text{Token ID}&0&1&2&3&4\\\hline
\text{文本}&\text{其他}&\text{春天}&\text{。}&\text{花}&\text{开了}
\end{array}
\]
用户已经给出“春天、花”，对应 ID $[1,3]$。
\hyperref[intro:20-embeddings]{前面那张教学 Embedding 表}中，
ID 1 的向量是 $(1,0)$，ID 3 的向量是 $(0,1)$。
把两个位置\textbf{按行}排起来：
\[
\underbrace{X}_{2\times2}=
\begin{bmatrix}1&0\\0&1\end{bmatrix}.
\]

\subsection{第二步：计算 Q/K/V，但不能偷看未来}

为了专注计算，假设 $W_Q=W_K=W_V=I_2$，
因此 $\Qrole=\Krole=\Vrole=X$；真实投影权重一般不同，需要通过训练学习。
三者分别用蓝色、青色和橙色表示查询、匹配键与读取内容。
每个 Key 的维度 $d_k=2$，分数矩阵是
\[
\frac{QK^\top}{\sqrt{d_k}}
=\frac{1}{\sqrt2}
\begin{bmatrix}1&0\\0&1\end{bmatrix}.
\]
因为我们在\textbf{预测下一 Token}，
第一个位置不能读到第二个位置，加入因果掩码：
\begin{equation}
S=
\begin{bmatrix}
1/\sqrt2&-\infty\\
0&1/\sqrt2
\end{bmatrix}.
\label{eq:two-token-scores}
\end{equation}
这就是整个算例中的\textbf{可见性约束}：
第一行只能看见“春天”，第二行可以看“春天”和“花”。

\subsection{第三步：Softmax 分配权重，读取 Value}

对 $S$ \textbf{逐行做 Softmax}。
第一行只能读取自己，权重是 $(1,0)$。
第二行两个候选的分数分别是 $0$ 和 $1/\sqrt2$。
由于 $e^{1/\sqrt2}\approx2.028$，第二行的权重为
\[
\left(\frac{1}{1+2.028},\frac{2.028}{1+2.028}\right)
\approx(0.330,0.670).
\]
因此整个注意力权重矩阵是
\[
A\approx
\begin{bmatrix}
1&0\\
0.330&0.670
\end{bmatrix}
\quad (2\times2).
\]
Value 也按行摆放，计算 $AV$：
\[
\underbrace{O_{\rm att}}_{2\times2}
=\underbrace{A}_{2\times2}\underbrace{V}_{2\times2}
\approx
\begin{bmatrix}1&0\\0.330&0.670\end{bmatrix}.
\]
\textbf{观察第二行：}它不再只是“花”的原始向量 $(0,1)$，
还读取了“春天”的一部分信息。

\subsection{第四步：经残差和一个很小的 FFN}

真实 Transformer Block 还要对特征继续加工。
为了保留可手算性，这里用最简单的\textbf{残差}，
先把输入 $X$ 加回注意力输出 $O_{\rm att}$：
\[
X_{\rm att}=X+O_{\rm att}\approx
\begin{bmatrix}
2&0\\
0.330&1.670
\end{bmatrix}.
\]
它仍是 $2\times2$：\textbf{位置数和隐藏宽度都没变}。

再人为选一个极简 FFN：
\[
\operatorname{FFN}(\vect h)=0.5\,\relu(\vect h)
\quad\text{（逐行作用）}.
\]
这相当于本例中上投影用 $I_2$、下投影用 $0.5I_2$，
是为了把乘法缩到最简单，\textbf{不是所有 FFN 的通用公式}。
FFN 后再加一次残差，得到
\[
X_{\rm block}=X_{\rm att}+\operatorname{FFN}(X_{\rm att})
\approx
\begin{bmatrix}
3&0\\
0.495&2.505
\end{bmatrix}.
\]
这样最后位置的输出行向量就是
$\vect h_{\rm last}^\top=(0.495,2.505)$。

\subsection{第五步：让输出头先犯错，训练才有意义}

最后位置的隐藏行向量是 $\vect h_{\rm last}^\top=(0.495,2.505)$。
取一个\textbf{尚未训练好的输出头}，故意让“花”（ID 3）得分最高：
\[
W_{\rm vocab}=
\begin{bmatrix}
0&1&0&0&0\\
0&0&0&1&0
\end{bmatrix}\in\R^{2\times5}.
\]
得到五个 logits（尚非概率）：
\[
\underbrace{\vect z^\top}_{1\times5}
=\vect h_{\rm last}^\top W_{\rm vocab}
=(0,0.495,0,2.505,0).
\]
Softmax 后，从 ID 0 到 4 的概率为
\[
\boxed{\vect p^\top\approx(0.059,0.097,0.059,0.725,0.059).}
\]
贪心预测是 ID 3“花”，而真实下一 Token 是 ID 4“开了”。
\textbf{模型此刻确实预测错了。}
下一章从这组参数出发，观察训练能否把正确 Token 的概率升到第一名。

\begin{example}[title={换一组 Value 会怎样？}]
保持 $Q,K$ 不变，最后位置的注意力权重仍为 $(0.330,0.670)$。
只将 $W_V$ 换成
$\begin{bmatrix}2&0\\0&1\end{bmatrix}$，
则新的 Value 加权输出为
\[
(0.330,0.670)\begin{bmatrix}2&0\\0&1\end{bmatrix}
=\boxed{(0.660,0.670)}.
\]
它与先前的 $(0.330,0.670)$ 不相同，
说明结果依赖\textbf{选定的可训练权重}，并不是“中文词语自然产生”。
\end{example}

\begin{center}
\begin{tcolorbox}[colback=paper,colframe=linegray,boxrule=.6pt,arc=2mm]
\small
\textbf{本次数值链条：}\par
\texttt{[1,3]} $\to$ $X:2\times2$
$\to$ 因果 Attention $AV:2\times2$
$\to$ FFN $X_{\rm block}:2\times2$
$\to$ 词表 logits $1\times5$
$\to$ 初始预测 ID 3（错误，下一章纠正）。
\end{tcolorbox}
\end{center}

\begin{warningbox}
这里只使用两步输入“春天、花”，\textbf{没有把未来的“开了”放入输入矩阵}；
否则预测时就会有泄漏。
为了突出计算逻辑，示例故意省略了一些实际网络部件，
不能将它当作完整工业 Transformer 的实现说明。
\end{warningbox}

\begin{conclusion}
你已经沿 Embedding、因果 Attention、FFN 算到了词表概率。
当前最高概率是错误的“花”，下章将用正确标签推动预测翻转。
\end{conclusion}

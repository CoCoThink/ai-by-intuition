\subsection{第一步：Token ID、位置向量与输入形状}

本书词表 ID 0--4 为“其他、春天、。、花、开了”。
完整句子 $[1,3,4,2]$，此处输入 $[1,3,4]$，
三位置的下一 Token 目标 $[3,4,2]$。
查 $5\times3$ 的 Embedding，逐行加 $3\times3$ 的位置向量后，
Block 输入 $X=E_{[1,3,4]}+P$ 有三行：
\begin{equation}
X=E_{[1,3,4]}+P\in\R^{3\times3},
\qquad X_{1,:}=(1.30,\ 0.05,\ -0.30).
\label{eq:running-three-token-x}
\end{equation}
一个位置占一行，三个特征占三列；
位置向量影响输入数值，而因果 Mask 控制哪些位置可以被读取。

\subsection{第二步：先 Norm，再投影 Q/K/V}

逐行 LayerNorm 得到 $U=\operatorname{LN}(X)$。
它对每行减均值并除以标准差（本例 $\varepsilon=10^{-5}$），
固定仿射参数 $\gamma=1,\beta=0$。
第一行从 $(1.30,0.05,-0.30)$ 变为
约 $(1.3833,-0.4368,-0.9464)$。
随后用\textbf{三组不同}的权重计算
\[
Q=UW_Q,\qquad K=UW_K,\qquad V=UW_V.
\]
每个投影的形状均为 $(3\times3)(3\times3)\to3\times3$。
例如第一行 Query 约为 $(1.1576,-0.2584,-1.0047)$。
因此这里没有使用 $Q=K=V=X$ 的简化假设；
全部初始投影权重和计算结果见附录核对表。

\subsection{第三步：用因果权重读取 Value}

对 $d_k=3$，匹配分数为 $QK^\top/\sqrt3$。
未来位置的分数设为 $-\infty$，
所以它们在 Softmax 后获得零权重：
\begin{equation}
S=QK^\top/\sqrt3+C,\qquad A=\operatorname{softmax}(S).
\label{eq:two-token-scores}
\end{equation}
先核对第二行权重，完整注意力矩阵见本章末：
\begin{equation}
A\in\R^{3\times3},\qquad
A_{2,:}\approx(0.1244,\ 0.8756,\ 0).
\label{eq:three-token-attention}
\end{equation}
\textbf{每一行的权重在可见 Key 上求和为 $1$}：
第二位置无法读取第三位置；
第三位置约把 $59\%$ 的读取权重给当前位置。
这张\textbf{真实注意力热力图}不同于仅标示“可见或不可见”的 Mask 图。

先计算 $R_{\rm raw}=AV$，再用 $W_O$ 投影并走第一条残差：
\[
X_{\rm att}=X+R_{\rm raw}W_O.
\]
每次读取和残差相加都保持 $3\times3$，
但每行已经结合此前可见位置的内容。

\subsection{第四步：第二次 Norm 与逐位置 FFN}

先令 $B=\operatorname{LN}(X_{\rm att})$，然后升维到 $4$：
\[
F_{\rm mid}=\operatorname{ReLU}(BW_{\rm up})\in\R^{3\times4},
\qquad
H=X_{\rm att}+F_{\rm mid}W_{\rm down},
\]
其中 $W_{\rm up}:3\times4$、$W_{\rm down}:4\times3$。
FFN 对每个 Token 行分别使用\textbf{同一组矩阵}；
跨 Token 的读取来自此前 Attention，FFN 本身不改变位置数。
第二条残差后的隐藏状态只用形状与一个代表元素核验：
\begin{equation}
H=X_{\rm att}+F_{\rm mid}W_{\rm down}\in\R^{3\times3},
\quad H_{1,1}\approx2.5609.
\label{eq:three-token-block-output}
\end{equation}

\subsection{第五步：同一个输出头预测五个类别}

令共享的词表输出头 $W_{\rm out}:3\times5$，
则 $Z=HW_{\rm out}\in\R^{3\times5}$；
对每行 logits 执行 Softmax，正文保留正确类概率：
\begin{equation}
\widehat P=\operatorname{softmax}_{\rm row}(Z)\in\R^{3\times5},
\quad(\widehat P_{1,3},\widehat P_{2,4},\widehat P_{3,2})
\approx(0.2617,0.0507,0.3418).
\label{eq:three-token-probabilities}
\end{equation}
下面青色柱表示\textbf{正确类别}，
并不代表该类别总有最高概率。

\subsection{改变前文，最后一行还会相同吗？}

保持最后两个 Token 不变，
仅把第一个输入由 ID 1 换成 ID 4，得到 $[4,3,4]$。
第三行 logits 从约
$(0,-0.3064,0.8002,-0.2620,0.5776)$
变为
$(0,-0.4279,0.9325,-0.6140,0.7915)$，
最大分数差约 $0.3520$。
这说明最后位置\textbf{受前文影响}，而不是重新训练过一遍。
全部结果可用附录参数与脚本复算。

\chapterchecktasks{22b-token-to-output}{定位／预测／找错／比较}{
\item \textbf{定位：}输入为三个 Token，每行隐藏宽度为 $3$，词表大小为 $5$。列出 $X$、$A$、$H$、$Z$、$\widehat P$ 的形状，并指出哪一步从三维隐藏特征变成五类分数。
\item \textbf{预测：}沿用初始正确类概率和贪心预测结果。三个位置中哪两个最初答错？只改第一个 Token 的 ID 后，为什么第三行的分数可能改变？
\item \textbf{找错：}某人说“FFN 对每一行使用同样的权重，所以 FFN 会在不同 Token 之间交换信息，而 Attention 只在每一行内部运算”。改正两处角色混淆。
\item \textbf{比较：}若去掉因果 Mask，第一个位置能够读取后面 Token 吗？在同一训练目标下，这会造成什么信息泄漏风险？
}
\chapterrecallanswer{Attention 负责跨位置读取，FFN 逐位置变换；输出头将 $H:3\times3$ 映射到 $Z:3\times5$。}

\section{从单 Query 到整段 Self-Attention}
\phantomsection\label{concept:self-attention}
\label{intro:12-self-attention-matrices}

上一章先从“为什么不平均读取所有位置”出发，
将任务拆成\textbf{按 Query 与 Key 决定读取比例}、
以及\textbf{把 Value 按比例组合}两部分。
随后才用一个 Query 手算了三条 Key 的分数，
并得到 Attention 输出。
现在仍使用同样的三种角色。

前面先算过\textbf{一个 Query} 对三条 Key 的分数，
又把同样的规则扩展成多行 Query 的公式 $\softmax(QK^\top)V$。
但这些 Q/K/V 向量在例子里是\textbf{提前给定的数字}。
真正处理一句话时，每个 Token 都有自己的隐藏表示：
\textbf{怎样从这些表示中实际计算出 Query、Key 和 Value？}

\subsection{首先回答：$Q$ 就是输入 $x$ 吗？}

\textbf{前两章把 Query 当作已经准备好的向量}，
以便只关注匹配与读取；
这时还没有回答\textbf{Query 由哪里产生}。
在最简单的教学模型里可以直接令 $\vect q=\vect x$，
真实 Transformer 则通常会先做可学习的投影。

\textbf{真实 Transformer 中，\conceptlink{qkv}{Query} 通常由当前输入表示经过一个可学习的线性变换得到，不必与原来的 $x$ 数值相同。}

从现在开始，Transformer 主线统一使用\textbf{行向量}：
\[
\vect x^\top=\begin{bmatrix}2&3\end{bmatrix},\qquad
W_Q=\begin{bmatrix}1&1\\0&2\end{bmatrix}.
\]
所以
\[
\boxed{\vect q^\top=\vect x^\top W_Q
=\begin{bmatrix}2&8\end{bmatrix}.}
\]
特意使用非对称权重，避免恰好看不出转置。
\textbf{同一映射若用列向量表达，权重也必须转置}：
\[
\boxed{\vect q=W_Q^\top\vect x
=\begin{bmatrix}1&0\\1&2\end{bmatrix}
\begin{bmatrix}2\\3\end{bmatrix}
=\begin{bmatrix}2\\8\end{bmatrix}.}
\]
Key 与 Value 同样遵循
$\vect k_i^\top=\vect x_i^\top W_K$、
$\vect v_i^\top=\vect x_i^\top W_V$。

如果将许多 Token 的输入表示按\textbf{行}排成矩阵 $X$，就得到标准 Transformer 常用的批量写法：
\begin{equation}
\boxed{Q=XW_Q,\qquad K=XW_K,\qquad V=XW_V.}
\label{eq:qkv-from-x}
\end{equation}
这里 $W_Q,W_K,W_V$ 的具体形状由输入维度和投影后的维度决定。

\begin{conclusion}
$\vect x$ 是\textbf{输入表示}；$\vect q$ / $Q$ 是扮演\textbf{查询角色}的向量 / 矩阵。简化推导中可以令 $q=x$，真实 Transformer 通常通过可训练参数投影得到 $Q$。二者角色有关，但不是恒等的概念。
\end{conclusion}

\subsection{为什么 $K$ 和 $K^\top$ 可以表示同一批 Key？}
\label{sec:key-layout-card}

\hyperref[sec:layout-matrix-card]{矩阵乘法章}已经用普通数字解释了按行排列与按列排列。
现在把这一规则用于 Key、Query 和 Value。图中使用相同的数值和颜色，直观看清每次转置改变了什么。

\input{figures/key-value-layout}

\textbf{再向前一步：}如果只有一个 Query，用 $K\vect q$ 或
$\vect q^\top K^\top$，得到的是同一组匹配分数的列/行表示。
如果有 $N$ 个 Query，将它们按行组成 $Q$，便得到
\[
\underbrace{Q}_{N\times d_k}
\underbrace{K^\top}_{d_k\times M}
=\underbrace{S}_{N\times M}.
\]
此时第 $i$ 行对应第 $i$ 个 Query，对 $M$ 个 Key 的分数。
在每一行上做 \conceptlink{softmax}{Softmax}，再乘按行排列的 Value 矩阵 $V$，便得到
$N$ 个 Query 对应的输出。

\subsection{给一句话里的每个 Token 一组 Q、K、V}

假设句子里有 $T$ 个 Token。前面用 $N$ 表示 Query 的数量、$M$ 表示 Key 的数量；\textbf{在当前的 Self-Attention 例子中，每个 Token 都各自提供 Query 与 Key，因此 $N=M=T$}。

每条 Query 与 Key 都有 $d_k$ 个数字，而每条 Value 有 $d_v$ 个数字。按\textbf{每个 Token 一行}的约定：
\[
Q\in\R^{T\times d_k},\qquad
K\in\R^{T\times d_k},\qquad
V\in\R^{T\times d_v}.
\]
于是：
\[
\underbrace{Q}_{T\times d_k}
\underbrace{K^\top}_{d_k\times T}
=
\underbrace{S}_{T\times T}.
\]
结果为什么是 $T\times T$？因为位置 $S_{ij}$ 就是\textbf{第 $i$ 个 Query 和第 $j$ 个 Key 的点积}。它记录了所有 Query 对所有 Key 的匹配程度。

\subsection{Softmax 对每一行分别作用}

对 $S$ 的每一行做 Softmax，相当于为每个 Query 分配一组加起来为 1 的检索权重。再与 Value 矩阵相乘：
\[
\underbrace{\softmax(S)}_{T\times T}
\underbrace{V}_{T\times d_v}
=
\underbrace{O_{\rm att}}_{T\times d_v}.
\]
这时乘法的含义是：\textbf{每个 Query 的输出 = 所有 Value 行的加权平均}。

于是就得到常见的缩放点积注意力：
\begin{equation}
\boxed{\operatorname{Attention}(Q,K,V)
=\softmax\left(\frac{QK^\top}{\sqrt{d_k}}\right)V.}
\end{equation}

\begin{example}[title={不是必须选出单独一条记忆}]
假设一个 Query 对两个 Key 的权重已经算成 $(0.75,0.25)$，对应 Value 是 $(2,0)$ 和 $(0,4)$。输出为：
\[
0.75\begin{bmatrix}2\\0\end{bmatrix}
+0.25\begin{bmatrix}0\\4\end{bmatrix}
=\begin{bmatrix}1.5\\1\end{bmatrix}.
\]
注意力通常是\textbf{混合}多条信息，而不是硬性只选一条。
\end{example}

\subsection{为什么前面的式子写 $V^\top$，这里却写 $V$？}

前一章的单查询公式为了手算曾临时使用列向量。对应的行向量版本满足 $(V^\top\vect a)^\top=\vect a^\top V$。该公式把 Value \textbf{排成列后读取}，因此用 $V^\top\vect{a}$；这里把所有 Token 的 Value \textbf{排成行}，权重矩阵乘 $V$ 得到一组输出行。两种写法基于不同的数据摆放约定，\textbf{不是数学矛盾}。让矩阵形状替你判断：$(T\times T)(T\times d_v)=(T\times d_v)$。

\subsection{把三种计算放在同一张表里}

\begin{center}

这三类运算可以组合成 Transformer，但\textbf{不能仅靠外形都是矩阵乘法，就认为它们具有同一种参数或上下文机制}。

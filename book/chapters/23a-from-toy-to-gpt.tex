\section{从一层三维算例，到真正的 GPT 差了什么？}
\label{intro:23a-from-toy-to-gpt}

上一章会用训练好的模型一步步生成 Token。
但我们手算的网络只有一层、一个头、三个隐藏特征和五项词表。
它为何能说明 GPT 的训练原理，却不能当成一款真正能回答问题的大模型？

\subsection{回看先前的 GPT-2 small 尺度示例}

在第三部分，\hyperref[intro:20b-task-contract]{语言预测任务}已给出尺寸对照。
经典基础版 GPT-2 的示例配置为：
词表 $50{,}257$，隐藏宽度 $768$，
$12$ 层 Transformer Block、$12$ 个注意力头，
每层 FFN 中间宽度为 $3{,}072$，最大配置位置数 $1{,}024$。
这些值来自
\href{https://github.com/huggingface/transformers/blob/main/src/transformers/models/gpt2/configuration_gpt2.py}{GPT-2 配置}
和
\href{https://github.com/huggingface/transformers/blob/main/src/transformers/models/gpt2/modeling_gpt2.py}{相应 FFN 实现}。
这不是 2026 年所有 LLM 的统一规格。

\subsection{宽度、层数、头数分别在改变什么？}

\textbf{宽度}增加每个 Token 的隐藏特征维度。
本书主例 $d_{\rm model}=3$，所有隐藏行都是 $1\times3$；
GPT-2 small 为 $1\times768$。

\textbf{头数}让不同注意力头在不同投影子空间中读取内容。
若将 768 个隐藏维度等分给 12 个注意力头，
每头 Query/Key 的宽度为 $768/12=64$。
这与本书另设的 $d_{\rm model}=4$ 两头示例相同地遵守整除原则，
不能把三维主例硬分成两个等宽头。

\textbf{层数}允许把一个 Block 的输出作为下一个 Block 的输入，
让上下文特征反复组合。它不是简单把每层的预测概率相加。

\textbf{FFN 宽度}决定每个 Token 经过非线性中间层时可用的特征数量，
不是 Token 的个数；它与词表输出头也不是同一个矩阵。

\subsection{参数怎么数：99 个教学参数与 GPT-2 量级}

本书三维贯通模型\textbf{按实际可训练元素个数}计数。
固定 LayerNorm 仿射系数、不使用偏置，输出头与输入 Embedding 独立，
也不把计算图中的中间激活当作参数：
\[
\begin{aligned}
E &: 5\times3=15, & P &:3\times3=9,\\
W_Q,W_K,W_V,W_O &:4\times(3\times3)=36,\\
W_{\rm up},W_{\rm down} &:3\times4+4\times3=24,\\
W_{\rm out} &:3\times5=15.
\end{aligned}
\]
因此总数为
\begin{equation}
\boxed{15+9+36+24+15=99\text{ 个可训练参数}.}
\label{eq:toy-99-parameters}
\end{equation}
\textbf{参数量不等于运行时显存}：
推理还会保存激活、缓存和程序开销，训练还需梯度及优化器状态。

再用经典 GPT-2 small 的已公开结构做量级估算：
Token Embedding 约有
$50{,}257\times768=38{,}597{,}376$ 个参数，约 $38.6$ M；
每个 Block 的四组 Attention 投影与两个约 $4d$ 的 FFN 投影，
主导项约为 $12d^2$，
即 $12\times768^2\approx7.08$ M/层。
十二层约 $84.9$ M；再加可学习位置 Embedding
$1{,}024\times768\approx0.79$ M、
归一化参数与偏置，得到约 $124$ M 的经典量级。
这是\textbf{结构上的近似预算}，
精确数值需按具体权重共享、偏置及 checkpoint 逐项核对；
不能将教学模型的独立输出头规则套在 GPT-2 上。


\subsection{［复算］训练前损失应该与什么比较？}

如果词表有 $|\mathcal V|$ 个候选且每个 Token 的概率\textbf{恰好均匀}，
那么任一正确类别的交叉熵为
\[
-\ln\frac1{|\mathcal V|}=\ln|\mathcal V|.
\]
本书五项词表的基准是
$\ln5\approx\boxed{1.609}$；
GPT-2 small 的词表规模为 $50{,}257$，
对应均匀基准 $\ln 50{,}257\approx\boxed{10.825}$。

\textbf{这是均匀预测的基准，并非所有随机初始化模型的严格损失值}：
实际 logits 的分散程度、初始化与数据分布都可能使初始交叉熵有所偏离。
本书三维例子的初始损失约为 $1.798430$，
高于均匀基准并不矛盾，因为我们手工设定了非均匀的初始参数和输出概率。
先确认基线量级、再尝试\textbf{过拟合同一小批数据}，
是检查训练链路是否正常的常见调试方法。

\subsection{同一个训练目标，不代表相同能力}

无论玩具模型还是 GPT-2 类 Decoder-only 模型，
在自回归预训练时都可以从当前及先前 Token 预测下一 Token。
不同点在于训练文本规模、Tokenization、
模型宽度和深度、参数量、优化预算以及数据分布。
本书的单条训练序列从 $L=1.7984$ 降到 $1.6114$
只证明该教学例子的一次优化工作正常：
\textbf{没有证据表明它已经具备一般中文理解、可靠回答或指令遵循能力。}

真实 GPT-2 的输出头通常与输入 Token Embedding 权重\textbf{绑定}，
采用词嵌入矩阵的转置来得到词表分数。
本书为了让每步梯度和形状易于检查，采用\textbf{独立的 $3\times5$ 输出头}，
因此不能把玩具参数总数按 GPT-2 的共享权重规则直接缩放。
真实模型的参数总量还与位置 Embedding、归一化、偏置等设计有关。

\subsection{［复算］真实 GPT-2：分词、概率、温度与注意力}

\localfixture{公开 GPT-2 small 预训练权重；非本书三维参数}
这一节提供一个\textbf{独立运行的真实模型实验}：
\href{https://huggingface.co/openai-community/gpt2}{openai-community/gpt2}，
固定修订（短 SHA）
\texttt{607a30d7}；完整 40 位 revision
由 \texttt{scripts/gpt2\_demo.py} 固定并在运行时输出。
它是历史上以英文为主进行预训练的模型；
不能期待它在中文任务上表现得像现代指令助手。

先在仓库根目录运行无需联网或额外依赖的数学自检：
\begin{verbatim}
python3 scripts/gpt2_demo.py
\end{verbatim}
真实推理需要先自行安装兼容的 \texttt{torch}、
\texttt{transformers}，绘制热图还需 \texttt{matplotlib}；
模型文件首次运行时需下载。显式启用：
\begin{verbatim}
python3 scripts/gpt2_demo.py --real
\end{verbatim}
若权重与分词器已缓存，可加
\texttt{--local-files-only} 防止网络访问。
保存第一层第零个注意力头热图时，可额外指定
\texttt{--heatmap gpt2-attn.png}；实验使用
\texttt{eager} 注意力后端以便读出权重。

\textbf{观察四个结果：}
Tokenizer 把英文 Prompt 变成真实 Token ID；
logits 的末尾形状是 $1\times50{,}257$；
温度分别为 $0.7,1.0,1.5$ 时，同一 logits 的概率分布不同；
热图中因果 Attention 的未来位置应被屏蔽。
更高温度通常使分布平坦，并不必然使每个 Token 的概率都增大。

实验打印模型 commit、PyTorch 和 Transformers 的实际版本。
由于包版本、计算设备与运算后端可能不同，
书中不预填未经执行核实的前五 Token 或概率。
这份在线权重实验\textbf{不会参与常规 PDF CI 的模型下载}；
默认离线自检始终可以独立运行。


\subsection{Decoder-only 与 Encoder--Decoder 是同一个概念吗？}

经典 Transformer 原论文的翻译架构有编码器和解码器，
其中解码器还可以用交叉注意力读取编码器输出。
GPT-2 是\textbf{仅解码器式}的自回归语言模型，
通过因果 Self-Attention 处理已有文本并持续预测下一 Token。
不能将“Transformer”与“GPT”当作完全同义词。

\begin{warningbox}
本章比较的是一类\textbf{经典、可查证的参考配置}，
不是对所有现代模型的排名；“参数更多”也不单独保证每项能力更强。
模型上线后还需要考虑训练分布外的可靠性、成本与安全边界。
\end{warningbox}

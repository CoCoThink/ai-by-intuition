\section{外积与矩阵：如何真正“写入”一条记忆？}
\label{intro:04-key-value-outer-product}
除了沿网络结构理解 Transformer，还可以从\textbf{关联记忆}出发：
一个矩阵能否保存“遇到某种输入，就返回某个结果”的关系？
沿着这个问题，我们会看到线性层、MLP 与 Attention 在读取规则上的联系。

\subsection*{行向量主线与列向量扩展：只差转置}

\textbf{本专题统一使用列向量}，便于把“外积写入”写成矩阵：
$\vect x\in\R^{d_k\times1}$，Key 和 Value 同样为列向量，
存储矩阵 $W\in\R^{d_v\times d_k}$，
读取是 $W\vect x$。主线的查询写成
$\vect x^\top\in\R^{1\times d_k}$，它就是这里输入的转置，
\textbf{两者并非不同的记忆机制}。

把 $M$ 条 Key 按行堆成 $K\in\R^{M\times d_k}$，
Value 按行堆成 $V\in\R^{M\times d_v}$，则
\[
\vect a=\sigma(K\vect x)\in\R^{M\times1},\qquad
\underbrace{\vect a^\top V}_{1\times d_v}
=\underbrace{(V^\top\vect a)^\top}_{1\times d_v}.
\]
右侧列向量读出做一次转置才是主线的行向量读出。
每次遇到 $K\vect x$、$V^\top\vect a$，
先核对形状，不把行列约定混用。



现在为一条记忆指定两个向量：
\[
\text{Key }\vect{k}=\begin{bmatrix}1\\0\end{bmatrix},\qquad
\text{Value }\vect{v}=\begin{bmatrix}2\\3\end{bmatrix}.
\]
我们的目标是设计函数 $f$，使输入 Key 时返回 Value，即 $f(\vect{k})=\vect{v}$。

\subsection{从匹配分数得到 Value}
考虑：
\begin{equation}
\boxed{f(\vect{x})=\vect{v}\bigl(\vect{k}^\top\vect{x}\bigr).}
\end{equation}
如果输入 $\vect{x}=\vect{k}$，由于 $\vect{k}$ 是单位向量，$\vect{k}^\top\vect{k}=1$，所以：
\[
f(\vect{k})=\vect{v}\times 1=\vect{v}.
\]

这个计算已经很像记忆检索：先看输入和哪条 Key 匹配，再按照匹配程度返回 Value。

\subsection{把关系装进矩阵：外积}
两向量的\textbf{外积（outer product）}是：
\begin{equation}
\vect{v}\vect{k}^\top=
\begin{bmatrix}2\\3\end{bmatrix}
\begin{bmatrix}1&0\end{bmatrix}
=\begin{bmatrix}2&0\\3&0\end{bmatrix}.
\end{equation}
外积与点积的区别：点积产生\textbf{一个数}；外积产生\textbf{一个矩阵}。

记这个矩阵为 $W=\vect{v}\vect{k}^\top$。根据矩阵乘法结合律：
\begin{equation}
\boxed{f(\vect{x})=\vect{v}(\vect{k}^\top\vect{x})=(\vect{v}\vect{k}^\top)\vect{x}=W\vect{x}.}
\end{equation}
这说明：我们可以把一条 Key--Value 关联“写入”权重矩阵 $W$，再用普通矩阵乘法取回来。

\begin{idea}
\textbf{一个线性层 $W\vect{x}$，可以被看作一个记忆检索器。}这给了我们另一种解释线性层的角度：可以把一次变换写成若干键值关联的检索和。
\end{idea}

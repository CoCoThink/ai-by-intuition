\section{进阶探索：高维空间与记忆容量}
\modelpipelinefocus{3}{高维记忆容量}
\chaptercompass{提高维度和匹配选择性，会改变哪些干扰尺度？}{从随机 Key 的点积和 Value 的符号抵消估计容量。}{$|k_i k_j^\top|\approx1/\sqrt{d_k}$}{本章分析理想随机状态，不估计实际模型可靠知识量}

高维空间能容纳许多彼此区分的方向。
在随机 Key 近似独立的理想联想记忆模型中，维度增加时，干扰会如何变化？
下面用典型尺度估算可区分的关联数量。

\subsection{随机高维向量往往近似正交}
如果两个独立随机单位向量在 $d_k$ 维空间中，那么它们点积的典型尺度为：
\begin{equation}
|\vect{k}_i^\top\vect{k}_j|\approx\frac{1}{\sqrt{d_k}},\qquad i\ne j.
\end{equation}
这里的 $\approx$ 表示随机情况下的\textbf{典型尺度}。

当 $d_k=64$，典型干扰相似度量级为：
\[
\frac{1}{\sqrt{64}}=\frac18=0.125.
\]
空间维度越高，随机无关 Key 往往越接近垂直，单条记忆造成的干扰通常越小。

\subsection{为什么有 \texorpdfstring{$\sqrt M$}{√M}？}
想象随机向左或向右走，每一步长度为 $1$。走 $100$ 步，并不是必然离原点 $100$ 步；方向会互相抵消，最终位移的典型大小是 $\sqrt{100}=10$。

如果各条干扰的方向、符号足够随机且近似独立，那么 $M$ 个小干扰的总波动规模通常不是 $M$ 倍，而是 $\sqrt M$ 倍。

将两条结果合并：
\begin{equation}
\boxed{\frac{\text{干扰}}{\text{信号}}\ \approx\ \sqrt M\times\frac{1}{\sqrt{d_k}}
=\sqrt{\frac{M}{d_k}}.}
\end{equation}
当干扰与信号处于同一量级时：
\begin{equation}
\sqrt{\frac{M}{d_k}}\approx1\quad\Rightarrow\quad M\approx d_k.
\end{equation}
因此在这个\textbf{随机 Key/Value、简单外积求和}的模型里，容量的标度大约是维度 $d_k$。

\subsection{平方激活为何带来平方量级？}
对于不相关 Key，原始相似度的典型大小是 $1/\sqrt{d_k}$；平方后，它变成约 $1/d_k$。但\textbf{$\relu(s)^2$ 本身非负，不会因为平方而产生正负抵消}。下面的 $\sqrt M$ 合并只在最终干扰的 Value 分量符号足够随机、近似独立且均值抵消等条件成立时适用；若所有 Value 同号，噪声可能随 $M$ 而不是 $\sqrt M$ 累加。在这些理想条件下，随机干扰的总体量级可以粗略看成：
\[
\frac{\text{干扰}}{\text{信号}}\ \approx\ \frac{\sqrt M}{d_k}.
\]
设这个量级达到 $1$：
\begin{equation}
\frac{\sqrt M}{d_k}\approx1
\quad\Rightarrow\quad
\boxed{M\approx d_k^2.}
\end{equation}
这就解释了为什么改变相似度的非线性，可以改变理论容量对维度的增长规律。一般的 $p$ 次选择性激活在相应理想假设下可产生 $M\approx d_k^p$ 这一类标度。

\subsection{线性注意力的状态，就是累加的外积记忆}

此前写入 $k_i^\top v_i$ 的方法可以按序列逐步进行。
每条 Key 和 Value 都是一行，$k_t:1\times d_k$、$v_t:1\times d_v$：
\[
\underbrace{S_0}_{d_k\times d_v}=0,\quad
\boxed{S_t=S_{t-1}+k_t^\top v_t
=\sum_{i\le t}k_i^\top v_i,\qquad y_t=q_tS_t.}
\]
查询行向量 $q_t:1\times d_k$ 得到 $y_t:1\times d_v$。
只有因果前缀参与累加，没有用到未来 Token 的信息；
这一结构与前面的\hyperref[intro:04-key-value-outer-product]{外积写入}
完全同形。

它是一类\textbf{未归一化线性状态}的教学基例。
核化线性 Attention 往往还需要特征映射、归一化分母等设计，
Gated DeltaNet 还包含对已有状态的误差修正或门控，
不能把这里的公式视为所有线性注意力模型的精确实现。

这些量级依赖独立性、随机性和激活函数的选择。
相关的 Key 与 Value 会改变干扰规模；可区分关联的数量也不同于模型可靠掌握的事实数量。

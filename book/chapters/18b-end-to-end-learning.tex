\subsection{把前面的数学连成一次真正的学习}

前面已经会用函数前向计算、用损失衡量误差，并沿两层计算链反传梯度。
把这些步骤连起来，就是一次参数学习。
继续沿用本章前半段的 $x=2,y=5,w_1=1,w_2=2$，这次添加两项偏置，
从\textbf{预测}算到\textbf{四个参数同时更新后的再预测}。

\subsubsection{先写一个只有一个隐藏单元的小网络}

设
\begin{equation}
z=w_1x+b_1,\quad h=\relu(z),\quad
\widehat y=w_2h+b_2,\quad
L=\frac12(\widehat y-y)^2.
\label{eq:small-network-full}
\end{equation}
从左到右分别是输入、第一层线性变换、激活函数、第二层线性变换、损失。虽然只有一个隐藏单元，但计算方式与更大 MLP 的局部结构相同。

取一个训练样本 $x=2,y=5$，初始参数设为：
\[
w_1=1,\qquad b_1=0,\qquad w_2=2,\qquad b_2=0.
\]

\subsubsection{第一步：把预测算出来（前向传播）}

\[\begin{aligned}
z&=1\times2+0=2,\\
h&=\relu(2)=2,\\
\widehat y&=2\times2+0=4,\\
L&=\frac12(4-5)^2=\frac12.
\end{aligned}\]
预测值 $4$ 比真实值 $5$ 小，损失是 $0.5$。但我们还不知道\textbf{究竟该调整哪一个参数}。

\subsubsection{第二步：从损失倒着求每个参数的梯度}

损失对预测值的导数是
\[
\frac{\partial L}{\partial\widehat y}=\widehat y-y=-1.
\]
因为初始偏置都是零，且本次 $\relu'(2)=1$，
所以本章前半段算过的两项权重梯度仍是
$\partial L/\partial w_1=-4$ 与 $\partial L/\partial w_2=-2$。
新加入的两项偏置梯度才是本章需要额外计算的：
\[
\frac{\partial L}{\partial b_2}=\widehat y-y=-1,\qquad
\frac{\partial L}{\partial b_1}=(-1)\times2\times1=-2.
\]
这四项梯度都来自\textbf{同一轮旧参数前向计算}，而不是边反传边修改权重。
注意 $\relu'(2)=1$；只有在\textbf{当前激活为正}的情况下，这条 ReLU 路径才传递了非零梯度。

\begin{idea}
\noindent\emph{为什么叫反向传播？}\par

计算损失时是 $x\to z\to h\to\widehat y\to L$；
计算梯度时则从 $\partial L/\partial\widehat y$ 开始，沿原来的计算链\textbf{倒着复用局部导数}。每条路径的变化率相乘，分叉路径的贡献相加。
\end{idea}

\subsubsection{第三步：四个参数一起更新，再做一次预测}

使用学习率 $\eta=0.05$，所有更新都依据同一轮前向传播的旧梯度：
\[\begin{aligned}
w_1'&=1-0.05(-4)=1.2,&
b_1'&=0-0.05(-2)=0.1,\\
w_2'&=2-0.05(-2)=2.1,&
b_2'&=0-0.05(-1)=0.05.
\end{aligned}\]

用新参数重新预测：
\[\begin{aligned}
z'&=1.2\times2+0.1=2.5,\\
h'&=\relu(2.5)=2.5,\\
\widehat y'&=2.1\times2.5+0.05=5.30,\\
L'&=\frac12(5.30-5)^2=0.045.
\end{aligned}\]
损失从 $0.5$ 降到 $0.045$，这次更新改善了该样本的预测。
新样本上是否同样有效，还需要另外检验。

\subsubsection{下一步：如果有许多输入数字怎么办？}

这一章仍只有单个 $x$ 与 $h$。若同时处理面积、房龄、位置等特征，
或有许多隐藏单元，我们仍然使用同一个学习循环，
但逐一写所有乘法和导数会非常繁琐。
后面会用\textbf{向量和矩阵}表达同样的计算，而不改变学习机制本身。

\chapterchecktasks{17-backpropagation}{正文基础三题}{
\item \textbf{计算：}设 $h=w_1x,\widehat y=w_2h$。当 $x=3,w_2=2$ 时，按链式法则求 $\partial\widehat y/\partial w_1$。
\item \textbf{预测：}在 $h=\relu(z)$ 且 $z=-2$ 时，从输出侧传来的梯度经过这条 ReLU 分支传向 $z$ 后还剩多少？
\item \textbf{找错：}同学把 $\partial L/\partial h$ 直接当作 $\partial L/\partial w_1$。缺了哪一个局部导数？
}
\chapterrecallanswer{反传沿计算图用链式法则传递并汇总梯度；优化器才负责把这些梯度变成参数更新。}

\chapterchecktasks{18b-end-to-end-learning}{正文基础三题}{
\item \textbf{流程：}把一次 SGD 分成“前向／损失／反传／更新”四步；哪一步读取训练目标，哪一步改变参数？
\item \textbf{手算：}$x=2,y=5,w_1=1,w_2=2,b_1=b_2=0$，$h=\relu(w_1x+b_1)$。求 $\widehat y$ 与 $\tfrac12(\widehat y-y)^2$。
\item \textbf{找错：}某同学先更新 $w_2$，再用新 $w_2$ 算本次 $w_1$ 的梯度，称它是“同一步同步 SGD”。指出问题。
}
\chapterrecallanswer{训练一步先用同一组旧参数求出完整梯度，再统一更新；单样本损失低不等于模型泛化好。}



\begin{conclusion}
训练的基本循环是：预测 $\to$ 算损失 $\to$ 求梯度 $\to$ 更新参数。
这个例子说明了参数怎样被更新；至于新样本是否预测得准，还涉及泛化问题。
下一章解释什么叫泛化，以及怎样识别模型把样本噪声当成规律。
\end{conclusion}

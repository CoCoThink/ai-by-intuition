\section{把 Attention 组装起来：Transformer 不只是一个公式}
\label{intro:22-transformer-architecture}

\begin{idea}
\noindent\emph{从“所有词都能互相查看”到完整网络}\par

Attention 能让 Token 从上下文读取信息，
但\textbf{一个 Attention 公式还不是完整的语言模型}。
把位置信息、多头读取、逐位置 FFN、归一化和残差接起来，
再经过词表输出头，才得到可以逐位置预测 Token 的网络。
\end{idea}

\subsection{先核对 Q/K/V 的形状}

设当前层输入为 $X$，每个 Token 是一行：
\[
\Qrole=XW_Q,\qquad \Krole=XW_K,\qquad \Vrole=XW_V.
\]
\begin{center}\QKVlegend\end{center}
例如 $T=3$，每条 Query/Key 为 $2$ 维，Value 为 $4$ 维，那么
\[
Q,K:3\times2,\qquad V:3\times4.
\]
计算分数：
\[
S=\frac{QK^\top}{\sqrt{d_k}}\in\R^{3\times3},
\]
第 $i$ 行记录第 $i$ 个 Token 对三个 Key 的匹配程度；每行 \conceptlink{softmax}{Softmax} 后和 $V$ 相乘，得到三个\textbf{带上下文信息}的新向量。

\subsection{Pre-Norm Block 中的两条残差连接}

把许多层接起来时，后层既需要已有特征，也需要本层提供的新信息。
能否保留原输入，让子层只补上一份修正？
例如输入为 $2$、子层给出修正 $0.3$，相加后得到 $2.3$。
\phantomsection\label{concept:residual}%
这条把输入直接送到加号的旁路叫作\textbf{残差连接}。
用一维函数表示，就是
\[
y=x+f(x)\quad\Longrightarrow\quad
\frac{\mathrm dy}{\mathrm dx}=1+f'(x).
\]
若只有 $y=f(x)$，梯度必须经过 $f'(x)$；相加后还多出一条导数为 $1$ 的旁路。
这个 $1$ 是不依赖子层导数的\textbf{恒等梯度通路}，
所以残差能改善深层网络的信息与梯度传播；
实际反传还要汇总各路径的梯度，并检查数值尺度。
还有一个问题：隐藏值经过层内运算，数值尺度可能越变越大或越变越小，增加训练的不稳定性。
能否先把送入子层的数值调整到较稳定的尺度，再做变换？
下面对\textbf{一个 Token 内的特征}操作，所有位置各自处理。

\Needspace{17\baselineskip}
\begin{example}[breakable=false]
\noindent\emph{LayerNorm：一个 Token 的两个特征怎么算？}\par

希望 $(2,4)$ 与整体放大十倍的 $(20,40)$ 都能先调整到可比较的尺度。
一种做法是\textbf{逐项减去本行均值，再除以本行标准差}，称为\textbf{层归一化（LayerNorm）}。
先忽略数值稳定项 $\varepsilon$、可学习缩放和平移。
对输入行向量 $(2,4)$，均值 $\mu=3$，
总体方差为 $\bigl((2-3)^2+(4-3)^2\bigr)/2=1$，
标准差为 $1$，得到
\[
\operatorname{LayerNorm}(2,4)
=\left(\frac{2-3}{1},\frac{4-3}{1}\right)=\boxed{(-1,1)}.
\]
对 $(20,40)$，均值为 $30$、标准差为 $10$，同样得到 $(-1,1)$。
这展示了它怎样消除整体放大带来的尺度差异。
实际实现加小正数 $\varepsilon$ 避免除零，还可学习逐特征的缩放与平移，调整归一化后的表示。
归一化在\textbf{该 Token 的特征维度}进行，
不是把全部 Token 的行平均掉。
\end{example}

把两种操作组合起来：旁路保留原输入，子层接收归一化后的输入。
\phantomsection\label{concept:pre-norm}%
这里选择\textbf{Pre-Norm（先归一化）}，本书数值主例的 Norm 取 LayerNorm。
每个子层都先 Norm、再计算、最后与旁路相加：
\begin{equation}
\label{eq:pre-norm-att}
X_{\rm att}=X+\operatorname{MHA}(\operatorname{Norm}(X)).
\end{equation}
\begin{equation}
\label{eq:pre-norm-ffn}
X_{\rm block}=X_{\rm att}+\operatorname{FFN}(\operatorname{Norm}(X_{\rm att})).
\end{equation}
这里 $\operatorname{MHA}$ 是多头注意力，$\operatorname{FFN}$ 是逐位置的前馈网络。
$X_{\rm att}$ 为第一次残差后的状态，$X_{\rm block}$ 为第二次残差后的输出；
两次相加各有自己的输入旁路，形状都保持 $T\times d_{\rm model}$。
FFN 的中间表示记为 $F_{\rm mid}$，与整个 Block 的输出相区分。

\textbf{观察两条标有“残差捷径”的旁路：}它们跳过模块直接到加号。
\input{figures/pre-norm-block}

另一种常见排列是 \textbf{Post-Norm}：先计算子层并与残差相加，再做归一化。
这里采用的是 Pre-Norm。

\subsection{训练时怎样防止目标泄漏？}

训练时，真实序列中的多个位置可以同时送入模型。第 $i$ 个位置只能读取输入中的第 $1$ 到第 $i$ 个 Token，不能读取自己的目标，也不能读取更后面的输入；否则模型会直接看到答案，损失就失去了“预测下一 Token”的意义。
因果掩码把这些不可见位置的注意力分数设成非常小的值（实现中常为 $-\infty$），经 Softmax 后权重变成零；三行的因果权重已在\conceptlink{causal-mask}{第~\ref*{intro:11-softmax-memory}~章}手算过。

例如 3 个 Token 的可见性（行是 Query，列是 Key）：

\input{figures/causal-mask-heatmap}

这能使\textbf{训练时的并行计算}保持“只能利用当前位置及之前内容”的条件。
生成时未来 Token 尚未输入，因此不存在一份可直接偷看的未来答案；
生成仍沿用同一套因果可见性规则，使训练和生成遵守相同的信息方向。

\subsection{原始 Transformer 与现代 Decoder-only LLM}
\phantomsection\label{concept:cross-attention}

经典 Encoder--Decoder Transformer 包含：编码器自注意力、解码器被掩码的自注意力，以及解码器对编码器输出的交叉注意力。交叉注意力的 Query 来自解码器，Key 和 Value 来自编码器。

很多生成式 LLM 使用\textbf{Decoder-only} 架构：以因果自注意力和 MLP 堆叠为主，逐步预测下一个 Token。
新架构也会重新组合编码器与解码器，第~\ref*{intro:22d-modern-transformers}~章介绍一个仍按自回归生成文本的实例。
还有\textbf{Encoder-only} 家族，例如 BERT，双向读取输入，
学习上下文表示，常用于分类、匹配或编码任务；
它与 Decoder-only 的因果下一 Token 预测目标不同。
至于图像\textbf{扩散模型（Diffusion Models）}，
常从噪声出发反复去噪生成数据，不属于 Transformer 编码器/解码器划分；
扩散模型的去噪网络本身可以选用 Transformer。

最后一个 Block 的隐藏状态再经词表输出头变成 logits，Softmax 后得到下一 Token 的概率；
第~\ref*{intro:10b-ffn-output-head}~章说明输出头与 FFN 的区别。

\subsection{十步口述：从文本到概率，再到学习或生成}
\phantomsection\label{sec:transformer-ten-steps}

先不逐项背公式，只说每一步\textbf{接收什么、产出什么}。
这份口述沿本书的 Decoder-only 主线，
原论文的 Encoder--Decoder 对照留到章末选读：

\begin{enumerate}[leftmargin=2.3em,itemsep=2pt]
\item \textbf{切分文字}：Tokenizer 把文本变成 Token ID（第~\ref*{intro:20a-tokenizer}~章）。
\item \textbf{查表并加位置}：Embedding 与位置表示得到 $X:T\times d$（第~\ref*{intro:20-embeddings}~章及第~\ref*{intro:22a-position-multihead}~章）。
\item \textbf{归一化输入}：每行做 Pre-Norm，为注意力子层准备特征（第~\ref*{intro:22-transformer-architecture}~章）。
\item \textbf{投影三种角色}：从每行得到 Query、Key、Value（第~\ref*{intro:21b-why-attention}~章）。
\item \textbf{匹配并遮挡未来}：计算 $QK^\top/\sqrt{d_k}$，对未来位置使用因果掩码（第~\ref*{intro:22-transformer-architecture}~章）。
\item \textbf{分配并读取}：逐行 Softmax 后乘 $V$；多头则拼接并做输出投影（第~\ref*{intro:11-softmax-memory}~章及第~\ref*{intro:22a-position-multihead}~章）。
\item \textbf{做第一次残差}：把注意力结果加回输入，形状仍为 $T\times d$（第~\ref*{intro:22-transformer-architecture}~章）。
\item \textbf{经过 FFN 和第二次残差}：再次归一化、逐行非线性变换，再与旁路相加（第~\ref*{intro:10b-ffn-output-head}~章）。
\item \textbf{产生词表概率}：输出头给每个位置 $|\mathcal V|$ 个 logits，再做 Softmax（第~\ref*{intro:22b-token-to-output}~章及第~\ref*{intro:22c-language-training}~章）。
\item \textbf{选择训练或生成}：训练用错位目标计算交叉熵并反传；生成只为下一位置选 Token、追加上下文（训练见第~\ref*{intro:22c-language-training}~章；生成见第~\ref*{intro:23-llm-systems}~章）。
\end{enumerate}

\textbf{第 1--9 步描述前向计算，第 10 步才分叉。}
生成时不执行反传；训练时可以并行监督多个位置。

\begin{example}
\noindent\emph{翻译任务怎样安排训练输入、目标与掩码？}\par

设源语句为“我 爱 你”，目标译文的三个 Token 为
“I / love / you”，另有开始符 \texttt{<BOS>} 和结束符 \texttt{<EOS>}。
训练时 Encoder 一次读取完整源语句，
Decoder 输入\textbf{右移后的真实目标前缀}
\[
[\texttt{<BOS>},\ \text{I},\ \text{love},\ \text{you}],
\]
需要预测
$[\text{I},\ \text{love},\ \text{you},\ \texttt{<EOS>}]$。
Decoder 的四个位置可以并行计算，
但第 $i$ 个位置的\textbf{自注意力}只能读取目标输入的前 $i$ 项，
例如第二位置的 Self-Attention 只读取前两个位置。
另一方面，每一个 Decoder 位置的\textbf{Cross-Attention}
都可以读取完整 Encoder 输出的三个源位置：
它看到的是\textbf{源语句}，不是未来目标标签。
\end{example}

原始 Encoder--Decoder 使用两种可见性规则：
\textbf{Decoder Self-Attention} 采用因果遮挡。

\textbf{Cross-Attention} 可访问整段已输入的源语句，并遮挡源语句的 Padding。
原论文与现代模型在 Norm 放置、位置编码、层数等细节上各有设计；

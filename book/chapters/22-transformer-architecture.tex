\section{把 Attention 组装起来：Transformer 不只是一个公式}
\label{intro:22-transformer-architecture}
\chaptercompass{只会 Attention 为什么还不够？}{残差和归一化连接 Attention 与 FFN，使表示可以逐层更新。}{$X:T\times d\to H:T\times d$}{Attention 的投影矩阵、FFN 两层权重；本书三维主例固定 Norm 仿射系数}
\modelpipelinefocus{3}{Transformer Block}


\begin{idea}
\noindent\emph{从“所有词都能互相查看”到完整网络}\par

Attention 能让 Token 从上下文读取信息，
但\textbf{一个 Attention 公式还不是完整的语言模型}。
把位置信息、多头读取、逐位置 FFN、归一化和残差接起来，
再经过词表输出头，才得到可以逐位置预测 Token 的网络。
\end{idea}

\subsection{先核对 Q/K/V 的形状}

设当前层输入为 $X$，每个 Token 是一行：
\[
\Qrole=XW_Q,\qquad \Krole=XW_K,\qquad \Vrole=XW_V.
\]
\begin{center}\QKVlegend\end{center}
例如 $T=3$，每条 Query/Key 为 $2$ 维，Value 为 $4$ 维，那么
\[
Q,K:3\times2,\qquad V:3\times4.
\]
计算分数：
\[
S=\frac{QK^\top}{\sqrt{d_k}}\in\R^{3\times3},
\]
第 $i$ 行记录第 $i$ 个 Token 对三个 Key 的匹配程度；每行 \conceptlink{softmax}{Softmax} 后和 $V$ 相乘，得到三个\textbf{带上下文信息}的新向量。

\subsection{Pre-Norm Block 中的两条残差连接}
\phantomsection\label{concept:pre-norm}
\phantomsection\label{concept:residual}

在这里选择\textbf{Pre-Norm（先归一化）}，每个子层都是
先 Norm、再计算、最后把尚未经过子层的输入加回来：
\begin{equation}
\label{eq:pre-norm-att}
X_{\rm att}=X+\operatorname{MHA}(\operatorname{Norm}(X)).
\end{equation}
\begin{equation}
\label{eq:pre-norm-ffn}
X_{\rm block}=X_{\rm att}+\operatorname{FFN}(\operatorname{Norm}(X_{\rm att})).
\end{equation}
$X_{\rm att}$ 表示第一次残差后的隐藏状态；
$X_{\rm block}$ 是第二次残差后的输出。
两个残差相加各有自己的输入旁路，保留特征宽度
$T\times d_{\rm model}$；因此输出仍可以继续进入下一层。
用一维函数看梯度：
\[
y=x+f(x)\quad\Longrightarrow\quad
\frac{\mathrm dy}{\mathrm dx}=1+f'(x).
\]
其中 $1$ 是不依赖子层导数的\textbf{恒等梯度通路}，
所以残差能改善深层网络的信息与梯度传播；
它不保证总梯度在所有情况下都不消失。
Block 有 Attention 与 FFN 两个子层，因此分别为这两次变换设置捷径。
多头 Attention 的单头输出记为 $O_j$，
FFN 的中间表示记为 $F_{\rm mid}$，与整个 Block 的输出相区分。

\textbf{观察橙色捷径：}它们跳过模块直接到加号，
而不是在模块里偷偷执行“残差”。

\begin{example}
\noindent\emph{LayerNorm：一个 Token 的两个特征怎么算？}\par

忽略数值稳定项 $\varepsilon$、可学习缩放和平移。
输入行向量 $(2,4)$，均值 $\mu=3$，
总体方差为 $\bigl((2-3)^2+(4-3)^2\bigr)/2=1$，
标准差为 $1$，得到
\[
\operatorname{LayerNorm}(2,4)
=\left(\frac{2-3}{1},\frac{4-3}{1}\right)=\boxed{(-1,1)}.
\]
为什么要归一化？不同层的隐藏值尺度可能改变，
导致训练的数值不稳定。LayerNorm 对单个 Token 的特征中心化并缩放，
帮助控制输入子层的尺度；它仍配合可学习的缩放、平移参数。
归一化在\textbf{该 Token 的特征维度}进行，
不是把全部 Token 的行平均掉。
\end{example}

另一种常见排列是 \textbf{Post-Norm}：先计算子层并与残差相加，再做归一化。
这里采用的是 Pre-Norm。

\subsection{生成时怎样禁止偷看未来？}
\phantomsection\label{concept:causal-mask}

在\textbf{生成下一个 Token} 的解码器里，第 $i$ 个位置不应该偷看第 $i+1$ 个及更后面的目标 Token。因果掩码把这些位置的注意力分数设成非常小的值（实现中常为 $-\infty$），经 Softmax 后权重变成零。

这能使\textbf{训练时的并行计算}保持“只能利用当前位置之前内容”的条件。

\subsection{原始 Transformer 与现代 Decoder-only LLM}
\phantomsection\label{concept:cross-attention}

经典 Encoder--Decoder Transformer 包含：编码器自注意力、解码器被掩码的自注意力，以及解码器对编码器输出的交叉注意力。交叉注意力的 Query 来自解码器，Key 和 Value 来自编码器。

很多生成式 LLM 使用\textbf{Decoder-only} 架构：以因果自注意力和 MLP 堆叠为主，逐步预测下一个 Token。不能把所有 Transformer 都说成完全相同的结构。

\subsection{对照原论文：Encoder、Decoder、Cross-Attention 分别在哪里？}

\href{https://arxiv.org/abs/1706.03762}{Vaswani 等（2017）《Attention Is All You Need》}
展示的是用于序列到序列任务的\textbf{编码器--解码器架构}。
本书主线的 Decoder-only 自回归模型，保留因果自注意力和 FFN，
但不需要一套独立的源语句 Encoder。

\begin{example}
\noindent\emph{翻译任务怎样安排训练输入、目标与掩码？}\par

设源语句为“我 爱 你”，目标译文的三个 Token 为
“I / love / you”，另有开始符 \texttt{<BOS>} 和结束符 \texttt{<EOS>}。
训练时 Encoder 一次读取完整源语句，
Decoder 输入\textbf{右移后的真实目标前缀}
\[
[\texttt{<BOS>},\ \text{I},\ \text{love},\ \text{you}],
\]
需要预测
$[\text{I},\ \text{love},\ \text{you},\ \texttt{<EOS>}]$。
Decoder 的四个位置可以并行计算，
但第 $i$ 个位置的\textbf{自注意力}只能读取目标输入的前 $i$ 项，
例如第二位置不能通过 Self-Attention 读到第三位置的“love”。
另一方面，每一个 Decoder 位置的\textbf{Cross-Attention}
都可以读取完整 Encoder 输出的三个源位置：
它看到的是\textbf{源语句}，不是未来目标标签。
\end{example}

这里是两种独立的可见性规则：
\textbf{Decoder Self-Attention} 要因果遮挡，
\textbf{Cross-Attention} 通常可访问整段已输入的源语句，
但仍需遮挡源语句的 Padding。
原论文与现代模型在 Norm 放置、位置编码、层数等细节上可能不同；
对照时先认清数据流，而不是把架构图所有框都当成同一配置。

\subsection{最后如何得到下一个 Token 的概率？}

对最后位置的隐藏状态 $\vect h_T$ 做输出线性投影，得到与词表大小一样多的\textbf{logits（未归一化的候选分数）}。它们还不是概率，也可能为负：
\[
\vect z^\top=\vect h_T^\top W_{\rm vocab}+\vect b_{\rm vocab}^\top,
\quad W_{\rm vocab}\in\R^{d_{\rm model}\times|\mathcal V|}.
\]
再通过 Softmax：
\[
p_i=\frac{e^{z_i}}{\sum_j e^{z_j}},
\]
得到下一 Token 的概率分布。生成时按一定策略选择 Token，再把它加入上下文，重复计算。

\subsection{十步口述：从文本到概率，再到学习或生成}
\phantomsection\label{sec:transformer-ten-steps}

先不逐项背公式，只说每一步\textbf{接收什么、产出什么}。
这份口述沿本书的 Decoder-only 主线，
与下面原论文的 Encoder--Decoder 对照图应分开阅读：

\begin{enumerate}[leftmargin=2.3em,itemsep=2pt]
\item \textbf{切分文字}：Tokenizer 把文本变成 Token ID（第 12 章）。
\item \textbf{查表并加位置}：Embedding 与位置表示得到 $X:T\times d$（第 14、21 章）。
\item \textbf{归一化输入}：每行做 Pre-Norm，为注意力子层准备特征（第 22 章）。
\item \textbf{投影三种角色}：从每行得到 Query、Key、Value（第 19 章）。
\item \textbf{匹配并遮挡未来}：计算 $QK^\top/\sqrt{d_k}$，对未来位置使用因果 Mask（第 20、22 章）。
\item \textbf{分配并读取}：逐行 Softmax 后乘 $V$；多头则拼接并做输出投影（第 20、21 章）。
\item \textbf{做第一次残差}：把注意力结果加回输入，形状仍为 $T\times d$（第 22 章）。
\item \textbf{经过 FFN 和第二次残差}：再次归一化、逐行非线性变换，再与旁路相加（第 22、23 章）。
\item \textbf{产生词表概率}：输出头给每个位置 $|\mathcal V|$ 个 logits，再做 Softmax（第 23、24 章）。
\item \textbf{选择训练或生成}：训练用错位目标计算交叉熵并反传；生成只为下一位置选 Token、追加上下文（第 25、26 章）。
\end{enumerate}

\textbf{第 1--9 步描述前向计算，第 10 步才分叉。}
生成时不执行反传；训练时可以并行监督多个位置。

\begin{conclusion}
一个常见的 Transformer Block 由注意力、逐 Token 的前馈网络、残差与归一化构成，
整个语言模型还需要 Token 表示与输出头。
现在网络的\textbf{组件清单}已经齐了，下一章先辨清Block 内的 FFN 与最终输出头为何不是一回事。
\end{conclusion}

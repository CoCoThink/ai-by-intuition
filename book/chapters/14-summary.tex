\subsection{线性层、MLP 与 Attention 的统一检索视角}
\phantomsection\label{intro:14-summary}
采用行向量 $x:1\times d_k$，
以及逐行堆叠的 $K:M\times d_k$、$V:M\times d_v$：

\begin{center}\small
\tagpdfsetup{table/header-rows={1}}
\begin{tabularx}{\linewidth}{@{}p{23mm}p{57mm}X@{}}
\toprule
计算 & 一次读取的行向量写法 & 关键区别\\\midrule
Linear & $x(K^\top V)=xS$ & 线性匹配，外积可相加\\
MLP & $\sigma(xK^\top)V$ & 非线性筛选，权重不必归一化\\
Attention & $\softmax(\beta xK^\top)V$ & 每条查询归一化权重，Mask 限制可见范围\\
\bottomrule
\end{tabularx}
\end{center}
缩放系数 $\beta$ 在标准点积注意力里通常取
$1/\sqrt{d_k}$。三者都可以写成加权读出的形式：
\[
\text{输出}=\sum_i \text{匹配权重}_i\,v_i.
\]
但不能由此认定它们的计算、容量和训练行为相同。

\subsubsection{Key 和 Value 究竟保存在哪里？}
从 MLP 的“记忆”视角，Key 和 Value 可由训练得到的权重表示；
从 Self-Attention 的视角，它们是当前序列经过投影产生的上下文状态。
因此 MLP 的参数记忆与 Attention 的上下文读取\textbf{来源不同}。
普通 Softmax Attention 不能直接用不带条件的固定 $S$ 精确替代。
正文第~\ref*{intro:22d-modern-transformers}~章已展示满足特定条件的\textbf{线性状态更新}，这里给出它的外积记忆视角。

% Chapter 29 concludes only after the 29.3 unified retrieval section.
\chapterchecktasks{09-nonlinearity-and-memory}{非线性：预测／手算／找错／比较}{
\item \textbf{预测：}当相似度在 $[0,1]$ 内时，提高幂次会怎样影响严格小于 $1$ 的匹配？恰为 $1$ 的匹配呢？
\chapterinlinehint{09-nonlinearity-and-memory}{1}
\item \textbf{手算：}分别算 $0.5^2$、$0.5^3$，再算 $(-0.5)^2$、$(-0.5)^3$。
\chapterinlinehint{09-nonlinearity-and-memory}{2}
\item \textbf{找错：}同学说“平方任何相似度都只会压小错误匹配，包括负值”。用上题反例指出问题。
\chapterinlinehint{09-nonlinearity-and-memory}{3}
\item \textbf{比较：}把 MLP 解释成“Key 匹配、Value 读取”有什么直觉收益？为什么不能据此宣称神经元一对一存储真实事实？
\chapterinlinehint{09-nonlinearity-and-memory}{4}
}
\chapterrecallanswer{非线性改变匹配的选择性，但必须说明分数范围；MLP 的记忆类比是计算视角而非事实库存证明。}

\chapterchecktasks{14-summary}{统一检索：比较／手算／找错／场景}{
\item \textbf{比较：}分别用一句话描述外积线性记忆、Softmax Attention 和逐 Token FFN 的匹配、读取或特征变换角色。
\chapterinlinehint{14-summary}{1}
\item \textbf{手算：}两条 Value 是 $(1,0),(0,1)$，读取权重为 $(0.25,0.75)$，输出是什么？
\chapterinlinehint{14-summary}{2}
\item \textbf{找错：}某人看到外积读出与 Attention 都可写成权重乘 Value，就宣布它们的权重归一化、容量与更新过程完全相同。至少指出两项差异。
\chapterinlinehint{14-summary}{3}
\item \textbf{场景：}若模型给出一句看似事实的答案，能否只根据某 FFN 神经元被激活就断言那是一条被验证的事实？应怎样补证？
\chapterinlinehint{14-summary}{4}
}
\chapterrecallanswer{“匹配—读取”帮助比较结构，不代表 Softmax 与线性记忆等价，更不代表模型事实已被外部验证。}



\begin{conclusion}
非线性 MLP、线性外积记忆与 Softmax Attention 都可以从匹配和读取来理解，
但归一化方式、参数来源和写入机制不同，不能把计算类比当作真实知识存储的证明。
\end{conclusion}

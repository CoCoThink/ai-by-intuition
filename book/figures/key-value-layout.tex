\small
\noindent{\sffamily\bfseries\color{ink}图解：为什么一会儿写 $K$，一会儿写 $K^\top$？}\par\smallskip
延续本章开头的单 Query 示例：$K=\begin{bmatrix}1&0\\1&1\\2&1\end{bmatrix}$，有 $M=3$ 条 Key、$d_k=2$ 个数字。
\textbf{相同底色表示同一条 Key：两栏中的数字相同，只是摆放方向不同。}

\vspace{1.5mm}
\noindent
\begin{minipage}[t]{.49\linewidth}

$K\in\R^{M\times d_k}$\\
{\footnotesize 每行一条 Key}

\textbf{行向量 Query 的写法}\\[2mm]
\begin{tikzpicture}[x=10mm,y=9mm]

\\[1mm]
$K^\top\in\R^{d_k\times M}$\\
{\footnotesize 每列一条 Key}
\end{minipage}

\[
K\vect q=\vect s,\qquad
\vect q^\top K^\top=\vect s^\top.
\]
{\footnotesize\color{muted}形状：$K:M\times d_k$，$\vect q:d_k\times1$，
$\vect s:M\times1$；转置后为 $1\times d_k$ 乘 $d_k\times M$。}\par
\begin{center}
{\color{blue}\bfseries $(K\vect q)^\top=\vect q^\top K^\top$}
\end{center}

\textbf{Value 同理：}约定 $V$ 的\textbf{每行是一条 Value}，
可以按需转置，读取相同的加权结果：
\[
V\ \xleftrightarrow{\text{转置}}\ V^\top,\qquad
V^\top\vect a=\vect y,\quad \vect a^\top V=\vect y^\top.
\]
{\footnotesize\color{muted}形状：$V:M\times d_v$，
$V^\top:d_v\times M$，$\vect a:M\times1$，
$\vect y:d_v\times1$。}\par
\textbf{检查：}若 $M=3$、$d_k=2$、$d_v=4$，
则 $K:3\times2$、$K^\top:2\times3$、
$V:3\times4$、$V^\top:4\times3$。
\textbf{Key 和 Value 不必具有相同维度。}

\textbf{重要边界：}上面比较的是\emph{同一个单 Query}的转置写法。
扩展成多个 Query 后使用 $QK^\top$；
不要把 $QK^\top$ 和 $KQ^\top$ 直接当作可以交换的运算。
